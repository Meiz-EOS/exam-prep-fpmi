## aig-t-1301
### Формулировка
Пусть 2 различные плоскости $pi_i$ заданы своими общими уравнениями
$\begin{gathered} \pi_1: f_1(x,y,z) = A_1x+B_1y+C_1z+D_1 = 0\\
\pi_2: f_2(x,y,z) = A_2x+B_2y+C_2z+D_2 = 0
\end{gathered}\Longrightarrow$ пучок, порожденный $\pi_1, \pi_2$ состоит из тех и только тех плоскостей, координаты точек которых удовлетворяют уравнению $$\alpha f_1(x,y,z)+\beta f_2(x,y,z) = 0, \alpha, \beta \in \mathbb{R}, \alpha^2+\beta^2\ne0$$
### Скелет
1. Пусть $\pi$ задаётся уравнением $\alpha f_1+\beta f_2=0$: если $\pi_1,\pi_2$ пересекаются по прямой $l$, то $f_1(l)=f_2(l)=0$, значит $\pi\supset l$ и лежит в пучке.
2. Если $\pi_1\parallel\pi_2$, то $\vec n_\pi=\alpha\vec n_1+\beta\vec n_2\parallel\vec n_1$, значит $\pi$ параллельна им и лежит в пучке параллельных плоскостей.
3. Обратно: пусть $\pi$ из пучка; возьмём точку $X\in\pi$ вне $\pi_1,\pi_2$ и положим $\alpha=f_2(X)$, $\beta=-f_1(X)$.
4. Плоскость $f_2(X)f_1-f_1(X)f_2=0$ проходит через $X$ и $l$, поэтому совпадает с $\pi$.

## aig-t-1302
### Формулировка
Пусть связка плоскостей в пространстве задается 3 плоскостями $\pi_i: A_ix+B_iy+C_iz+D_i = f_i(x,y,z) = 0, i = 1,2,3$, пересекающиеся в одной точке $X_0$. Тогда связка плоскостей состоит из тех и только тех плоскостей, координаты точек которых удовлетворяют уравнению $\alpha f_1(x,y,z) + \beta f_2(x,y,z)+\gamma f_3(x,y,z) = 0$.
### Скелет
1. Три плоскости пересекаются в одной точке, поэтому система их уравнений имеет единственное решение.
2. Следовательно, определитель из коэффициентов нормалей ненулевой: $\vec n_1,\vec n_2,\vec n_3$ некомпланарны и образуют базис $V_3$.
3. Разложим нормаль произвольной плоскости связки: $\vec n=\alpha\vec n_1+\beta\vec n_2+\gamma\vec n_3$.
4. Те же коэффициенты дают уравнение $\alpha f_1+\beta f_2+\gamma f_3=0$ плоскости, проходящей через $X_0$.

## aig-t-1303
### Формулировка
За угол между двумя плоскостями принимается линейный угол между двумя прямыми, который образуется при пересечении $\pi_1,\pi_2$ плоскостью $\pi$, перпендикулярной прямой пересечения $\pi_1\cap\pi_2=l$. Тогда $\cos\phi=|\cos\angle(\vec n_1,\vec n_2)|=\dfrac{|(\vec n_1,\vec n_2)|}{|\vec n_1||\vec n_2|}$.
