## aig-t-3301
### Формулировка
(Теорема Кэли) Любая группа $G$ изоморфна некоторой подгруппе группы перестановок $S_G$. Если $|G|=n$, то $G$ изоморфна подгруппе симметрической группы $S_n$.
### Скелет
1. Для каждого $g\in G$ зададим перестановку элементов группы левым умножением: $g_j\mapsto gg_j$.
2. Отображение $g\mapsto\sigma_g$ сохраняет операцию, поскольку последовательные умножения соответствуют произведению элементов.
3. Ядро состоит из тех $g$, которые фиксируют каждый элемент; из условия $ge=e$ следует $g=e$.
4. Гомоморфизм с тривиальным ядром задает изоморфизм на свою подгруппу перестановок.

## aig-t-3302
### Формулировка
$<X> = \{x_1^{\epsilon_1}\cdot\ldots\cdot x_k^{\epsilon_k}| k = 0, 1, \ldots, \epsilon_i = \pm 1\} = F$. (k = 0 соответствует тривиальной группе)
### Скелет
1. Множество таких конечных произведений содержит единицу и $X$.
2. Оно замкнуто относительно произведения и обратного, значит, является подгруппой.
3. Поэтому минимальная подгруппа, содержащая $X$, содержится в этом множестве.
4. Любая подгруппа, содержащая $X$, содержит все такие произведения; значит, содержит $F$.
