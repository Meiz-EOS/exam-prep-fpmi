## aig-t-0101
### Формулировка
Матрица - прямоугольная таблица чисел. Пусть будет $m$ строк и $n$ столбцов. Обозначения для матриц - $A, B, C ...$ Для элементов: $a_{ij}, b_{ij}, c_{ij}$

## aig-t-0102
### Формулировка
Операции сложения матриц и умножения на число удовлетворяют следующим свойствам: $(A, B \in M_{m\times n})$

1. Коммутативность сложения $A + B = B + A$
2. Ассоциативность сложения $(A+B)+C = A+(B+C)$
3. Существует нулевая матрица: $0 + A = A + 0 = A$
4. Существует противоположная матрица $(-A)$: $A + (-A) = (-A) + A = 0$
5. Унитарность $1 * A = A * 1 = A$
6. Ассоциативность $(\lambda\nu)A = \lambda(\nu A)$
7. Дистрибутивность: $\lambda(A+B) = \lambda A + \lambda B$
8. Дистрибутивность: $(\lambda + \mu) A = \lambda A + \mu A$

### Скелет
1. Поэлементно раскроем сумму матриц и умножение на скаляр.
2. Используем distributивность умножения числа относительно сложения элементов.
3. Получившиеся элементы совпадают с элементами матрицы $\lambda A+\lambda B$.
