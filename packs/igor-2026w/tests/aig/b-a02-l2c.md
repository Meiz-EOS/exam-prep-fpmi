## aig-q-1409
ticket: aig-t-3302 · level: L2
Докажите, что подгруппа, порождённая $X=\{x_1,\ldots,x_k\}\subseteq G$, состоит ровно из конечных произведений элементов $x_i$ и $x_i^{-1}$, включая пустое произведение $e$.
### Эталон
- Обозначить множество таких произведений через $F$.
- Пустое произведение даёт $e\in F$; произведение двух слов снова слово, значит $F$ замкнуто относительно операции.
- Обратное к слову $x_1^{\epsilon_1}\cdots x_k^{\epsilon_k}$ равно обратному порядку множителей с противоположными степенями, поэтому лежит в $F$.
- Значит $F$ — подгруппа $G$, содержащая $X$, откуда $\langle X\rangle\subseteq F$.
- Каждое слово из определения $F$ принадлежит любой подгруппе, содержащей $X$; в частности $F\subseteq\langle X\rangle$.
- Получаем $F=\langle X\rangle$.

## aig-q-1410
ticket: aig-t-3401 · level: L2
Докажите, что циклические группы одинакового порядка изоморфны: бесконечная циклическая группа изоморфна $\mathbb{Z}$, а группа порядка $n$ — $\mathbb{Z}_n$.
### Эталон
- Пусть $G=\langle a\rangle$ бесконечного порядка; задать $\phi:\mathbb{Z}\to G$, $k\mapsto a^k$.
- Равенство $a^{k_1}a^{k_2}=a^{k_1+k_2}$ доказывает гомоморфность; порождаемость даёт сюръективность.
- Если $a^k=e$, бесконечный порядок вынуждает $k=0$, поэтому $\phi$ инъективно.
- Для конечной группы порядка $n$ задать $\phi:\mathbb{Z}_n\to G$, $\overline{k}\mapsto a^k$.
- Из $k_1-k_2=qn$ и $a^n=e$ следует $a^{k_1}=a^{k_2}$, так что отображение корректно; правило степеней даёт гомоморфизм.
- Представители $\overline0,\ldots,\overline{n-1}$ переходят во все различные элементы $e,a,\ldots,a^{n-1}$; значит $\phi$ биективно, а любые две группы того же порядка изоморфны композицией полученных изоморфизмов.

## aig-q-1411
ticket: aig-t-3402 · level: L2
Докажите теорему Лагранжа: если $H$ — подгруппа конечной группы $G$, то $|H|$ делит $|G|$.
### Эталон
- Для каждого $a\in G$ рассмотреть левый смежный класс $aH$.
- Отображение $h\mapsto ah$ — биекция $H\to aH$, поэтому каждый смежный класс имеет $|H|=q$ элементов.
- Смежные классы попарно не пересекаются либо совпадают и покрывают $G$.
- Выбрать по одному представителю каждого из $m$ различных классов; тогда $G$ — дизъюнктное объединение этих классов.
- Следовательно, $|G|=mq$ для целого $m$.
- Значит $q=|H|$ делит $|G|$.

## aig-q-1412
ticket: aig-t-3601 · level: L2
Выведите правила умножения комплексных чисел и докажите, что $\mathbb{C}=\{a+bi:a,b\in\mathbb{R}\}$ образует поле: $(a+bi)(c+di)=(ac-bd)+(ad+bc)i$.
### Эталон
- Положить $i^2=-1$ и раскрыть произведение по дистрибутивности: $ac+adi+bci+bdi^2=(ac-bd)+(ad+bc)i$.
- Сложение покоординатно задаёт абелеву группу с нулём $0+0i$ и противоположным $-a-bi$.
- Формула умножения замкнута на парах $(a,b)$. Коммутативность следует из коммутативности умножения в $\mathbb R$; при раскрытии обе расстановки скобок в произведении трёх чисел дают действительную часть $ace-bde-adf-bcf$ и мнимую часть $acf-bdf+ade+bce$ для множителей $a+bi,c+di,e+fi$, значит умножение ассоциативно.
- Единица равна $1+0i$, дистрибутивность следует из раскрытия произведения.
- Для $a+bi\ne0$ имеем $a^2+b^2>0$, поэтому существует обратное $(a-bi)/(a^2+b^2)$.
- Проверка умножением даёт $(a+bi)(a-bi)/(a^2+b^2)=1$; следовательно, каждый ненулевой элемент обратим и $\mathbb{C}$ — поле.
