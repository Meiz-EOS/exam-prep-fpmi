## aig-q-614
ticket: aig-t-0601 · level: L0
Сформулируйте правило Крамера для системы линейных уравнений с тремя неизвестными.
### Эталон
- Система называется определённой тогда и только тогда, когда $\det A=\Delta\ne0$.
- В этом случае она имеет единственное решение.
- $x=\frac{\Delta_x}{\Delta}$, $y=\frac{\Delta_y}{\Delta}$, $z=\frac{\Delta_z}{\Delta}$, где $\Delta_x,\Delta_y,\Delta_z$ получаются заменой соответствующего столбца $A$ столбцом правой части.

## aig-q-615
ticket: aig-t-3202 · level: L0
Сформулируйте характеристизацию определителя через полилинейность и кососимметричность.
### Эталон
- $\det A$ является полилинейной кососимметрической функцией от строк (или столбцов) матрицы $A$.
- Если $f:M_n(F)\to F$ — полилинейная кососимметрическая функция от строк (или столбцов), то $f(A)=f(E)\det A$.
- Здесь $E$ — единичная матрица.

## aig-q-616
ticket: aig-t-3203 · level: L0
Сформулируйте разложение определителя по выбранной строке или столбцу.
### Эталон
- Для строки $i$ выполняется $\det A=\sum_{j=1}^{n}a_{ij}A_{ij}$.
- Для столбца $j$ выполняется $\det A=\sum_{i=1}^{n}a_{ij}A_{ij}$.
- $A_{ij}$ — алгебраическое дополнение соответствующего элемента.

## aig-q-617
ticket: aig-t-3203 · level: L1
Назовите идею и скелет доказательства разложения определителя по строке.
### Эталон
- Представляют выбранную строку как сумму строк, в каждой из которых ненулевой только один элемент.
- По полилинейности определитель равен сумме определителей полученных матриц.
- Каждый такой определитель равен элементу строки, умноженному на его алгебраическое дополнение.
- Складывая слагаемые, получают $\det A=\sum_{j=1}^{n}a_{ij}A_{ij}$; для столбца рассуждение аналогично.
