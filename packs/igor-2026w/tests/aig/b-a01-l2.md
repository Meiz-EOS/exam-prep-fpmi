## aig-q-1401
ticket: aig-t-0102 · level: L2
Докажите дистрибутивность умножения матрицы на число относительно сложения матриц: для $A,B\in M_{m\times n}$ и $\lambda\in\mathbb{R}$ выполнено $\lambda(A+B)=\lambda A+\lambda B$.
### Эталон
- Зафиксировать произвольные $i,j$ и обозначить элементы матриц через $a_{ij},b_{ij}$.
- По определению сложения и умножения на число $(\lambda(A+B))_{ij}=\lambda(A+B)_{ij}$.
- По поэлементному определению сложения это равно $\lambda(a_{ij}+b_{ij})$.
- По дистрибутивности в $\mathbb{R}$ получаем $\lambda a_{ij}+\lambda b_{ij}$.
- По определению операций это $(\lambda A)_{ij}+(\lambda B)_{ij}=(\lambda A+\lambda B)_{ij}$.
- Равенство всех элементов влечёт равенство матриц.
