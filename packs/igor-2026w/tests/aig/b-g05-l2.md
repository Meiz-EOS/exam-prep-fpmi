## aig-q-1109
ticket: aig-t-0801 · level: L2
Докажите, что для любых $\vec a,\vec b,\vec c$ ориентированный объём равен $V(\vec a,\vec b,\vec c)=([\vec a,\vec b],\vec c)=(\vec a,[\vec b,\vec c])$.
### Эталон
- При $\vec a\parallel\vec b$ обе части равны нулю.
- Иначе выбирают единичную нормаль $\vec n$ к плоскости $\vec a,\vec b$ так, чтобы $(\vec a,\vec b,\vec n)$ была правой тройкой.
- По формуле ориентированного объёма через ориентированную площадь основания $V(\vec a,\vec b,\vec c)=S(\vec a,\vec b)(\vec n,\vec c)$.
- По определению векторного произведения $[\vec a,\vec b]=S(\vec a,\vec b)\vec n$.
- Подстановка даёт $V(\vec a,\vec b,\vec c)=([\vec a,\vec b],\vec c)$.
- Циклическая перестановка аргументов не меняет объём; повторное применение равенства даёт $V(\vec a,\vec b,\vec c)=(\vec a,[\vec b,\vec c])$.

## aig-q-1110
ticket: aig-t-0901 · level: L2
Выведите формулу векторного произведения в произвольном базисе $\mathfrak E=(\vec e_1,\vec e_2,\vec e_3)$, если координаты $\vec a,\vec b$ равны $\alpha=(\alpha_1,\alpha_2,\alpha_3)$ и $\beta=(\beta_1,\beta_2,\beta_3)$:
$$[\vec a,\vec b]=(\alpha_2\beta_3-\alpha_3\beta_2)[\vec e_2,\vec e_3]+(\alpha_3\beta_1-\alpha_1\beta_3)[\vec e_3,\vec e_1]+(\alpha_1\beta_2-\alpha_2\beta_1)[\vec e_1,\vec e_2].$$
### Эталон
- Разлагают $\vec a=\sum_i\alpha_i\vec e_i$ и $\vec b=\sum_j\beta_j\vec e_j$.
- Билинейность даёт $[\vec a,\vec b]=\sum_{i,j}\alpha_i\beta_j[\vec e_i,\vec e_j]$.
- Кососимметрия зануляет диагональные члены и заменяет $[\vec e_j,\vec e_i]$ на $-[\vec e_i,\vec e_j]$.
- Собирают слагаемые при $[\vec e_2,\vec e_3]$, получая коэффициент $\alpha_2\beta_3-\alpha_3\beta_2$.
- Сбор при $[\vec e_3,\vec e_1]$ и $[\vec e_1,\vec e_2]$ даёт оставшиеся два указанных коэффициента.
- Полученная линейная комбинация есть искомое векторное произведение; её коэффициенты образуют определитель из формулировки.
