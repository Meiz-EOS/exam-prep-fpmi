## aig-q-101
ticket: aig-t-0201 · level: L1
Назовите идею и скелет доказательства утверждения о равенстве направленных отрезков, задающих один и тот же вектор.
### Эталон
- Рассматривают два направленных отрезка, задающих один вектор.
- По определению равенства векторов они равны как направленные отрезки.
- Если направленные отрезки равны, они принадлежат одному классу эквивалентности.
- Поэтому они задают один и тот же вектор.

## aig-q-102
ticket: aig-t-0202 · level: L0
Сформулируйте свойства сложения векторов и умножения на скаляр, указанные в теореме.
### Эталон
- Сложение коммутативно и ассоциативно; существует нулевой вектор и противоположный вектор для каждого вектора.
- $1\vec a=\vec a$ и $(\lambda\mu)\vec a=\lambda(\mu\vec a)$.
- $(\lambda+\mu)\vec a=\lambda\vec a+\mu\vec a$.
- $\lambda(\vec a+\vec b)=\lambda\vec a+\lambda\vec b$.

## aig-q-103
ticket: aig-t-0202 · level: L1
Назовите идею и скелет доказательства свойств сложения векторов и умножения на скаляр.
### Эталон
- Представляют векторы направленными отрезками и используют правило параллелограмма для сложения.
- Коммутативность и ассоциативность сложения следуют из геометрического правила сложения.
- Нулевой вектор и противоположный вектор задают нейтральный и обратный элементы сложения.
- Свойства умножения на скаляр проверяют по длинам и направлениям; дистрибутивности следуют из сложения отрезков.

## aig-q-104
ticket: aig-t-0301 · level: L0
Сформулируйте критерий линейной зависимости конечной системы векторов.
### Эталон
- Система векторов линейно зависима тогда и только тогда, когда хотя бы один из её векторов выражается как линейная комбинация остальных.
- Эквивалентно, существует нетривиальная линейная комбинация векторов, равная нулю.
- Нетривиальная означает, что хотя бы один коэффициент отличен от нуля.

## aig-q-105
ticket: aig-t-0301 · level: L1
Назовите идею и скелет доказательства критерия линейной зависимости системы векторов.
### Эталон
- Из нетривиальной линейной комбинации, равной нулю, выбирают ненулевой коэффициент.
- Делят равенство на этот коэффициент и выражают соответствующий вектор через остальные.
- Если один вектор выражается через остальные, переносят выражение в одну сторону.
- Получают нетривиальную линейную комбинацию, равную нулю.

## aig-q-106
ticket: aig-t-0302 · level: L1
Назовите идею и скелет доказательства теоремы о линейно независимых системах векторов.
### Эталон
- Для одного ненулевого вектора равенство $\lambda\vec a=\vec 0$ при $\lambda\ne0$ невозможно по длинам.
- Если два вектора зависимы, один выражается через другой, поэтому они коллинеарны.
- Если три вектора зависимы, один выражается через два остальных, поэтому тройка компланарна.
- В каждом случае предположение зависимости противоречит соответствующему геометрическому условию.
