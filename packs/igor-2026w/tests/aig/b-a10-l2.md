## aig-q-1708
ticket: aig-t-0601 · level: L2
Докажите правило Крамера для системы $A(x,y,z)^T=b$ с $\det A=\Delta\ne0$: решение единственно и $x=\Delta_x/\Delta$, $y=\Delta_y/\Delta$, $z=\Delta_z/\Delta$, где $\Delta_x,\Delta_y,\Delta_z$ получаются заменой соответствующего столбца на $b$.
### Эталон
- $\Delta\ne0$ означает, что векторы-столбцы $a_1,a_2,a_3$ линейно независимы и образуют базис.
- Поэтому разложение $b=xa_1+ya_2+za_3$ существует и единственно.
- В смешанном произведении $V(a_1,a_2,b)$ подстановка разложения и полилинейность оставляют только $zV(a_1,a_2,a_3)$.
- Отсюда $z=V(a_1,a_2,b)/V(a_1,a_2,a_3)=\Delta_z/\Delta$.
- Аналогично вычисляются $x$ и $y$ циклической заменой столбцов.
- Базисное разложение даёт единственность решения.

## aig-q-1709
ticket: aig-t-3202 · level: L2
Докажите характеризацию определителя: он полилинеен и кососимметричен по строкам (столбцам), а всякая такая функция $f$ удовлетворяет $f(A)=f(E)\det A$.
### Эталон
- Формула определителя как суммы по перестановкам показывает линейность по каждой строке.
- Перестановка двух строк меняет знак каждого слагаемого по знаку перестановки; при совпавших строках определитель равен нулю.
- Пусть строки $A$ равны $a_i=\sum_j a_{ij}e_j$; полилинейность раскрывает $f(A)$ в сумму по выборам $j_1,\ldots,j_n$.
- Слагаемые с повторяющимися индексами равны нулю по кососимметрии.
- Оставшиеся наборы индексов задаются перестановками $\sigma$; перестановка аргументов даёт множитель $\epsilon(\sigma)$.
- Следовательно, $f(A)=\sum_\sigma\epsilon(\sigma)\prod_i a_{i\sigma(i)}f(E)=\det(A)f(E)$.

## aig-q-1710
ticket: aig-t-3203 · level: L2
Выведите разложение определителя по $i$-й строке: $\det A=\sum_{j=1}^n a_{ij}A_{ij}$, где $A_{ij}$ — алгебраическое дополнение элемента $a_{ij}$.
### Эталон
- Представляют строку $a_i$ суммой строк, в каждой из которых оставлен только один элемент $a_{ij}$.
- По линейности определителя по $i$-й строке определитель равен сумме определителей полученных матриц.
- В слагаемом с единственным ненулевым элементом строки $a_{ij}$ выносят этот множитель.
- Оставшийся минор со знаком кофактора равен $A_{ij}$ по определению алгебраического дополнения.
- Суммирование по $j=1,\ldots,n$ даёт требуемое равенство.
