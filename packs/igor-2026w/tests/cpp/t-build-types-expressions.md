## cpp-q-101
ticket: cpp-t-001 · level: L1
Какой командой получить только препроцессированный файл, а какой — объектный файл? Почему компоновщик не может исправить неизвестное имя переменной внутри функции?
### Эталон
- В GCC/Clang `-E` останавливает обработку после препроцессирования; `-c` компилирует и ассемблирует, но не выполняет компоновку.
- `undefined reference` означает, что компоновщик не нашёл определение символа, на которое есть ссылка.
- Неизвестное имя в выражении функции — ошибка поиска имени/семантической проверки на этапе компиляции, до компоновки.

## cpp-q-102
ticket: cpp-t-002 · level: L0
Что означает статическая типизация в C++? Укажите типы выражений `42`, `42u` и `true`.
### Эталон
- При статической типизации тип выражения известен и проверяется во время компиляции.
- Тип `42` — `int`; тип `42u` — `unsigned int`; тип `true` — `bool`.
- Суффикс `u` задаёт беззнаковый тип; без суффикса целочисленный десятичный литерал `42` имеет тип `int`.

## cpp-q-103
ticket: cpp-t-002 · level: L1
Какой тип и значение имеет `auto x = 1 + 0.5`? Объясните преобразование операндов перед сложением.
### Эталон
- `x` имеет тип `double`, значение — `1.5`.
- Перед сложением `int`-операнд `1` преобразуется к `double`, чтобы типы операндов совпадали.
- Результат арифметического выражения имеет тип `double`; `auto` выводит тип инициализирующего выражения.

## cpp-q-104
ticket: cpp-t-003 · level: L0
Чем объявление отличается от определения? Является ли `extern int count;` определением переменной?
### Эталон
- Объявление вводит имя и его свойства в программу; определение дополнительно создаёт сущность или задаёт её тело/хранилище.
- `extern int count;` без инициализатора — объявление переменной, не её определение.
- Определение `int count;` на уровне пространства имён создаёт объект с статической длительностью хранения и нулевой инициализацией.

## cpp-q-105
ticket: cpp-t-003 · level: L1
Что напечатает программа?
```cpp
#include <iostream>
int x = 1;
int main() {
    int x = 2;
    { int x = 3; std::cout << x; }
    std::cout << x;
}
```
### Эталон
- Вывод: `32`.
- Внутреннее объявление `x` скрывает одноимённую переменную внешнего блока в своей области видимости.
- После закрытия внутреннего блока снова видна локальная `x` со значением `2`; глобальная `x` не используется.

## cpp-q-106
ticket: cpp-t-004 · level: L1
Что выведет программа? Объясните разницу между префиксным и постфиксным инкрементом.
```cpp
#include <iostream>
int main() {
    int x = 3;
    std::cout << x++ << ' ' << ++x << ' ' << x;
}
```
### Эталон
- Вывод: `3 5 5`.
- Постфиксный `x++` даёт прежнее значение `3`, затем увеличивает `x` до `4`.
- Префиксный `++x` сначала увеличивает `x` до `5`, затем даёт ссылку на изменённый объект.
