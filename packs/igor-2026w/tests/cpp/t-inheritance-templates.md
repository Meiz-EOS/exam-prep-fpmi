## cpp-q-207
ticket: cpp-t-018 · level: L0
Что задаёт наследование? Как записывается публичное наследование и что означает `protected`?
### Эталон
- Наследование задаёт отношение производного класса к базовому и позволяет производному классу расширить или переопределить поведение базового.
- Синтаксис публичного наследования: `struct D : public B { };`.
- При публичном наследовании открытые члены `B` остаются открытыми в интерфейсе `D`, а защищённые остаются защищёнными.
- Член `protected` доступен членам класса и его производных классов, но не обычному внешнему коду.

## cpp-q-208
ticket: cpp-t-019 · level: L0
Различите приведение вверх и вниз в публичной иерархии классов. Что такое срезка?
### Эталон
- Приведение указателя или ссылки на производный объект к публичной базовой части выполняется неявно.
- Обратное приведение от базового к производному не выполняется неявно; `static_cast` допустим, но корректность фактического типа объекта должна быть обеспечена программой.
- Если объект действительно содержит соответствующий базовый подобъект целевого производного типа, обратный `static_cast` даёт указатель на этот объект.
- Если объект не является базовым подобъектом объекта целевого производного типа, поведение обратного `static_cast` указателя или ссылки неопределённое (UB).
- При копировании производного объекта в объект базового типа копируется только базовая часть — это срезка.

## cpp-q-209
ticket: cpp-t-019 · level: L1
Что выведет программа и что окажется в `b` после присваивания?
```cpp
#include <iostream>
struct B { int x = 1; };
struct D : B { int y = 2; };
int main() {
    D d;
    B* p = &d;
    B b = d;
    std::cout << p->x << ' ' << b.x;
}
```
### Эталон
- Вывод: `1 1`.
- `D*` неявно преобразуется в `B*`; `p` указывает на базовую часть `d`.
- При инициализации `b` копируется только подобъект `B`; поля `D::y` в `b` нет.

## cpp-q-210
ticket: cpp-t-020 · level: L0
Что такое шаблон функции и шаблон класса? Приведите синтаксис объявления каждого.
### Эталон
- Шаблон задаёт семейство функций или классов, параметры которого подставляются при инстанцировании.
- Шаблон функции объявляется, например, так: `template<class T> T identity(T x);`.
- Шаблон класса объявляется, например, так: `template<class T> struct Box { T value; };`.
- Компилятор инстанцирует специализацию при использовании с конкретными аргументами шаблона.

## cpp-q-211
ticket: cpp-t-020 · level: L1
Какой тип `T` выводится и что напечатает функция?
```cpp
#include <iostream>
template<class T>
T twice(T x) { return x + x; }
int main() { std::cout << twice(3); }
```
### Эталон
- Для вызова `twice(3)` выводится `T = int`, поскольку тип аргумента `3` — `int`.
- Инстанцируется функция с параметром и результатом типа `int`.
- Вывод: `6`.

## cpp-q-212
ticket: cpp-t-021 · level: L0
Что такое нетиповой параметр шаблона? Приведите пример с целым параметром.
### Эталон
- Нетиповой параметр шаблона — параметр, значением которого служит значение допустимого типа, а не тип.
- В C++20 аргумент нетипового параметра должен удовлетворять ограничениям стандарта для такого параметра; целочисленные константные выражения подходят.
- Пример: `template<std::size_t N> struct Array { int data[N]; };`.
- `Array<4>` и `Array<8>` — разные специализации шаблона.

## cpp-q-213
ticket: cpp-t-021 · level: L1
Скомпилируется ли `Array<3> a`? Каков размер массива `data`?
```cpp
#include <cstddef>
template<std::size_t N>
struct Array { int data[N]; };
int main() { Array<3> a{}; }
```
### Эталон
- Код компилируется в C++20: `3` является допустимым аргументом типа `std::size_t`.
- Инстанцируется `Array<3>` с полем `data` из трёх элементов `int`.
- `a.data` инициализируется нулями благодаря `a{}`.
