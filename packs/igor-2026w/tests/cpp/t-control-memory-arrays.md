## cpp-q-107
ticket: cpp-t-005 · level: L0
Что делает `continue` в цикле `for` и чем его действие отличается от `break`?
### Эталон
- `continue` прекращает текущую итерацию и переходит к следующей; в `for` перед этим выполняется выражение итерации.
- `break` завершает ближайший охватывающий цикл или `switch`.
- Ни одна из инструкций сама по себе не завершает функцию.

## cpp-q-108
ticket: cpp-t-005 · level: L1
Что выведет код?
```cpp
#include <iostream>
int main() {
    int i = 0;
    while (i < 5) {
        ++i;
        if (i == 2) continue;
        if (i == 4) break;
        std::cout << i;
    }
}
```
### Эталон
- Вывод: `13`.
- При `i == 2` выполнение переходит к проверке условия цикла, пропуская печать.
- При `i == 4` цикл завершается до печати; значения `1` и `3` печатаются.

## cpp-q-109
ticket: cpp-t-006 · level: L1
Какой тип имеет `x` и какое значение напечатает программа? Где здесь ловушка преобразования?
```cpp
#include <iostream>
int main() {
    unsigned int u = 0;
    int x = -1 < u;
    std::cout << x;
}
```
### Эталон
- Код компилируется; напечатает `0`.
- В сравнении `-1` преобразуется к `unsigned int`; его значение по модулю $2^N$ больше нуля, поэтому сравнение ложно.
- Ложное значение типа `bool` при инициализации `int` преобразуется в `0`.

## cpp-q-110
ticket: cpp-t-007 · level: L1
Какое значение выведет программа? Почему прибавление единицы допустимо, а разыменование результата — нет?
```cpp
#include <iostream>
int main() {
    int a[2] = {4, 9};
    int* end = a + 2;
    std::cout << (end - a);
}
```
### Эталон
- Вывод: `2`.
- Указатель на один элемент за концом массива допустимо получить и использовать в сравнении/разности в пределах того же массива.
- Разыменовывать такой указатель нельзя; это привело бы к неопределённому поведению.

## cpp-q-111
ticket: cpp-t-008 · level: L0
Какая длительность хранения у локальной переменной без `static`, у локальной `static` переменной и у объекта, созданного через `new`?
### Эталон
- У обычной локальной переменной автоматическая длительность хранения: время жизни связано с блоком.
- У локальной переменной `static` статическая длительность хранения: объект существует в течение выполнения программы.
- У динамически выделенного объекта длительность хранения динамическая; он живёт до освобождения или завершения программы.

## cpp-q-112
ticket: cpp-t-008 · level: L1
Что выведет программа при двух вызовах `next()`? Почему локальная переменная сохраняет значение?
```cpp
#include <iostream>
int next() {
    static int n = 0;
    return ++n;
}
int main() { std::cout << next() << next(); }
```
### Эталон
- Вывод: `12`.
- Инициализация локальной `static` переменной выполняется один раз; её время жизни продолжается до завершения программы.
- Первый вызов возвращает `1`, второй — `2`.

## cpp-q-113
ticket: cpp-t-009 · level: L1
Что произойдёт при выполнении кода? Укажите допустимое исправление.
```cpp
int main() {
    int* p = new int[3]{1, 2, 3};
    delete p;
}
```
### Эталон
- Выражение выделяет массив; освобождение через одиночный `delete` вместо `delete[]` даёт неопределённое поведение.
- Правильная пара — `new[]` и `delete[]`.
- Для этой последовательности допустимо заменить освобождение на `delete[] p;`.
