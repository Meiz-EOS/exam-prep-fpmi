## cpp-q-301
ticket: cpp-t-026 · level: L1
Какие структуры данных лежат в основе `std::vector`, `std::list`, `std::map` и `std::unordered_map`, каковы типичные сложности доступа или поиска и что происходит с итераторами при реаллокации `vector` или rehash `unordered_map`?
### Эталон
- `std::vector` — динамический непрерывный массив: индексирование $O(1)$, вставка в конец амортизированно $O(1)$, вставка в середину $O(n)$.
- `std::list` — двусвязный список: поиск по позиции $O(n)$, вставка/удаление по уже имеющемуся итератору $O(1)$.
- `std::map` обычно реализуется сбалансированным деревом: поиск, вставка и удаление $O(\log n)$; элементы упорядочены по ключу.
- `std::unordered_map` — хеш-таблица: поиск/вставка/удаление в среднем $O(1)$, в худшем случае $O(n)$; порядок элементов не задан.
- Реаллокация `std::vector` инвалидирует все его итераторы, указатели и ссылки на элементы; без реаллокации вставка может инвалидировать итераторы и ссылки начиная с позиции вставки.
- Rehash в `std::unordered_map` инвалидирует итераторы, но не ссылки и указатели на элементы.

## cpp-q-302
ticket: cpp-t-027 · level: L0
Перечислите категории итераторов от слабейшей к сильнейшей и назовите стандартную категорию итераторов `std::vector` и `std::list`.
### Эталон
- Категории: input, output, forward, bidirectional, random access; в C++20 также выделена более сильная contiguous-категория.
- Итераторы `std::vector` — random access; в C++20 они также contiguous.
- Итераторы `std::list` — bidirectional.
- Более сильная категория поддерживает операции слабейшей категории и дополнительные операции.

## cpp-q-303
ticket: cpp-t-028 · level: L0
Что делает `std::move`, и в чём различие `push_back` и `emplace_back` у `std::vector`?
### Эталон
- `std::move(x)` не перемещает ресурс сам: оно приводит выражение к xvalue, чтобы разрешить выбор перемещающей перегрузки.
- `push_back` добавляет переданный объект; `emplace_back` строит элемент непосредственно из переданных аргументов в хранилище контейнера.
- Перемещение возможно только если тип элемента и выбранный конструктор его поддерживают.
- Успешное перемещение не обещает, что исходный объект уничтожен; он остаётся в допустимом для типа состоянии.

## cpp-q-304
ticket: cpp-t-029 · level: L1
Что выведется и какой тип получит `y`? Укажите, как исправить объявление, чтобы `y` ссылался на `x`.
```cpp
#include <iostream>
int main() {
    int x = 4;
    auto y = x;
    auto& r = x;
    y = 9;
    r = 7;
    std::cout << x << ' ' << y;
}
```
### Эталон
- Вывод: `7 9`.
- `y` имеет тип `int` и является отдельной копией `x`.
- `r` имеет тип `int&` и ссылается на `x`, поэтому присваивание `r = 7` меняет `x`.
- Для ссылки при выводе типа нужно написать `auto& y = x` (либо `const auto&`, если нужна ссылка только для чтения).
