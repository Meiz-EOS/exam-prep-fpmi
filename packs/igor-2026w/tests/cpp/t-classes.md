## cpp-q-201
ticket: cpp-t-014 · level: L0
Что такое класс (структура) в C++? Назовите различия `class` и `struct` по умолчанию.
### Эталон
- Класс — пользовательский тип, объединяющий данные и функции-члены; объект класса имеет собственное состояние.
- У `class` доступ к членам и наследование по умолчанию `private`; у `struct` — `public`.
- В остальном `class` и `struct` в C++ имеют одинаковые возможности.

## cpp-q-202
ticket: cpp-t-014 · level: L1
Скомпилируется ли код? Объясните действие `.` и `->` и найдите нарушение доступа.
```cpp
struct Box {
private:
    int value = 3;
public:
    int get() const { return value; }
};
int main() {
    Box b;
    Box* p = &b;
    int x = b.value;
    int y = p->get();
}
```
### Эталон
- Код не компилируется: `value` — закрытый член, к нему нельзя обратиться из `main`.
- Для объекта `b` оператор `.` выбирает член объекта; для указателя `p` запись `p->get()` эквивалентна `(*p).get()`.
- Вызов `p->get()` разрешён, поскольку `get` открыт; он возвращает `3`.

## cpp-q-203
ticket: cpp-t-015 · level: L0
Дайте определения конструктора и деструктора. Когда компилятор не объявляет конструктор по умолчанию?
### Эталон
- Конструктор — специальная функция-член без типа результата, инициализирующая объект при создании.
- Деструктор — специальная функция-член `~T()`, вызываемая при завершении времени жизни объекта.
- Если класс объявляет любой собственный конструктор, компилятор не объявляет для него конструктор по умолчанию автоматически.
- Список инициализации задаёт непосредственную инициализацию членов; члены инициализируются в порядке объявления, независимо от порядка в списке.

## cpp-q-204
ticket: cpp-t-016 · level: L0
Сформулируйте правило трёх и объясните поверхностное и глубокое копирование.
### Эталон
- Правило трёх: классу, которому нужен собственный деструктор, обычно нужны также собственные копирующий конструктор и копирующее присваивание.
- Поверхностная копия копирует значения членов, в том числе адрес указателя, поэтому два объекта могут разделить один ресурс.
- Глубокая копия создаёт отдельный ресурс и копирует в него данные; объекты затем владеют разными ресурсами.
- В C++ копирующие операции могут быть неявно объявлены компилятором; наличие пользовательского деструктора само по себе не запрещает их генерацию.

## cpp-q-205
ticket: cpp-t-017 · level: L0
Что означает `const` у метода-члена? Что такое статический метод-член?
### Эталон
- Суффикс `const` у нестатического метода означает, что через его неявный объектный параметр нельзя менять обычные нестатические поля.
- Константный метод можно вызвать для константного объекта; неконстантный метод — нельзя.
- Статический метод принадлежит классу, а не отдельному объекту, и не имеет `this`.
- Статический метод непосредственно обращается к статическим членам; для доступа к нестатическому члену ему нужен объект.

## cpp-q-206
ticket: cpp-t-017 · level: L1
Какую перегрузку выберут два вызова? Почему тип объекта влияет на выбор?
```cpp
#include <iostream>
struct S {
    void f() { std::cout << "non-const"; }
    void f() const { std::cout << "const"; }
};
int main() {
    S s;
    const S cs{};
    s.f();
    std::cout << ' ';
    cs.f();
}
```
### Эталон
- Вывод: `non-const const`.
- Для неконстантного `s` лучше подходит неконстантная перегрузка.
- Для `const`-объекта `cs` доступна только константная перегрузка.
