## oktch-q-1405
ticket: oktch-t-048 · level: L2
Найдите функцию Мёбиуса частично упорядоченного множества $\langle\mathbb N,\le\rangle$ (для $x\le y$) и, применив обращение Мёбиуса для ЧУМ, выведите: из $g(y)=\sum_{x\le y}f(x)$ следует $f(1)=g(1)$ и $f(y)=g(y)-g(y-1)$ при $y\ge2$.
### Эталон
- Множество $\langle\mathbb N,\le\rangle$ локально конечно: у $y$ ровно $y$ предшественников; функция определяется рекурсией $\mu(x,x)=1$, $\mu(x,y)=-\sum_{x\le z<y}\mu(x,z)$ при $x<y$.
- При $y=x+1$: $\mu(x,x+1)=-\mu(x,x)=-1$.
- При $y=x+2$: $\mu(x,x+2)=-(\mu(x,x)+\mu(x,x+1))=-(1-1)=0$.
- Индукцией по $y-x$: если $y\ge x+2$, то в сумме $\sum_{x\le z<y}\mu(x,z)$ ненулевые слагаемые только $z=x,x+1$, дающие $1-1=0$; значит, $\mu(x,y)=0$.
- Общая формула обращения (б/д): $f(y)=\sum_{x\le y}\mu(x,y)g(x)$; в ней ненулевые только $\mu(y,y)=1$ и $\mu(y-1,y)=-1$ (если $y\ge2$).
- Получаем $f(y)=g(y)-g(y-1)$ при $y\ge2$ и $f(1)=g(1)$; проверка: $g(y)-g(y-1)=f(y)$ непосредственно из определения $g$.

## oktch-q-1406
ticket: oktch-t-049 · level: L2
Докажите, что на порядке делимости $\mu_{|}(1,n)=\mu(n)$ для каждого натурального $n$.
### Эталон
- Лемма: $\sum_{d\mid n}\mu(d)=0$ при $n>1$ (квадратсвободные делители по $\binom sk$ с $\mu=(-1)^k$ дают $(1-1)^s=0$); поэтому $\mu(n)=-\sum_{d\mid n,\ d<n}\mu(d)$ при $n>1$.
- База: $\mu_{|}(1,1)=1=\mu(1)$.
- Для $n>1$ рекурсия ЧУМа даёт $\mu_{|}(1,n)=-\sum_{d\mid n,\ d<n}\mu_{|}(1,d)$ (суммирование по $1\mid d\mid n$, $d\ne n$).
- Индукция по $n$: для всех собственных делителей $d<n$ верно $\mu_{|}(1,d)=\mu(d)$.
- Подставляем: $\mu_{|}(1,n)=-\sum_{d\mid n,\ d<n}\mu(d)$, и по лемме это равно $\mu(n)$.

## oktch-q-1407
ticket: oktch-t-050 · level: L2
Выведите общее решение рекуррентного соотношения второго порядка $a_{n+2}+c_1a_{n+1}+c_0a_n=0$ при двойном корне характеристического уравнения.
### Эталон
- Характеристический многочлен $P(x)=x^2+c_1x+c_0$ имеет двойной корень $\lambda$, поэтому $P(x)=(x-\lambda)^2$ и $c_1=-2\lambda$, $c_0=\lambda^2$. Для рекурсии второго порядка предполагается $c_0\ne0$, значит $\lambda\ne0$.
- Подставьте $a_n=(C_1n+C_2)\lambda^n$ в левую часть: после вынесения $\lambda^n$ получаем $C_1nP(\lambda)+C_2P(\lambda)+C_1(2\lambda^2+c_1\lambda)$.
- Здесь $P(\lambda)=0$ и $2\lambda^2+c_1\lambda=\lambda P'(\lambda)=0$, так что формула удовлетворяет рекурсии.
- Из $a_0=C_2$ и $a_1=(C_1+C_2)\lambda$ однозначно находятся $C_1,C_2$, поскольку $\lambda\ne0$. Каждая пара начальных условий задаёт ровно одно решение второго порядка, значит формула описывает все решения.
## oktch-q-1408
ticket: oktch-t-051 · level: L2
Докажите, что при различных корнях $\lambda_1,\lambda_2$ характеристического уравнения общее решение рекурсии второго порядка имеет вид $a_n=C_1\lambda_1^n+C_2\lambda_2^n$.
### Эталон
- Подстановка $a_n=\lambda^n$ в $a_{n+2}+c_1a_{n+1}+c_0a_n$ даёт $\lambda^nP(\lambda)$, где $P(x)=x^2+c_1x+c_0$; при $P(\lambda_i)=0$ обе последовательности $\lambda_i^n$ — решения.
- Рекурсия линейна и однородна, поэтому любая комбинация $C_1\lambda_1^n+C_2\lambda_2^n$ также решение.
- Для произвольного решения с начальными значениями $a_0,a_1$ константы ищем из системы $C_1+C_2=a_0$, $C_1\lambda_1+C_2\lambda_2=a_1$.
- Определитель системы равен $\lambda_2-\lambda_1\ne0$, поэтому $C_1,C_2$ существуют и единственны.
- Две последовательности, удовлетворяющие одной рекурсии второго порядка и совпадающие в $a_0,a_1$, совпадают целиком (каждый следующий член определён предыдущими); значит, найденная формула даёт все решения.

## oktch-q-1409
ticket: oktch-t-052 · level: L2
Докажите равенство числа разбиений $n$ на чётное и нечётное число различных положительных частей, если $n$ не является обобщённым пятиугольным числом.
### Эталон
- В произведении $\prod_{j\ge1}(1-x^j)$ выбор слагаемого $-x^j$ означает включение части $j$ в разбиение, а выбор $1$ — её отсутствие.
- Поэтому коэффициент при $x^n$ равен сумме $(-1)^t$ по разбиениям $n$ на $t$ различных частей.
- Эта сумма есть число разбиений с чётным числом частей минус число с нечётным.
- По теореме Эйлера коэффициент равен $0$, если $n$ не имеет вида $k(3k-1)/2$ или $k(3k+1)/2$ для целого $k\ge1$.
- Следовательно, при таком $n$ обеих чётностей разбиений поровну.
