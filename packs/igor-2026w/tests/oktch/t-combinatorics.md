## oktch-q-511
ticket: oktch-t-058 · level: L0
Сформулируйте одномерную теорему Эрдёша—Гинзбурга—Зива, общую постановку проблемы и контрпримеры при $d=1,2$.
### Эталон
- Для любых $2n-1$ целых чисел найдутся $n$, сумма которых делится на $n$.
- Общая постановка: найти наименьшее $N(n,d)$ такое, что среди любых $N$ векторов из $\mathbb Z^d$ найдутся $n$ с суммой, делящейся на $n$ покоординатно.
- $d=1$: $n-1$ нулей и $n-1$ единиц — $2n-2$ числа без такого поднабора, поэтому $N(n,1)=2n-1$.
- $d=2$: по $n-1$ копий пар $(0,0),(0,1),(1,0),(1,1)$ — $4n-4$ пары без такого поднабора, поэтому $N(n,2)\ge4n-3$.
- Для простого $p$: $\binom{2p-1}{p}\equiv1\pmod p$ и $\binom{2p-1-q}{p-q}\equiv0\pmod p$ при $1\le q<p$.

## oktch-q-512
ticket: oktch-t-058 · level: L1
Как устроена идея доказательства одномерной теоремы Эрдёша—Гинзбурга—Зива для простого модуля?
### Эталон
- Предполагают, что ни одно $p$-элементное подмножество из $2p-1$ чисел не имеет сумму $0$ по модулю простого $p$.
- Рассматривают $S=\sum_{|I|=p}(\sum_{i\in I}a_i)^{p-1}$. По малой теореме Ферма и $\binom{2p-1}{p}\equiv1\pmod p$ получаем $S\equiv1\pmod p$.
- После раскрытия $(\sum_{i\in I}a_i)^{p-1}$ каждый моном имеет вид $c\prod_{j\in J}a_j^{e_j}$, где $J$ — его носитель, $q=|J|\le p-1$, все $e_j>0$, а $c$ — мультиномиальный коэффициент. Этот моном входит ровно в те слагаемые, для которых $I$ содержит $J$, то есть с кратностью $\binom{2p-1-q}{p-q}$.
- Так как степень равна $p-1>0$, у каждого монома $q\ge1$; случая $q=0$ нет. Для всех возможных $1\le q\le p-1$ кратность делится на $p$ по теореме Люка: $\binom{2p-1-q}{p-q}\equiv0\pmod p$. Значит, каждый вклад в $S$ делится на $p$, поэтому $S\equiv0\pmod p$, что противоречит $S\equiv\binom{2p-1}{p}\equiv1\pmod p$.

## oktch-q-513
ticket: oktch-t-059 · level: L0
Сформулируйте теорему Кантора—Бернштейна.
### Эталон
- Если существуют инъекции $f:A\to B$ и $g:B\to A$, то существует биекция $A\to B$.
- Эквивалентно, взаимные вложения множеств влекут их равномощность.

## oktch-q-514
ticket: oktch-t-059 · level: L1
Опишите построение биекции в доказательстве теоремы Кантора—Бернштейна.
### Эталон
- Положим $A_0=A\setminus g(B)$ и $A_{n+1}=g(f(A_n))$, затем $C=\bigcup_{n\ge0}A_n$.
- На $C$ задают отображение $f$, а на $A\setminus C$ — отображение $g^{-1}$; на этой части каждый элемент лежит в образе $g$.
- Обе части переводятся в непересекающиеся части $B$, и отображение получается взаимно однозначным.
- Идея цепочек: стартующие вне $g(B)$ цепочки идут через $f$, остальные элементы сопоставляются обратным шагом $g^{-1}$.

## oktch-q-515
ticket: oktch-t-060 · level: L0
Сформулируйте принцип Дирихле и оценки для максимальной мощности семейства попарно неортогональных векторов из $\{-1,0,1\}^n$, указанные в программе.
### Эталон
- Если $N+1$ объектов распределены по $N$ ящикам, в некотором ящике находятся как минимум два объекта.
- Речь о множестве $V$ векторов из $\{-1,0,1\}^8$ ровно с четырьмя ненулевыми координатами: $|V|=\binom84\cdot2^4=1120$.
- Ищется наибольшая мощность $f$ подмножества $W\subseteq V$, в котором скалярное произведение любых двух векторов ненулевое.
- Оценки: $70\le f\le140$.

## oktch-q-516
ticket: oktch-t-060 · level: L1
Объясните схему применения принципа Дирихле для верхней оценки размера семейства попарно неортогональных векторов из $\{-1,0,1\}^n$.
### Эталон
- Все $1120$ векторов $V$ разбивают на $140$ ящиков по $8$ векторов так, что любые два вектора одного ящика ортогональны.
- Ящик: разбиение позиций на четвёрки $S,\bar S$ ($\binom84/2=35$ способов) и одна из $4$ групп по $4$ попарно ортогональных знаковых наборов; её наборы ставят на $S$ и на $\bar S$.
- Из каждого ящика в $W$ попадает не больше одного вектора, поэтому при $|W|\ge141$ по принципу Дирихле два вектора попали бы в один ящик и были бы ортогональны: $f\le140$.
- Нижняя оценка $70$ подтверждается явной конструкцией семейства; она не следует из принципа Дирихле.
- Оценки не утверждают точного значения максимума.

## oktch-q-517
ticket: oktch-t-061 · level: L0
Запишите формулу обращения Мёбиуса для сумм по делителям и поясните, как она применяется к циклическим словам.
### Эталон
- Если $g(n)=\sum_{d\mid n}f(d)$, то $f(n)=\sum_{d\mid n}\mu(n/d)g(d)$.
- Для циклических слов сначала выражают число слов с периодом, делящим $n$, как сумму чисел слов минимального периода по делителям.
- Обращение Мёбиуса выделяет число слов минимального периода $n$ из этой суммы.

## oktch-q-518
ticket: oktch-t-061 · level: L1
Выведите формулу для числа циклических слов длины $n$ над алфавитом из $q$ символов.
### Эталон
- Пусть $P(d)$ — число линейных слов длины $d$ минимального периода $d$. Тогда $q^n=\sum_{d\mid n}P(d)$.
- По обращению Мёбиуса $P(d)=\sum_{e\mid d}\mu(e)q^{d/e}$.
- Циклических классов минимального периода $d$ ровно $P(d)/d$, поскольку каждый такой класс содержит $d$ линейных слов.
- Итого $T_q(n)=\sum_{d\mid n}\frac1d\sum_{e\mid d}\mu(e)q^{d/e}$.

## oktch-q-519
ticket: oktch-t-062 · level: L0
Определите функцию Мёбиуса на частично упорядоченном множестве и сформулируйте сумму $\sum_{a\le z\le b}\mu(z,b)$.
### Эталон
- Для конечного интервала: $\mu(x,x)=1$, а при $x<y$ функция определяется рекурсией $\mu(x,y)=-\sum_{x\le z<y}\mu(x,z)$.
- Для $a\le b$: $\sum_{a\le z\le b}\mu(z,b)=1$ при $a=b$ и $0$ при $a<b$.

## oktch-q-520
ticket: oktch-t-062 · level: L1
Докажите формулу суммы $\sum_{a\le z\le b}\mu(z,b)$.
### Эталон
- При $a=b$ сумма состоит из одного слагаемого $\mu(b,b)=1$.
- На конечном частично упорядоченном множестве матрица ζ задана элементами $\zeta(x,y)=1$ при $x\le y$ и $0$ иначе. Она обратима как треугольная матрица, а её обратная — матрица Мёбиуса $M=(\mu(x,y))$.
- Из $\zeta M=I$ следует для $a\le b$: $\sum_{a\le z\le b}\mu(z,b)=\delta_{a,b}$.
- При $a<b$ правая часть равна $0$; при $a=b$ сумма равна $\mu(b,b)=1$.

## oktch-q-521
ticket: oktch-t-063 · level: L0
Сформулируйте обобщённую формулу обращения Мёбиуса на частично упорядоченном множестве.
### Эталон
- Для функций на конечных интервалах положим $g(x)=\sum_{y\le x}f(y)$.
- Тогда $f(x)=\sum_{y\le x}g(y)\mu(y,x)$.
- Здесь $\mu$ — функция Мёбиуса частичного порядка; суммы берутся по интервалу, влияющему на значение в $x$.

## oktch-q-522
ticket: oktch-t-063 · level: L1
Примените обобщённое обращение Мёбиуса на множестве делителей числа $6$: если $g(d)=\sum_{e\mid d}f(e)$ и значения $g(1)=2$, $g(2)=5$, $g(3)=7$, $g(6)=20$, найдите $f(6)$.
### Эталон
- Для порядка делимости формула имеет вид $f(6)=\sum_{d\mid6}g(d)\mu(d,6)$.
- На интервале делителей $6$: $\mu(1,6)=1$, $\mu(2,6)=-1$, $\mu(3,6)=-1$, $\mu(6,6)=1$.
- Поэтому $f(6)=2-5-7+20=10$.
