## oktch-q-409
ticket: oktch-t-044 · level: L0
Запишите формулу Эйлера для $\varphi(n)$ через различные простые делители $n$.
### Эталон
- Если различные простые делители $n$ равны $p_1,\ldots,p_s$, то $\varphi(n)=n\prod_{i=1}^{s}(1-1/p_i)$.
- Эквивалентно, $\varphi(n)=n\prod_{p\mid n}(1-1/p)$, где произведение по простым $p$.
## oktch-q-410
ticket: oktch-t-044 · level: L1
Докажите формулу включений-исключений для трёх множеств проверкой по принадлежности элемента.
### Эталон
- Элемент, входящий ровно в одно множество, учитывается один раз.
- Элемент, входящий ровно в два множества, учитывается как $2-1=1$.
- Элемент, входящий во все три, учитывается как $3-3+1=1$.
- Не принадлежащий объединению элемент не входит ни в один член; значит правая часть считает каждый элемент объединения ровно один раз.
## oktch-q-411
ticket: oktch-t-045 · level: L0
Сформулируйте формулу обращения Мёбиуса для делимости.
### Эталон
- Если $g(n)=\sum_{d\mid n}f(d)$, то $f(n)=\sum_{d\mid n}\mu(n/d)g(d)$.
- Эквивалентно, $f(n)=\sum_{d\mid n}\mu(d)g(n/d)$.
- Здесь $\mu$ — арифметическая функция Мёбиуса.
## oktch-q-412
ticket: oktch-t-045 · level: L1
Объясните, почему формула обращения Мёбиуса восстанавливает $f$ из $g$.
### Эталон
- Подставьте $g(d)=\sum_{e\mid d}f(e)$ в предполагаемую формулу для $f(n)$.
- Перегруппировка по $e\mid n$ даёт коэффициент $\sum_{r\mid n/e}\mu(r)$ при $f(e)$.
- Этот коэффициент равен $1$ при $e=n$ и $0$ при $e<n$, поскольку сумма $\mu$ по делителям равна индикатору единицы.
- Остаётся ровно $f(n)$.
## oktch-q-413
ticket: oktch-t-046 · level: L0
Определите функцию Эйлера $\varphi(n)$.
### Эталон
- $\varphi(n)$ — число целых $a$ от $1$ до $n$, взаимно простых с $n$.
- В частности, $\varphi(1)=1$; для $n>1$ это число обратимых классов вычетов по модулю $n$.
## oktch-q-414
ticket: oktch-t-046 · level: L1
Выведите произведение для $\varphi(n)$ формулой включений-исключений.
### Эталон
- Среди $1,\ldots,n$ исключаются числа, делящиеся хотя бы на один простой делитель $p_i$ числа $n$.
- Чисел, делящихся на произведение простых из набора $J$, ровно $n/\prod_{i\in J}p_i$.
- Включения-исключения дают $n\sum_{J\subseteq\{1,\ldots,s\}}(-1)^{|J|}/\prod_{i\in J}p_i$.
- Раскрытие произведения превращает сумму в $n\prod_i(1-1/p_i)$.
## oktch-q-415
ticket: oktch-t-047 · level: L0
Определите циклический сдвиг и период линейной последовательности длины $n$; запишите частные случаи формулы числа циклических слов.
### Эталон
- Циклический сдвиг переносит последний символ в начало; повторные сдвиги задают циклическое слово.
- Период — наименьшее положительное число сдвигов, возвращающее последовательность к исходной; период делит $n$.
- Для алфавита мощности $q$: $T(n,q)=\frac1n\sum_{d\mid n}\varphi(d)q^{n/d}$.
- При $n=3,4,5,6$ соответственно: $\frac{q^3+2q}{3}$, $\frac{q^4+q^2+2q}{4}$, $\frac{q^5+4q}{5}$, $\frac{q^6+q^3+2q^2+2q}{6}$.
## oktch-q-416
ticket: oktch-t-047 · level: L1
Как получить формулу числа циклических слов через фиксированные точки сдвигов?
### Эталон
- Рассмотрите действие циклической группы сдвигов на $q^n$ линейных слов.
- По лемме Бёрнсайда число орбит равно среднему числу слов, фиксируемых каждым сдвигом.
- Сдвиг на $r$ позиций фиксирует $q^{\gcd(n,r)}$ слов, поскольку символы постоянны на циклах перестановки позиций.
- Группировка сдвигов по порядку приводит к $\frac1n\sum_{d\mid n}\varphi(d)q^{n/d}$.
