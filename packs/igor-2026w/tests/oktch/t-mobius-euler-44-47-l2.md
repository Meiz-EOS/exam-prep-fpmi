## oktch-q-1401
ticket: oktch-t-044 · level: L2
Докажите формулу включений-исключений для трёх конечных множеств и выведите из неё (в общей форме для $s$ множеств) формулу $\varphi(n)=n\prod_{p\mid n}(1-1/p)$.
### Эталон
- Для $x\in A_1\cup A_2\cup A_3$ пусть $r\in\{1,2,3\}$ — число множеств, содержащих $x$; в правой части $x$ даёт вклад $\binom r1-\binom r2+\binom r3$, а $x$ вне объединения не даёт вклада ни в одну часть.
- При $r=1,2,3$ вклад равен $1$, $2-1=1$, $3-3+1=1$, то есть каждый элемент объединения учтён ровно один раз: $|A_1\cup A_2\cup A_3|=\sum|A_i|-\sum_{i<j}|A_i\cap A_j|+|A_1\cap A_2\cap A_3|$.
- Тот же подсчёт для $s$ множеств: вклад элемента с $r\ge1$ равен $\sum_{j=1}^r(-1)^{j+1}\binom rj=1-(1-1)^r=1$, это даёт общую формулу включений-исключений.
- Пусть $p_1,\ldots,p_s$ — различные простые делители $n$, $A_i\subseteq\{1,\ldots,n\}$ — числа, делящиеся на $p_i$. Тогда $\varphi(n)=n-|A_1\cup\cdots\cup A_s|$ (числа, не делящиеся ни на один $p_i$, взаимно просты с $n$).
- Для набора $J$ индексов $|\bigcap_{i\in J}A_i|=n/\prod_{i\in J}p_i$, так как простые различны и все делят $n$ (числа, делящиеся на $\prod_{i\in J}p_i$).
- Включения-исключения дают $\varphi(n)=n\sum_{J\subseteq\{1,\ldots,s\}}(-1)^{|J|}/\prod_{i\in J}p_i$; раскрытие скобок в $\prod_i(1-1/p_i)$ даёт ровно эту сумму, поэтому $\varphi(n)=n\prod_{p\mid n}(1-1/p)$.

## oktch-q-1402
ticket: oktch-t-045 · level: L2
Докажите формулу обращения Мёбиуса: если $g(n)=\sum_{d\mid n}f(d)$, то $f(n)=\sum_{d\mid n}\mu(d)g(n/d)$.
### Эталон
- Лемма: $\sum_{d\mid m}\mu(d)=1$ при $m=1$ и $0$ при $m>1$. Доказательство: при $m=p_1^{\alpha_1}\cdots p_s^{\alpha_s}$ ненулевой вклад дают только квадратсвободные $d$, их ровно $\binom sk$ с $k$ простыми и $\mu=(-1)^k$, сумма равна $(1-1)^s=0$ при $s\ge1$.
- Подставляем определение $g(n/d)$ в правую часть: $\sum_{d\mid n}\mu(d)\sum_{e\mid n/d}f(e)$.
- Это сумма по парам $(d,e)$ с $d\mid n$, $e\mid n/d$, то есть с $de\mid n$; конечная, поэтому порядок суммирования можно менять.
- Группируем по $e$: коэффициент при $f(e)$ равен $\sum_{d\mid n/e}\mu(d)$.
- По лемме он равен $1$ при $n/e=1$ и $0$ при $e<n$.
- Остаётся одно слагаемое: вся сумма равна $f(n)$.

## oktch-q-1403
ticket: oktch-t-046 · level: L2
Выведите формулу $\varphi(n)=n\prod_{p\mid n}(1-1/p)$ с помощью формулы обращения Мёбиуса.
### Эталон
- Докажите $\sum_{d\mid n}\varphi(d)=n$: числа $a\in\{1,\ldots,n\}$ разбиваются по $\gcd(a,n)=n/d$ для $d\mid n$.
- Числа с $\gcd(a,n)=n/d$ — это $a=(n/d)b$ с $1\le b\le d$, $\gcd(b,d)=1$; их ровно $\varphi(d)$, поэтому сумма по $d\mid n$ равна $n$.
- Применяем обращение Мёбиуса к $g(n)=n$, $f=\varphi$: $\varphi(n)=\sum_{d\mid n}\mu(d)\,n/d=n\sum_{d\mid n}\mu(d)/d$.
- Слагаемые с $\mu(d)=0$ (не квадратсвободные $d$) отбрасываем; остаются $d=\prod_{p\in J}p$ для подмножеств $J$ простых делителей $n$, где $\mu(d)=(-1)^{|J|}$.
- Получаем $\sum_{d\mid n}\mu(d)/d=\sum_J\prod_{p\in J}(-1/p)$.
- Раскрытие скобок даёт $\prod_{p\mid n}(1-1/p)$, откуда $\varphi(n)=n\prod_{p\mid n}(1-1/p)$.

## oktch-q-1404
ticket: oktch-t-047 · level: L2
Выведите явные формулы числа $T_q(n)$ циклических последовательностей длины $n$ в алфавите из $q$ букв для $n=3,4,5,6$ (свойства периода можно использовать без доказательства).
### Эталон
- Период слова длины $n$ делит $n$, а слово периода $d$ — это $n/d$ повторений блока длины $d$, имеющего период ровно $d$ (свойства периода, б/д).
- Пусть $M(d)$ — число циклических слов, получаемых зацикливанием слов длины $d$ периода ровно $d$; каждое склеивает ровно $d$ линейных слов. Разбивая $q^n$ слов по периодам: $q^n=\sum_{d\mid n}d\,M(d)$.
- Обращение Мёбиуса с $g(n)=q^n$, $f(d)=dM(d)$: $M(n)=\frac1n\sum_{d\mid n}\mu(d)q^{n/d}$; а $T_q(n)=\sum_{d\mid n}M(d)$, так как циклическое слово определяется периодом и блоком.
- $n=3$: $M(1)=q$, $M(3)=(q^3-q)/3$; $T_q(3)=(q^3+2q)/3$. $n=5$: $M(5)=(q^5-q)/5$; $T_q(5)=(q^5+4q)/5$.
- $n=4$: $M(2)=(q^2-q)/2$, $M(4)=(q^4-q^2)/4$; $T_q(4)=q+\frac{q^2-q}2+\frac{q^4-q^2}4=(q^4+q^2+2q)/4$.
- $n=6$: $M(2)=(q^2-q)/2$, $M(3)=(q^3-q)/3$, $M(6)=(q^6-q^3-q^2+q)/6$; сумма с $M(1)=q$ равна $T_q(6)=(q^6+q^3+2q^2+2q)/6$.
