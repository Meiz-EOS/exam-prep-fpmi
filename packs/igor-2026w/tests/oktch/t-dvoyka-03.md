## oktch-q-711
ticket: oktch-t-d31 · level: L0
Пусть линейное слово длины $n$ составлено из символов одного алфавита. Определите его период как наименьшее положительное число циклических сдвигов, после которых слово совпадает с исходным, и сформулируйте связь периода с $n$.
### Эталон
- Период — наименьшее положительное число циклических сдвигов, после которых последовательность совпадает с исходной.
- Период делит длину $n$ последовательности.

## oktch-q-712
ticket: oktch-t-d34 · level: L0
Сколько существует разбиений числа $n$ на положительные слагаемые с учётом порядка при $n\ge1$?
### Эталон
- Каждое разбиение задаётся выбором, ставить ли разделитель в каждом из $n-1$ промежутков между единицами.
- Число упорядоченных разбиений равно $2^{n-1}$.
