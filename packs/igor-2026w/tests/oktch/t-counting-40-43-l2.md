## oktch-q-1309
ticket: oktch-t-040 · level: L2
Докажите, что для любых $15$ пятиэлементных подмножеств $M_1,\ldots,M_{15}\subseteq\{1,\ldots,n\}$ существует раскраска чисел в два цвета, при которой ни одно $M_i$ не одноцветно.
### Эталон
- Для каждого $M_i$ обозначим через $\mathcal M_i$ множество раскрасок, в которых $M_i$ одноцветно.
- Общий цвет пятёрки выбирается двумя способами, остальные $n-5$ элементов красятся произвольно, поэтому $|\mathcal M_i|=2\cdot2^{n-5}=2^{n-4}$.
- Плохие раскраски образуют объединение $\bigcup_{i=1}^{15}\mathcal M_i$; мощность объединения не превосходит суммы мощностей: $|\bigcup_i\mathcal M_i|\le15\cdot2^{n-4}$.
- Имеем $15\cdot2^{n-4}<16\cdot2^{n-4}=2^n$, а всего раскрасок $2^n$.
- Значит, существует раскраска вне объединения, в которой ни одно из заданных множеств не одноцветно.

## oktch-q-1310
ticket: oktch-t-041 · level: L2
Докажите для каждого фиксированного $k\ge0$, что $S_k(n)=\sum_{j=1}^n j^k$ — многочлен от $n$ степени $k+1$ со старшим коэффициентом $1/(k+1)$.
### Эталон
- Сильная индукция по $k$; база $k=0$: $S_0(n)=n$ имеет степень $1$ и старший коэффициент $1$.
- Из бинома $(j+1)^{k+1}-j^{k+1}=\sum_{r=0}^{k}\binom{k+1}{r}j^r$; суммируя по $j=1,\ldots,n$, слева получаем телескопическую сумму $(n+1)^{k+1}-1$, справа $\sum_{r=0}^{k}\binom{k+1}{r}S_r(n)$.
- Выделив слагаемое $r=k$, имеем $(k+1)S_k(n)=(n+1)^{k+1}-1-\sum_{r=0}^{k-1}\binom{k+1}{r}S_r(n)$.
- По предположению индукции $S_r$ при $r<k$ — многочлен степени $r+1\le k$, поэтому вычитаемая сумма — многочлен степени не выше $k$.
- Многочлен $(n+1)^{k+1}-1$ имеет степень $k+1$ и старший коэффициент $1$.
- Делим на $k+1\ne0$: $S_k(n)$ — многочлен степени $k+1$ со старшим коэффициентом $1/(k+1)$.

## oktch-q-1311
ticket: oktch-t-042 · level: L2
Докажите тождество $\sum_{j=0}^n(-1)^j\binom nj=0$ при $n\ge1$ и докажите, что число сюръекций $n$-элементного множества на $k$-элементное равно $\sum_{j=0}^k(-1)^j\binom kj(k-j)^n$.
### Эталон
- Первое тождество получается из бинома: $0=(1-1)^n=\sum_{j=0}^n\binom nj(-1)^j$ при $n\ge1$ (при $n=0$ сумма равна $1$).
- Для второго зафиксируем отображения из $n$-элементного множества в $k$-элементное $K$ (их $k^n$) и обозначим $E_i$ свойство «$i$-й элемент $K$ не принадлежит образу».
- Для набора из $j$ свойств отображение принимает значения лишь в оставшихся $k-j$ элементах, таких отображений $(k-j)^n$, а набор выбирается $\binom kj$ способами.
- По формуле включений-исключений число отображений, не обладающих ни одним свойством $E_i$, равно $\sum_{j=0}^k(-1)^j\binom kj(k-j)^n$.
- Не обладать ни одним $E_i$ означает, что каждый элемент $K$ лежит в образе, то есть отображение — сюръекция; формула доказана (при $n<k$ сумма равна $0$).

## oktch-q-1312
ticket: oktch-t-043 · level: L2
Докажите формулу включений и исключений: для $N$ объектов и свойств $\alpha_1,\ldots,\alpha_n$ число объектов, не обладающих ни одним из свойств, равно $N-\sum_iN(\alpha_i)+\sum_{i<j}N(\alpha_i\alpha_j)-\cdots+(-1)^nN(\alpha_1\ldots\alpha_n)$.
### Эталон
- Индукция по числу свойств $n$ для любых наборов объектов и любых $n$ свойств. База $n=1$: $N(\bar\alpha_1)=N-N(\alpha_1)$.
- Шаг: для свойств $\alpha_1,\ldots,\alpha_{n+1}$ применим предположение ко всем $N$ объектам и свойствам $\alpha_1,\ldots,\alpha_n$; получим формулу (1) для $N(\bar\alpha_1\ldots\bar\alpha_n)$.
- Применим предположение только к $N(\alpha_{n+1})$ объектам со свойством $\alpha_{n+1}$ и тем же $\alpha_1,\ldots,\alpha_n$; число среди них обладающих $\alpha_i$ равно $N(\alpha_i\alpha_{n+1})$, поэтому формула (2) для $N(\bar\alpha_1\ldots\bar\alpha_n\alpha_{n+1})$ имеет вид $N(\alpha_{n+1})-\sum_{i\le n}N(\alpha_i\alpha_{n+1})+\cdots+(-1)^nN(\alpha_1\ldots\alpha_{n+1})$.
- Вычтем (2) из (1): слева остаются объекты, не обладающие ни одним из $n+1$ свойств, то есть $N(\bar\alpha_1\ldots\bar\alpha_{n+1})$.
- Справа набор свойств без $\alpha_{n+1}$ остаётся со знаком $(-1)^{s}$, а набор из $s$ свойств с $\alpha_{n+1}$ входит из (2) со знаком $(-1)^{s-1}$ и после вычитания получает знак $(-1)^{s}$; получаются все наборы из $n+1$ свойств.
- Это формула для $n+1$ свойства; в форме множеств ($\alpha_i$ — принадлежность $A_i$) получаем $|A_1\cup\cdots\cup A_n|=N-N(\bar\alpha_1\ldots\bar\alpha_n)$.
