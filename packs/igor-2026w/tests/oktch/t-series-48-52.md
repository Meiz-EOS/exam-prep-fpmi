## oktch-q-417
ticket: oktch-t-048 · level: L0
Определите функцию Мёбиуса на частично упорядоченном множестве и запишите общую формулу обращения.
### Эталон
- Предполагается, что для каждого $y$ нижнее множество $\{x:x\le y\}$ конечно. Тогда $\mu(x,x)=1$.
- При $x<y$: $\mu(x,y)=-\sum_{x\le z<y}\mu(x,z)$.
- Если $g(y)=\sum_{x\le y}f(x)$, то $f(y)=\sum_{x\le y}\mu(x,y)g(x)$.
- В программе общая формула обращения дана без доказательства.
## oktch-q-418
ticket: oktch-t-048 · level: L1
Вычислите функцию Мёбиуса для цепи $1<2<3$ и примените обращение к $g(y)=\sum_{x\le y}f(x)$.
### Эталон
- Рекурсия даёт $\mu(1,1)=\mu(2,2)=\mu(3,3)=1$.
- Для соседних элементов $\mu(1,2)=\mu(2,3)=-1$.
- $\mu(1,3)=-\bigl(\mu(1,1)+\mu(1,2)\bigr)=0$.
- Поэтому $f(1)=g(1)$, $f(2)=g(2)-g(1)$, $f(3)=g(3)-g(2)$.
## oktch-q-419
ticket: oktch-t-049 · level: L0
Сформулируйте связь функции Мёбиуса на порядке делимости с арифметической функцией Мёбиуса.
### Эталон
- На порядке делимости натуральных чисел $\mu_{|}(a,b)$ определена при $a\mid b$.
- Для всех $n\ge1$: $\mu_{|}(1,n)=\mu(n)$.
- Общая формула обращения для частичного порядка в программе формулируется без доказательства.
## oktch-q-420
ticket: oktch-t-049 · level: L1
Объясните механизм совпадения $\mu_{|}(1,n)=\mu(n)$.
### Эталон
- По рекурсии на порядке делимости, $\mu_{|}(1,1)=1$ и при $n>1$: $\mu_{|}(1,n)=-\sum_{d\mid n,\ d<n}\mu_{|}(1,d)$.
- Арифметическая функция Мёбиуса удовлетворяет той же рекурсии, поскольку $\sum_{d\mid n}\mu(d)=0$ при $n>1$.
- Индукция по $n$ даёт равенство для всех натуральных $n$.
## oktch-q-421
ticket: oktch-t-050 · level: L0
Определите линейное рекуррентное соотношение с постоянными коэффициентами и характеристическое уравнение.
### Эталон
- Рекурсия порядка $r$ имеет вид $a_{n+r}+c_{r-1}a_{n+r-1}+\cdots+c_0a_n=0$ с постоянными коэффициентами.
- Её характеристическое уравнение: $\lambda^r+c_{r-1}\lambda^{r-1}+\cdots+c_0=0$.
- Корни уравнения определяют вид формулы общего решения.
## oktch-q-422
ticket: oktch-t-050 · level: L1
Запишите общий вид решения рекурсии второго порядка при двойном характеристическом корне и объясните, как определить константы по начальным условиям.
### Эталон
- При двойном корне $\lambda$ общее решение имеет вид $a_n=(C_1+C_2n)\lambda^n$.
- Константы $C_1,C_2$ задаются начальными условиями.
- Подстановка двух начальных значений в $a_n=(C_1+C_2n)\lambda^n$ даёт систему для $C_1,C_2$.
## oktch-q-423
ticket: oktch-t-051 · level: L0
Запишите общий вид решения рекурсии второго порядка при различных характеристических корнях.
### Эталон
- При различных корнях $\lambda_1,\lambda_2$ решение имеет вид $a_n=C_1\lambda_1^n+C_2\lambda_2^n$.
- $C_1,C_2$ определяются двумя начальными условиями.
## oktch-q-424
ticket: oktch-t-051 · level: L1
Почему степени корней характеристического уравнения дают решение рекурсии второго порядка?
### Эталон
- Подстановка пробного решения $a_n=\lambda^n$ в рекурсию приводит к характеристическому уравнению.
- При двух различных корнях последовательности $\lambda_1^n$ и $\lambda_2^n$ линейно независимы.
- Их линейные комбинации образуют все решения: два начальных значения однозначно задают решение второго порядка.
## oktch-q-425
ticket: oktch-t-052 · level: L0
Запишите формальный степенной ряд из билета и сформулируйте теорему Эйлера о его коэффициентах и равенство числа разбиений на чётное и нечётное число различных частей.
### Эталон
- $\prod_{j\ge1}(1-x^j)=\sum_{n\ge0}a_nx^n$; коэффициент $a_n$ равен разности числа разбиений $n$ на чётное и нечётное число различных положительных слагаемых.
- Теорема Эйлера: $a_n=(-1)^k$, если $n=(3k^2-k)/2$ или $n=(3k^2+k)/2$ для некоторого $k\ge1$; во всех остальных случаях $a_n=0$ (также $a_0=1$).
- В частности, числа разбиений на чётное и нечётное число различных частей равны, если $n$ не является обобщённым пятиугольным числом.
## oktch-q-426
ticket: oktch-t-052 · level: L1
Как проверить теорему Эйлера о коэффициентах произведения для $k=1,2$?
### Эталон
- Для первых двух значений параметра в теореме получаются степени $1,2$ со знаком $-1$ и $5,7$ со знаком $+1$.
- При раскрытии произведения до степени $7$ получаем $\prod_{j\ge1}(1-x^j)=1-x-x^2+x^5+x^7+O(x^8)$.
- Степени $1,2,5,7$ совпадают с $k(3k-1)/2$ и $k(3k+1)/2$ при $k=1,2$.
- При подсчёте разбиений это также даёт равенство количеств чётных и нечётных разбиений для $n=4$.
