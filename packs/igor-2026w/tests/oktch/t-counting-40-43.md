## oktch-q-401
ticket: oktch-t-040 · level: L0
Сформулируйте теорему о раскраске множества в два цвета из лекции (15 пятиэлементных подмножеств).
### Эталон
- В $\{1,\ldots,n\}$ выбраны произвольные $15$ пятиэлементных подмножеств $M_1,\ldots,M_{15}$.
- Тогда числа $1,\ldots,n$ можно раскрасить в два цвета так, что ни одно $M_i$ не одноцветно.
- Утверждение верно и для $16$ подмножеств.

## oktch-q-402
ticket: oktch-t-040 · level: L1
Изложите идею доказательства теоремы о раскраске: для любых $15$ пятиэлементных подмножеств $\{1,\ldots,n\}$ есть раскраска в два цвета без одноцветных подмножеств.
### Эталон
- Пусть $\mathcal M_i$ — множество раскрасок, в которых $M_i$ одноцветно: $|\mathcal M_i|=2\cdot2^{n-5}=2^{n-4}$.
- «Плохие» раскраски — это $\bigcup_i\mathcal M_i$, и $\left|\bigcup_i\mathcal M_i\right|\le\sum_i|\mathcal M_i|=15\cdot2^{n-4}<2^n$.
- Всего раскрасок $2^n$, плохих меньше, значит, хорошая существует.
- Для $16$ множеств оценка суммой строгая: раскраска «всё красное» лежит во всех $\mathcal M_i$, поэтому $\left|\bigcup\mathcal M_i\right|<16\cdot2^{n-4}=2^n$.

## oktch-q-403
ticket: oktch-t-041 · level: L0
Запишите формулу суммы $k$-х степеней первых $n$ натуральных чисел.
### Эталон
- Для фиксированного целого $k\ge0$ сумма $S_k(n)=\sum_{j=1}^{n}j^k$ является многочленом от $n$ степени $k+1$.
- Его старший член равен $n^{k+1}/(k+1)$.
- При $k=1$: $S_1(n)=n(n+1)/2$; при $k=2$: $S_2(n)=n(n+1)(2n+1)/6$.
## oktch-q-404
ticket: oktch-t-041 · level: L1
Опишите индуктивный способ получить формулу для суммы $k$-х степеней.
### Эталон
- Просуммировать тождество $(j+1)^{k+1}-j^{k+1}=\sum_{r=0}^{k}\binom{k+1}{r}j^r$ по $j=1,\ldots,n$.
- Левая часть телескопируется и выражается через $(n+1)^{k+1}$ и константу.
- Получается линейное уравнение для $S_k(n)$ через суммы меньших степеней; их формулы подставляются последовательно.
- Из сравнения старших членов следует коэффициент $1/(k+1)$ при $n^{k+1}$.
## oktch-q-405
ticket: oktch-t-042 · level: L0
Запишите два знакопеременных тождества программы: для суммы биномиальных коэффициентов и для числа сюръекций.
### Эталон
- При $n\ge1$: $\sum_{j=0}^{n}(-1)^j\binom nj=0$.
- Число сюръекций из $n$-элементного множества в $k$-элементное равно $\sum_{j=0}^{k}(-1)^j\binom kj(k-j)^n$.
- В частности, при $n<k$ эта знакопеременная сумма равна $0$, а при $n=k$ равна $k!$.

## oktch-q-406
ticket: oktch-t-042 · level: L1
Объясните знаки в формуле включений-исключений для числа сюръекций.
### Эталон
- Для каждого элемента целевого множества рассмотрите событие, что он не попал в образ.
- Пересечение событий для фиксированного набора из $j$ элементов означает, что образ лежит в оставшихся $k-j$ элементах; таких отображений $(k-j)^n$.
- Включения-исключения дают сумму $\sum_{j=0}^{k}(-1)^j\binom kj(k-j)^n$.
- Для суммы биномиальных коэффициентов разложение $(1+1)^n$ даёт $2^n$, а $(1-1)^n$ — знакопеременную сумму.
## oktch-q-407
ticket: oktch-t-043 · level: L0
Сформулируйте формулу включений-исключений для конечных множеств $A_1,\ldots,A_n$.
### Эталон
- $|A_1\cup\cdots\cup A_n|=\sum_{\varnothing\ne J\subseteq[n]}(-1)^{|J|+1}|\bigcap_{j\in J}A_j|=\sum_i|A_i|-\sum_{i<j}|A_i\cap A_j|+\cdots+(-1)^{n+1}|A_1\cap\cdots\cap A_n|$.
- Пересечения $k$ множеств входят со знаком $(-1)^{k+1}$: нечётные $k$ — с плюсом, чётные — с минусом.
## oktch-q-408
ticket: oktch-t-043 · level: L1
Почему формула включений-исключений даёт верный коэффициент для каждого элемента объединения?
### Эталон
- Зафиксируйте элемент, принадлежащий ровно $r\ge1$ из множеств.
- В правой части он учитывается с коэффициентом $\sum_{j=1}^{r}(-1)^{j+1}\binom rj$.
- По биному Ньютона этот коэффициент равен $1-(1-1)^r=1$.
- Элемент вне объединения не входит ни в одно слагаемое и получает коэффициент $0$.
