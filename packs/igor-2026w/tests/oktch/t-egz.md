## oktch-q-611
ticket: oktch-t-069 · level: L0
Сформулируйте одномерную теорему Эрдёша–Гинзбурга–Зива для простого $p$.
### Эталон
- Среди любых $2p-1$ целых чисел найдутся $p$ чисел, сумма которых делится на $p$.
- В доказательстве используют сравнения $\binom{2p-1}{p}\equiv1\pmod p$ и $\binom{2p-1-q}{p-q}\equiv0\pmod p$ при $1\le q<p$; эти сравнения можно считать известными.

## oktch-q-612
ticket: oktch-t-069 · level: L1
Опишите идею доказательства одномерной теоремы Эрдёша–Гинзбурга–Зива для $n=p$.
### Эталон
- Рассматривают сумму $S=\sum_{|I|=p}(\sum_{i\in I}a_i)^{p-1}$ по модулю $p$.
- Предположение об отсутствии нужного подмножества и малая теорема Ферма дают $S\equiv\binom{2p-1}{p}\equiv1\pmod p$.
- После раскрытия степеней группируют слагаемые по множеству индексов с положительными степенями; для фиксированных $q$ индексов кратность равна $\binom{2p-1-q}{p-q}\equiv0\pmod p$.
- Значит, $S\equiv0\pmod p$, противоречие. Сравнения для биномиальных коэффициентов в программе разрешено использовать без доказательства.

## oktch-q-613
ticket: oktch-t-070 · level: L0
Сформулируйте проблему Эрдёша–Гинзбурга–Зива для $d=2$, приведите указанный в программе контрпример и назовите итог решения для плоскости.
### Эталон
- Вопрос состоит в наименьшем числе элементов $\mathbb Z^2$, гарантирующем $n$ элементов с суммой, делящейся на $n$ покоординатно.
- Для $n-1$ копий каждой из пар $(0,0),(0,1),(1,0),(1,1)$ всего $4n-4$ пар, и никакие $n$ из них не имеют сумму, делящуюся на $n$ покоординатно.
- Теорема Роньяи (решение гипотезы Кемница): среди любых $4n-3$ пар из $\mathbb Z^2$ найдутся $n$ с суммой, делящейся на $n$ покоординатно.

## oktch-q-614
ticket: oktch-t-070 · level: L1
Почему приведённый набор из $4n-4$ пар в $\mathbb Z^2$ не содержит $n$ пар с суммой, делящейся на $n$ покоординатно?
### Эталон
- В каждой из четырёх клеток $(0,0),(0,1),(1,0),(1,1)$ лежит $n-1$ копий.
- Если сумма $n$ выбранных пар равна $(0,0)\pmod n$, то число выбранных пар с первой координатой $1$ должно быть кратно $n$.
- Это число между $0$ и $2n-2$, значит оно равно $0$ или $n$; аналогично для второй координаты.
- Если число пар с первой или второй координатой $1$ равно $0$, то для суммы $n$ выбранных пар потребовалось бы $n$ копий одной из типов $(0,0),(0,1),(1,0)$, но каждого типа имеется лишь $n-1$.
- Если оба числа равны $n$, обозначим через $w$ число выбранных $(1,1)$. Тогда числа выбранных $(1,0)$ и $(0,1)$ равны $n-w$, а условие на общее число выбранных пар вынуждает число $(0,0)$ быть $w-n$. Неотрицательность требует $w\ge n$, что невозможно: таких пар всего $n-1$.

## oktch-q-615
ticket: oktch-t-071 · level: L0
Сформулируйте вспомогательное утверждение программы о многочлене $2(1-x_1)\cdots(1-x_m)$ над полем нечётной характеристики $p$.
### Эталон
- На булевом кубе $\{0,1\}^m$ функция, равная $2$ в нуле и $0$ во всех остальных точках, задаётся многочленом $2(1-x_1)\cdots(1-x_m)$.
- При $p\ne2$ его степень равна $m$, поскольку коэффициент при $x_1\cdots x_m$ равен $2(-1)^m\ne0$. При $p=2$ функция тождественно нулевая.
- Любая функция на булевом кубе единственным образом представляется многочленом, в котором степень каждой переменной не больше $1$.

## oktch-q-616
ticket: oktch-t-071 · level: L1
Объясните, как вспомогательный многочлен $2\prod_{i=1}^m(1-x_i)$ используется в доказательстве методом теоремы Шевалле для нечётного простого $p$.
### Эталон
- В доказательстве теоремы Роньяи многочлен $F$ на булевых наборах совпадает с функцией, равной $2$ только в нулевом наборе и $0$ в остальных.
- Единственное мультлинейное представление этой функции есть $F'=2\prod_{i=1}^m(1-x_i)$; единственность следует из линейной независимости мономов $\prod_{i\in I}x_i$ как функций на кубе.
- Поэтому при нечётном $p$ имеем $\deg F'=m$. Но для многочлена из доказательства $\deg F\le4p-3<m=4p-2$, тогда как переход к мультлинейному представителю не увеличивает степень.
- Получено противоречие; это завершает доказательство теоремы Роньяи для нечётного простого $p$. Случай $p=2$ этим аргументом не покрывается.

## oktch-q-617
ticket: oktch-t-072 · level: L0
Сформулируйте нижнюю и верхнюю оценки из программы для числа пар в задаче Эрдёша–Гинзбурга–Зива при $d=2$, $n=p$.
### Эталон
- Контрпример из $4p-4$ пар показывает, что минимальное гарантирующее число не меньше $4p-3$.
- Доказанный результат для $n=p$ даёт верхнюю оценку $4p-2$: любые $4p-2$ пар из $\mathbb Z^2$ содержат $p$ пар с суммой $0$ покоординатно по модулю $p$.
- Вместе эти утверждения ограничивают минимальное гарантирующее число интервалом от $4p-3$ до $4p-2$; приведённый аргумент сам по себе не доказывает точное значение.

## oktch-q-618
ticket: oktch-t-072 · level: L1
Опишите доказательство основной леммы: среди $3p$ пар из $\mathbb Z^2$ с суммой, делящейся на $p$ покоординатно, найдутся $p$ пар с тем же свойством.
### Эталон
- Отбросим одну из $3p$ пар; для оставшихся $3p-1$ пар $(a_i,b_i)$ задают над $\mathbb F_p$ многочлены $F_1=\sum a_ix_i^{p-1}$, $F_2=\sum b_ix_i^{p-1}$, $F_3=\sum x_i^{p-1}$.
- Сумма степеней $3(p-1)<3p-1$, поэтому по обобщённой теореме Варнинга число общих нулей делится на $p$; так как ноль — общий нуль, есть нетривиальный.
- Пусть $J$ — множество ненулевых координат: по малой теореме Ферма суммы $a_i$ и $b_i$ по $J$ делятся на $p$, а $|J|\equiv0\pmod p$, $1\le|J|\le3p-1$, то есть $|J|\in\{p,2p\}$.
- Если $|J|=p$ — готово; если $|J|=2p$, берём дополнение $J$ до всех $3p$ пар: в нём $p$ пар, и его сумма нулевая, так как нулевая сумма всех $3p$.

## oktch-q-619
ticket: oktch-t-073 · level: L0
Сформулируйте основную лемму программы для вывода теоремы Роньяи при $d=2$, $n=p$.
### Эталон
- Если $3p$ пар имеют суммарные координаты, сравнимые с нулём по модулю $p$, то среди них есть $p$ пар с тем же свойством.
- Утверждение применяется к ненулевым координатам нетривиального решения системы многочленов, полученного обобщённой теоремой Варнинга.
- Если таких координат $2p$, берут дополнение до всех $3p$ пар; его мощность $p$, а суммы координат также нулевые по модулю $p$.

## oktch-q-620
ticket: oktch-t-073 · level: L1
Опишите вывод теоремы Роньяи (любые $4p-2$ пары из $\mathbb Z^2$ содержат $p$ пар с суммой, делящейся на $p$ покоординатно) из основной леммы.
### Эталон
- Для доказательства верхней оценки предполагают противное для $4p-2$ пар и сначала используют лемму: среди $3p$ пар с суммой $(0,0)$ по модулю $p$ найдутся $p$ таких пар.
- Рассматривают многочлен над $\mathbb F_p$ от $m=4p-2$ переменных: произведение трёх множителей $(L^{p-1}-1)$ для двух координатных сумм и числа выбранных элементов, умноженное на $(\sigma_p-2)$.
- По предположению и лемме он равен нулю на булевых наборах веса $p$, $2p$, $3p$; остальные ненулевые веса обращают в ноль один из первых трёх множителей. В нуле значение равно $2$.
- При нечётном простом $p$ его мультлинейный представитель обязан быть $2\prod_i(1-x_i)$ степени $4p-2$, но исходная степень не больше $3(p-1)+p=4p-3$ — противоречие. Значит, любые $4p-2$ пар подходят; в сочетании с контрпримером предыдущего вопроса это даёт границы $4p-3\le N(p)\le4p-2$ для минимального гарантирующего числа.
