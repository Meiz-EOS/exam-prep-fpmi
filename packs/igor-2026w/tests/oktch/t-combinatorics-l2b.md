## oktch-q-1504
ticket: oktch-t-061 · level: L2
Выведите формулу числа $T_r(n)$ циклических слов длины $n$ над алфавитом из $r$ букв через обращение Мёбиуса (формулу обращения для делителей можно использовать без доказательства).
### Эталон
- Период линейного слова длины $n$ — наименьшее $d$, при котором $d$ сдвигов возвращают слово; $d\mid n$ (иначе остаток $\rho<d$ от деления $n$ на $d$ тоже возвращал бы слово). Слова длины $n$ разбиваются на классы $V_d$ по периоду $d\mid n$.
- Слово периода $d$ — это $n/d$ повторений блока длины $d$ периода ровно $d$, и обратно; значит, $|V_d|=|W_d|$, где $W_d$ — слова длины $d$ периода $d$.
- Каждое циклическое слово, полученное зацикливанием слов из $W_d$, склеивает ровно $d$ различных линейных слов (сдвиги различны), поэтому $|W_d|=d\,M(d)$, где $M(d)$ — число таких циклических слов.
- Отсюда $r^n=\sum_{d\mid n}dM(d)$; обращение Мёбиуса при $g(n)=r^n$, $f(d)=dM(d)$ даёт $nM(n)=\sum_{d\mid n}\mu(d)r^{n/d}$, то есть $M(n)=\frac1n\sum_{d\mid n}\mu(d)r^{n/d}$.
- Циклические слова длины $n$ — это зацикленные блоки длины $d\mid n$ периода $d$, поэтому $T_r(n)=\sum_{d\mid n}M(d)$.
- Итак, $T_r(n)=\sum_{d\mid n}\frac1d\sum_{e\mid d}\mu(e)r^{d/e}$.

## oktch-q-1505
ticket: oktch-t-062 · level: L2
Докажите, что для функции Мёбиуса локально конечного ЧУМа $\mu(x,x)=1$, $\mu(x,y)=-\sum_{x\preceq z\prec y}\mu(x,z)$ при $x\prec y$ выполнено $\sum_{a\preceq z\preceq b}\mu(z,b)=1$ при $a=b$ и $0$ при $a\prec b$.
### Эталон
- Индукция по длине самой длинной цепи от $a$ до $b$ (она конечна по локальной конечности). База $a=b$: сумма состоит из $\mu(b,b)=1$.
- Пусть $a\prec b$. Выделим слагаемое $z=b$ (оно равно $1$), а остальные раскроем по определению $\mu(z,b)=-\sum_{z\preceq w\prec b}\mu(z,w)$: сумма равна $1-\sum_{a\preceq z\prec b}\sum_{z\preceq w\prec b}\mu(z,w)$.
- Двойная сумма идёт по парам $a\preceq z\preceq w\prec b$; меняем порядок суммирования: $1-\sum_{a\preceq w\prec b}\sum_{a\preceq z\preceq w}\mu(z,w)$.
- Для каждого $w\prec b$ самая длинная цепь от $a$ до $w$ короче, чем до $b$, поэтому по предположению индукции внутренняя сумма равна $1$ при $w=a$ и $0$ при $a\prec w$.
- В двойной сумме остаётся одно слагаемое $w=a$ со значением $1$; итого $1-1=0$.

## oktch-q-1506
ticket: oktch-t-063 · level: L2
Пусть $P$ — локально конечный ЧУМ, $f,g:P\to\mathbb R$ и $g(y)=\sum_{x\preceq y}f(x)$ для всех $y$. Докажите обобщённую формулу обращения Мёбиуса $f(y)=\sum_{x\preceq y}\mu(x,y)g(x)$; лемму $\sum_{a\preceq z\preceq b}\mu(z,b)=\delta_{a,b}$ можно использовать без доказательства.
### Эталон
- Подставим определение $g$ в правую часть: $\sum_{x\preceq y}\mu(x,y)\sum_{z\preceq x}f(z)$ (все суммы конечны по локальной конечности).
- Перегруппируем по $z$: пары $(x,z)$ с $z\preceq x\preceq y$ дают $\sum_{z\preceq y}f(z)\sum_{z\preceq x\preceq y}\mu(x,y)$.
- По лемме внутренняя сумма равна $1$ при $z=y$ и $0$ при $z\prec y$.
- Поэтому все слагаемые, кроме $z=y$, исчезают.
- Остаётся $f(y)$, что и требовалось.
