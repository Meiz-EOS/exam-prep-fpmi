## oktch-q-1110
ticket: oktch-t-014 · level: L2
Опишите с точностью до изоморфизма все частично упорядоченные множества на трёх элементах и докажите, что список полон и элементы списка попарно неизоморфны.
### Эталон
- Число строгих сравнений в ч.у.м. на трёх элементах не превосходит трёх; если их три, получается цепь.
- При двух сравнениях они имеют общий конец: получаем либо один минимальный элемент ниже двух несравнимых, либо двойственный вариант.
- При одном сравнении есть одна двухэлементная цепь и изолированный элемент.
- При нуле сравнений получаем антицепь.
- Перечислены все случаи по числу сравнений; случаи с разным числом сравнений неизоморфны, два случая с двумя сравнениями различаются числом минимальных (или максимальных) элементов.

## oktch-q-1111
ticket: oktch-t-016 · level: L2
Докажите, что предпорядок полон тогда и только тогда, когда индуцированный частичный порядок на классах безразличия линеен.
### Эталон
- Для предпорядка положить $x\sim y$ тогда и только тогда, когда $x\precsim y$ и $y\precsim x$; рефлексивность и транзитивность предпорядка показывают, что это эквивалентность.
- На классах определить $[x]\le[y]$ условием $x\precsim y$. Замена представителей сохраняет условие: из $x'\sim x$, $y'\sim y$ следует $x'\precsim x\precsim y\precsim y'$.
- Рефлексивность и транзитивность индуцированного отношения следуют из соответствующих свойств предпорядка; если $[x]\le[y]$ и $[y]\le[x]$, то $x\sim y$ и классы равны. Значит, это частичный порядок.
- Если предпорядок полон, для любых $x,y$ выполнено $x\precsim y$ или $y\precsim x$, то есть любые классы сравнимы; индуцированный порядок линеен.
- Если индуцированный порядок линеен, для любых $x,y$ сравнимы $[x]$ и $[y]$; по определению индуцированного порядка это означает $x\precsim y$ или $y\precsim x$. Значит, предпорядок полон.

## oktch-q-1112
ticket: oktch-t-018 · level: L2
Выведите формулы для числа $k$-размещений и $k$-сочетаний из $n$ элементов как с повторениями, так и без повторений.
### Эталон
- Для размещения с повторениями на каждом из $k$ упорядоченных мест имеется $n$ вариантов, поэтому число равно $n^k$.
- Для размещения без повторений последовательно имеется $n,n-1,\ldots,n-k+1$ вариантов, всего $n!/(n-k)!$.
- При $k=n$ размещение без повторений является перестановкой, поэтому число перестановок равно $n!$.
- Каждое сочетание без повторений задаёт ровно $k!$ размещений перестановкой выбранных элементов, поэтому число сочетаний равно $n!/((n-k)!k!)$.
- Сочетание с повторениями задаётся неубывающей последовательностью индексов $1\le i_1\le\cdots\le i_k\le n$.
- Преобразование $j_r=i_r+r-1$ задаёт биекцию с выбором $k$ различных чисел из $n+k-1$; число равно $\binom{n+k-1}{k}$.
