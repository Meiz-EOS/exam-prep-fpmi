## oktch-q-706
ticket: oktch-t-d16 · level: L0
Определите изоморфизм упорядоченных множеств.
### Эталон
- Изоморфизм $(A,\le_A)$ и $(B,\le_B)$ — биекция $f:A\to B$, сохраняющая и отражающая порядок.
- Для всех $x,y\in A$: $x\le_A y$ тогда и только тогда, когда $f(x)\le_B f(y)$.

## oktch-q-707
ticket: oktch-t-d19 · level: L0
Сформулируйте принцип Дирихле.
### Эталон
- Если $N+1$ объектов распределены по $N$ ящикам, то хотя бы в одном ящике находятся не менее двух объектов.
- Обобщение: при $N,k\in\mathbb N$ и $N,k>0$ распределение $N$ объектов по $k$ ящикам означает, что хотя бы один ящик содержит не менее $\lceil N/k\rceil$ объектов.

## oktch-q-708
ticket: oktch-t-d22 · level: L0
Запишите формулы чисел размещений и сочетаний с повторениями и без повторений.
### Эталон
- При $n\ge1$ и $0\le k\le n$ размещения без повторений: $A_n^k=\frac{n!}{(n-k)!}$; при $n\ge1$, $k\ge0$ размещения с повторениями: $n^k$.
- При $n\ge1$ и $0\le k\le n$ сочетания без повторений: $\binom nk=\frac{n!}{k!(n-k)!}$; при $n\ge1$, $k\ge0$ сочетания с повторениями: $\binom{n+k-1}{k}$.

## oktch-q-709
ticket: oktch-t-d24 · level: L0
Сформулируйте полиномиальную формулу.
### Эталон
- $(x_1+\cdots+x_m)^n=\sum_{k_1+\cdots+k_m=n}\frac{n!}{k_1!\cdots k_m!}x_1^{k_1}\cdots x_m^{k_m}$.
- Суммирование ведётся по неотрицательным целым $k_i$.

## oktch-q-710
ticket: oktch-t-d28 · level: L0
Запишите сумму арифметической функции Мёбиуса по делителям натурального числа.
### Эталон
- $\sum_{d\mid n}\mu(d)=1$ при $n=1$.
- $\sum_{d\mid n}\mu(d)=0$ при $n>1$.

## oktch-q-012
ticket: oktch-t-d18 · level: L0
Сформулируйте правила сложения и умножения в комбинаторном подсчёте.
Также проверьте билет `oktch-t-d19`: Сформулируйте принцип Дирихле.
### Эталон
- Для попарно непересекающихся вариантов выбора одного из случаев общее число вариантов — сумма количеств.
- Для последовательности независимых этапов выбора число вариантов — произведение количеств.
- Если $N+1$ объектов распределены по $N$ ящикам, в каком-то ящике не менее двух объектов.
- Обобщение: среди $N$ объектов по $k$ ящикам есть ящик как минимум с $\lceil N/k\rceil$ объектами.

## oktch-q-014
ticket: oktch-t-d21 · level: L0
Определите размещения, перестановки и сочетания. Сколькими способами выбрать двух дежурных из четырёх разных школьников?
Также проверьте билет `oktch-t-d22`: Запишите формулы размещений и сочетаний с повторениями и без повторений.
### Эталон
- Размещение выбирает $k$ различных элементов из $n$ с учётом порядка; перестановка упорядочивает все $n$.
- Сочетание выбирает $k$ элементов из $n$ без учёта порядка.
- Выбор дежурных: $\binom42=6$.
- $A_n^k=n!/(n-k)!$ и $\binom nk=n!/(k!(n-k)!)$.
- Размещения с повторениями: $n^k$.
- Сочетания с повторениями: $\binom{n+k-1}{k}$.

## oktch-q-020
ticket: oktch-t-d30 · level: L0
Определите циклический сдвиг линейной последовательности длины $n$.
Также проверьте билет `oktch-t-d31`: Определите период линейной последовательности длины $n$ и сформулируйте связь периода с $n$.
### Эталон
- Циклический сдвиг переносит последний элемент в начало (или первый в конец).
- Последовательности, получаемые друг из друга циклическими сдвигами, задают один циклический класс.
- Период — наименьшее положительное число сдвигов, возвращающее последовательность к исходной.
- Период делит длину $n$.
