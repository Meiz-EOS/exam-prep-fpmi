## oktch-q-216
ticket: oktch-t-023 · level: L0
Определите арифметическую функцию Мёбиуса и сформулируйте сумму её значений по делителям числа.
### Эталон
- $\mu(1)=1$; если $n$ делится на квадрат простого числа, то $\mu(n)=0$.
- Если $n$ квадратсвободно и имеет $r$ простых делителей (то есть является произведением всех этих $r$ различных простых чисел), то $\mu(n)=(-1)^r$.
- $\sum_{d\mid n}\mu(d)=1$ при $n=1$ и $0$ при $n>1$.

## oktch-q-217
ticket: oktch-t-023 · level: L1
Докажите тождество $\sum_{d\mid n}\mu(d)=0$ для $n>1$ и поясните сумму по делителям с чётным числом простых множителей.
### Эталон
- Пусть у $n$ ровно $r>0$ различных простых делителей. Ненулевой вклад дают только квадратсвободные делители.
- Их вклады суммируются как $\sum_{j=0}^{r}\binom rj(-1)^j=(1-1)^r=0$.
- В частности, сумма по квадратсвободным делителям с чётным числом простых множителей равна $\sum_{0\le j\le r,\ j\text{ чётно}}\binom rj=2^{r-1}$ при $r>0$. Сумма по нечётным $j$ также равна $2^{r-1}$, поэтому их вклады $+1$ и $-1$ взаимно уничтожаются в нулевой сумме Мёбиуса.

## oktch-q-218
ticket: oktch-t-024 · level: L0
Определите циклический сдвиг, период линейной последовательности длины $n$ и общий вид последовательности с периодом $d$.
### Эталон
- Циклический сдвиг переносит элементы по кругу; например, последний элемент ставится перед первым.
- Период — наименьшее положительное число сдвигов, после которого последовательность совпадает с исходной.
- При периоде $d$ и длине $n$ элементы задаются повторением первых $d$ элементов; $d\mid n$.

## oktch-q-219
ticket: oktch-t-024 · level: L1
Перечислите свойства периода линейной последовательности длины $n$. Найдите период последовательности $(a,b,a,b,a,b)$.
### Эталон
- Период — наименьшее положительное число циклических сдвигов, возвращающих последовательность к исходной.
- Период является делителем длины $n$, а последовательность состоит из повторений блока длины, равной периоду.
- Для $(a,b,a,b,a,b)$ период равен $2$: блок $(a,b)$ повторён трижды.

## oktch-q-220
ticket: oktch-t-025 · level: L0
Определите функцию Мёбиуса конечного частично упорядоченного множества.
### Эталон
- Для $x\le y$ функция задаётся рекурсией $\mu(x,x)=1$ и $\mu(x,y)=-\sum_{x\le z<y}\mu(x,z)$ при $x<y$.
- Эквивалентно, $\sum_{x\le z\le y}\mu(x,z)=0$ при $x<y$.

## oktch-q-221
ticket: oktch-t-025 · level: L1
Вычислите функцию Мёбиуса на четырёхэлементном частично упорядоченном множестве с отношениями $a<b<d$ и $a<c<d$, где $b,c$ несравнимы. Найдите значения на интервалах $[a,b]$, $[a,c]$, $[b,d]$, $[c,d]$ и $[a,d]$.
### Эталон
- По рекурсии $\mu(a,b)=\mu(a,c)=\mu(b,d)=\mu(c,d)=-1$.
- Для $[a,d]$ учитываются $a,b,c$: $\mu(a,d)=-(\mu(a,a)+\mu(a,b)+\mu(a,c))=-(1-1-1)=1$.
- Несравнимость $b,c$ означает, что ни один из них не входит в интервал $[a,b]$ или $[a,c]$.

## oktch-q-222
ticket: oktch-t-026 · level: L0
Различите упорядоченные и неупорядоченные разбиения числа на положительные слагаемые и запишите рекуррентные формулы их подсчёта.
### Эталон
- В упорядоченных разбиениях порядок слагаемых учитывается; в неупорядоченных — нет.
- Пусть $S=(s_1,\ldots,s_r)$ — фиксированный конечный список различных положительных целых частей. Для упорядоченных: $f(0;S)=1$, $f(n;S)=0$ при $n<0$, $f(n;S)=\sum_{i=1}^r f(n-s_i;S)$ при $n>0$.
- Для неупорядоченных частей из этого списка: $F(n;s_1,\ldots,s_r)=F(n-s_1;s_1,\ldots,s_r)+F(n;s_2,\ldots,s_r)$; $F(0;S)=1$, $F(n;\varnothing)=0$ при $n>0$, и $F(n;S)=0$ при $n<0$.

## oktch-q-223
ticket: oktch-t-026 · level: L1
Объясните рекурсию для упорядоченных разбиений $f(n;S)$ и получите число всех упорядоченных разбиений целого $n\ge1$ на положительные слагаемые.
### Эталон
- Разбиения разбиваются на непересекающиеся случаи по первому слагаемому $s_i$; после него остаётся упорядоченное разбиение $n-s_i$, откуда $f(n;S)=\sum_i f(n-s_i;S)$.
- Для всех положительных частей положим $S=\{1,\ldots,n\}$; разложение $n$ изображается строкой из $n$ единиц.
- Каждый из $n-1$ промежутков между единицами либо разделён, либо нет; выбор разделителей взаимно однозначен с упорядоченными разбиениями.
- Поэтому их число равно $2^{n-1}$ при $n\ge1$.
