## oktch-q-1201
ticket: oktch-t-019 · level: L2
Докажите полиномиальную формулу: для коммутирующих $x_1,\ldots,x_m$ и целого $n\ge0$ $(x_1+\cdots+x_m)^n=\sum\frac{n!}{k_1!\cdots k_m!}x_1^{k_1}\cdots x_m^{k_m}$, где сумма берётся по всем целым $k_i\ge0$ с $\sum_i k_i=n$.
### Эталон
- Записать степень как произведение $n$ скобок; слагаемое получается выбором одного из $x_i$ в каждой скобке.
- Из-за коммутативности каждый выбор даёт одночлен $x_1^{k_1}\cdots x_m^{k_m}$, где $k_i$ — сколько раз выбран $x_i$; $k_i\ge0$ и $\sum_i k_i=n$.
- Одночлен определяется вектором $(k_1,\ldots,k_m)$; нужно посчитать число выборов с таким вектором — число способов выбрать, в каких скобках берётся $x_1$, в каких $x_2$ и т. д.
- Последовательный выбор мест: $\binom n{k_1}\binom{n-k_1}{k_2}\cdots\binom{n-k_1-\cdots-k_{m-1}}{k_m}$.
- Сократить факториалы (произведение телескопируется) и получить $\frac{n!}{k_1!\cdots k_m!}$.
- Сложить вклады по всем допустимым векторам $(k_1,\ldots,k_m)$ — это формула.

## oktch-q-1202
ticket: oktch-t-020 · level: L2
Докажите шесть комбинаторных тождеств для биномиальных коэффициентов: $\binom nk=\binom n{n-k}$ (при $0\le k\le n$), $\binom nk=\binom{n-1}k+\binom{n-1}{k-1}$ (при $1\le k\le n-1$), $\sum_{k=0}^n\binom nk=2^n$, $\sum_{k=0}^n(-1)^k\binom nk=0$ при $n>0$, $\sum_{k=0}^n\binom nk^2=\binom{2n}n$ и $\sum_{k=r}^n\binom kr=\binom{n+1}{r+1}$ (при $0\le r\le n$).
### Эталон
- Симметрия: дополнение подмножества в $n$-элементном множестве задаёт биекцию между выборами $k$ и $n-k$ элементов.
- Паскаль: разбить $k$-элементные подмножества по наличию фиксированного элемента; получить $\binom{n-1}{k-1}+\binom{n-1}k$.
- Сумма строки: подсчитать все подмножества $n$-элементного множества двумя способами — всего $2^n$ и по размеру $i$ ($\binom ni$ штук).
- Знакопеременная сумма: при $n>0$ спарить каждое подмножество с результатом переключения фиксированного элемента (в подмножество или из него); размеры отличаются на 1, знаки противоположны, значит сумма равна нулю.
- Сумма квадратов: подсчитать $n$-элементные подмножества объединения двух непересекающихся $n$-множеств: всего $\binom{2n}n$, а по числу $i$ элементов из первого множества — $\sum_i\binom ni\binom n{n-i}=\sum_i\binom ni^2$.
- Сумма диагонали: $(r+1)$-элементные подмножества $\{1,\ldots,n+1\}$ классифицировать по максимальному элементу; с максимумом $k+1$ их $\binom kr$ ($k=r,\ldots,n$), всего $\binom{n+1}{r+1}$.

## oktch-q-1203
ticket: oktch-t-021 · level: L2
Докажите формулу включений и исключений для трёх конечных множеств $A,B,C$ и выведите из общей формулы $N(\bar\alpha_1\ldots\bar\alpha_n)=N-\sum N(\alpha_i)+\sum N(\alpha_i\alpha_j)-\cdots+(-1)^nN(\alpha_1\ldots\alpha_n)$ число беспорядков на $n$ элементах.
### Эталон
- Элемент, не лежащий ни в одном из $A,B,C$, не даёт вклада ни в одну часть правой части формулы для $|A\cup B\cup C|$.
- Элемент, лежащий ровно в $r\in\{1,2,3\}$ множествах, даёт вклад $r-\binom r2+\binom r3$ (в одиночные, попарные и тройное пересечения).
- Проверка: $r=1$ даёт $1$, $r=2$ даёт $2-1=1$, $r=3$ даёт $3-3+1=1$; значит, каждый элемент объединения учтён ровно один раз и равенство доказано.
- Беспорядок: объекты — все $n!$ перестановок, свойство $\alpha_i$ — «$i$ неподвижна».
- Перестановок, фиксирующих заданные $k$ элементов, $(n-k)!$; наборов из $k$ свойств $\binom nk$.
- $D_n=\sum_{k=0}^n(-1)^k\binom nk(n-k)!=n!\sum_{k=0}^n\frac{(-1)^k}{k!}$.

## oktch-q-1204
ticket: oktch-t-022 · level: L2
Выведите формулу числа сюръекций из $k$-элементного множества $X$ в $m$-элементное множество $Y$ ($k,m\ge1$), применив формулу включений и исключений.
### Эталон
- Объекты — все $m^k$ отображений $X\to Y$; для $y\in Y$ свойство $\alpha_y$: отображение не принимает значение $y$.
- Сюръекции — отображения, не обладающие ни одним из свойств $\alpha_y$.
- Для любых $j$ фиксированных значений число отображений, не принимающих ни одного из них, равно $(m-j)^k$ (значения берутся из оставшихся $m-j$ элементов).
- Наборов из $j$ свойств $\binom mj$.
- Подставить в формулу включений и исключений: слагаемые уровня $j$ входят со знаком $(-1)^j$ (уровень $j=0$ — все $m^k$ отображений).
- Получить $\sum_{j=0}^m(-1)^j\binom mj(m-j)^k$.
