## oktch-q-601
ticket: oktch-t-064 · level: L0
Сформулируйте переобоснование формулы включений и исключений через обращение Мёбиуса на частично упорядоченном множестве.
### Эталон
- Рассматривается булеан $2^{[n]}$ с порядком включения и функция Мёбиуса $\mu(I,J)=(-1)^{|J|-|I|}$ при $I\subseteq J$.
- Обращение Мёбиуса связывает числа элементов, принадлежащих ровно заданным наборам множеств, с мощностями пересечений.
- Для объединения получается $|\bigcup_{i=1}^n A_i|=\sum_{\varnothing\ne J\subseteq[n]}(-1)^{|J|+1}|\bigcap_{j\in J}A_j|$.

## oktch-q-602
ticket: oktch-t-064 · level: L1
Опишите идею переобоснования формулы включений и исключений посредством обращения Мёбиуса на булеане.
### Эталон
- Вводят $g(I)=|\bigcap_{i\notin I}A_i|$ (пустое пересечение равно $\Omega=\bigcup_iA_i$) и $f(I)$ — число элементов, лежащих во всех $A_i$ с $i\notin I$ и ни в одном $A_i$ с $i\in I$.
- Тогда $g(I)=\sum_{I'\subseteq I}f(I')$, поэтому обращение Мёбиуса даёт $f(I)=\sum_{I'\subseteq I}(-1)^{|I|-|I'|}g(I')$.
- При $I=[n]$ величина $f([n])=0$; выделив член $g([n])=|\Omega|$ и заменив $[n]\setminus I'$ на $J$, получают формулу включений и исключений.

## oktch-q-603
ticket: oktch-t-065 · level: L0
Сформулируйте формулу включений и исключений, полученную обращением Мёбиуса на булеане.
### Эталон
- Для конечного семейства $A_1,\ldots,A_n$ мощность объединения равна знакопеременной сумме мощностей непустых пересечений.
- Член для пересечения с $k$ множествами имеет знак $(-1)^{k+1}$.
- Формула: $|\bigcup_iA_i|=\sum_{\varnothing\ne J\subseteq[n]}(-1)^{|J|+1}|\bigcap_{j\in J}A_j|$.

## oktch-q-604
ticket: oktch-t-065 · level: L1
Покажите, как из функции Мёбиуса булеана получается формула включений и исключений.
### Эталон
- На булеане $\mu(I,J)=(-1)^{|J|-|I|}$.
- Счёт элементов по точному множеству принадлежности даёт соотношение суммирования по подмножествам; обращение Мёбиуса восстанавливает числа точных принадлежностей.
- Для верхнего индекса $[n]$ число элементов, не принадлежащих ни одному $A_i$, равно нулю, поскольку считаются элементы объединения.
- Перенос этого нулевого слагаемого и замена индексов на дополнения дают знаки $(-1)^{|J|+1}$ и формулу для объединения.

## oktch-q-605
ticket: oktch-t-066 · level: L0
Запишите формулу для коэффициентов формального ряда $\sqrt{1+x}$.
### Эталон
- Биномиальное разложение имеет вид $\sqrt{1+x}=\sum_{n\ge0}\binom{1/2}{n}x^n$ как формальный степенной ряд.
- Здесь $\binom{1/2}{0}=1$, а при $n\ge1$ коэффициент равен $(-1)^{n-1}\binom{2n-2}{n-1}/(n\,2^{2n-1})$.

## oktch-q-606
ticket: oktch-t-066 · level: L1
Выведите коэффициент при $x^n$ в разложении $\sqrt{1+x}$ через биномиальные коэффициенты.
### Эталон
- Используют биномиальный ряд $\sum_{n\ge0}\binom{1/2}{n}x^n$.
- Для $n\ge1$: $\binom{1/2}{n}=\frac{(1/2)(1/2-1)\cdots(1/2-n+1)}{n!}$.
- Вынося знаки и удваивая множители, получают $\binom{1/2}{n}=(-1)^{n-1}\binom{2n-2}{n-1}/(n2^{2n-1})$.

## oktch-q-607
ticket: oktch-t-067 · level: L0
Определите числа Каталана и запишите их явную формулу.
### Эталон
- $C_n$ — число правильных скобочных выражений из $2n$ скобок; $C_0=1$.
- $C_n=\frac{1}{n+1}\binom{2n}{n}$ для $n\ge0$.
- Эквивалентная рекурсия: $C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}$ при $n\ge1$.

## oktch-q-608
ticket: oktch-t-067 · level: L1
Выведите формулу $C_n=\frac1{n+1}\binom{2n}{n}$ из производящей функции чисел Каталана.
### Эталон
- Разбиение правильной скобочной последовательности по первой паре скобок даёт $C_0=1$ и $C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}$.
- Для $C(x)=\sum_{n\ge0}C_nx^n$ это означает $C(x)=1+xC(x)^2$.
- Решение с постоянным членом $1$: $C(x)=(1-\sqrt{1-4x})/(2x)$.
- Подстановка биномиального разложения корня даёт коэффициент $[x^n]C(x)=\binom{2n}{n}/(n+1)$.

## oktch-q-609
ticket: oktch-t-068 · level: L0
Запишите производящую функцию для числа разбиений на неупорядоченные положительные части и укажите тождество Эйлера о различных и нечётных частях.
### Эталон
- Производящая функция всех разбиений: $\prod_{k\ge1}(1-x^k)^{-1}$.
- Для частей, выбранных не более одного раза: $\prod_{k\ge1}(1+x^k)$.
- Для нечётных частей: $\prod_{k\ge1}(1-x^{2k-1})^{-1}$.
- Число разбиений на попарно различные части равно числу разбиений на нечётные части; соответствующие производящие функции равны.

## oktch-q-610
ticket: oktch-t-068 · level: L1
Объясните через производящие функции равенство чисел разбиений на попарно различные и на нечётные части.
### Эталон
- Производящая функция разбиений на различные части есть $\prod_{k\ge1}(1+x^k)$.
- Из $1+x^k=(1-x^{2k})/(1-x^k)$ получаем $\prod_{k\ge1}(1+x^k)=\prod_{k\ge1}(1-x^{2k})/\prod_{k\ge1}(1-x^k)$.
- Сокращая множители, получаем $\prod_{k\ge1}(1-x^{2k-1})^{-1}$ — производящую функцию разбиений на нечётные части.
- Равенство коэффициентов при каждой степени даёт равенство чисел разбиений.
