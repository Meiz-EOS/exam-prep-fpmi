## oktch-q-1507
ticket: oktch-t-064 · level: L2
Для переобоснования формулы включений и исключений через обращение Мёбиуса задайте ЧУМ на подмножествах $[n]$ и вычислите на нём функцию Мёбиуса: докажите $\mu(I',I)=(-1)^{|I|-|I'|}$ при $I'\subseteq I$.
### Эталон
- ЧУМ: $X=2^{[n]}$, $I'\preceq I\Leftrightarrow I'\subseteq I$ (конечный, значит локально конечный); нужно найти $\mu(I',I)$ по определению $\mu(I,I)=1$, $\mu(I',I)=-\sum_{I'\subseteq J\subsetneq I}\mu(I',J)$.
- Индукция по $k=|I|-|I'|$. База $k=0$: $\mu(I,I)=1=(-1)^0$.
- Шаг $k\ge1$: множеств $J$ с $I'\subseteq J\subsetneq I$ и $|J|-|I'|=l$ ровно $\binom kl$ при $0\le l\le k-1$, и по предположению индукции $\mu(I',J)=(-1)^l$.
- Поэтому $\mu(I',I)=-\sum_{l=0}^{k-1}\binom kl(-1)^l$.
- Так как $\sum_{l=0}^{k}\binom kl(-1)^l=(1-1)^k=0$ при $k\ge1$, имеем $\mu(I',I)=-(0-(-1)^k)=(-1)^k$.
- Применение: в обращении $f(I)=\sum_{I'\subseteq I}\mu(I',I)g(I')$ при $I=[n]$ (где $f([n])=0$, $g([n])=|\Omega|$) эти коэффициенты дают формулу включений и исключений.

## oktch-q-1508
ticket: oktch-t-065 · level: L2
Выведите формулу включений и исключений $|\bigcup_{i=1}^nA_i|=\sum_{\varnothing\ne J\subseteq[n]}(-1)^{|J|+1}|\bigcap_{j\in J}A_j|$ из обращения Мёбиуса: задайте ЧУМ и функции $f,g$ (формулу $\mu(I',I)=(-1)^{|I|-|I'|}$ для булеана можно использовать без доказательства).
### Эталон
- ЧУМ: $X=2^{[n]}$ с порядком $\subseteq$; $\Omega=\bigcup_iA_i$.
- Определим $g(I)=|\bigcap_{i\notin I}A_i|$ (пустое пересечение равно $\Omega$) и $f(I)$ — число точек $\Omega$, лежащих во всех $A_i$ с $i\notin I$ и ни в одном $A_i$ с $i\in I$.
- Каждая точка пересечения $\bigcap_{i\notin I}A_i$ для ровно одного $I'\subseteq I$ не лежит в точности в $A_i$, $i\in I'$; поэтому $g(I)=\sum_{I'\subseteq I}f(I')$.
- Обращение Мёбиуса и $\mu(I',I)=(-1)^{|I|-|I'|}$ дают $f(I)=\sum_{I'\subseteq I}(-1)^{|I|-|I'|}g(I')$.
- При $I=[n]$: $f([n])=0$, так как каждая точка $\Omega$ лежит в некотором $A_i$, а $g([n])=|\Omega|$.
- Положим $J=[n]\setminus I'$ и выделим слагаемое $J=\varnothing$: $0=|\Omega|+\sum_{\varnothing\ne J}(-1)^{|J|}|\bigcap_{j\in J}A_j|$, откуда следует формула включений и исключений.

## oktch-q-1509
ticket: oktch-t-066 · level: L2
Выведите формулу коэффициента $[x^n]\sqrt{1+x}=\binom{1/2}{n}$ и его выражение через обычный биномиальный коэффициент.
### Эталон
- В формальном биномиальном ряду коэффициент при $x^n$ равен $\binom{1/2}{n}=\frac{(1/2)(1/2-1)\cdots(1/2-n+1)}{n!}$.
- При $n=0$ коэффициент равен $1$.
- Для $n\ge1$ в числителе вынесем знак: имеется $n-1$ отрицательных множителей.
- Удвоение каждого множителя даёт нечётные числа $1,3,\ldots,2n-3$ и знаменатель $2^n n!$.
- Домножая числитель и знаменатель на $2\cdot4\cdots(2n-2)=2^{n-1}(n-1)!$, получаем $(-1)^{n-1}\frac{(2n-2)!}{n!(n-1)!2^{2n-1}}$.
- Переписывая факториалы через биномиальный коэффициент, имеем $[x^n]\sqrt{1+x}=(-1)^{n-1}\frac{\binom{2n-2}{n-1}}{n2^{2n-1}}$.

## oktch-q-1510
ticket: oktch-t-067 · level: L2
Выведите формулу Каталана $C_n=\frac1{n+1}\binom{2n}{n}$ из производящей функции чисел Каталана ($C_0=1$, $C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}$), используя без доказательства $\sqrt{1+x}=\sum_{m\ge0}\binom{1/2}{m}x^m$ и формулу $\binom{1/2}{m}=(-1)^{m-1}\binom{2m-2}{m-1}/(m\,2^{2m-1})$ при $m\ge1$.
### Эталон
- Для $C(x)=\sum_{n\ge0}C_nx^n$ коэффициент при $x^n$ в $C(x)^2$ равен $C_{n+1}$ по рекурсии, поэтому $xC(x)^2=C(x)-1$.
- Решаем квадратное уравнение $xC^2-C+1=0$: $xC(x)=\frac{1\pm\sqrt{1-4x}}2$. При $x=0$ левая часть равна $0$, поэтому выбираем знак «минус»: $xC(x)=\frac{1-\sqrt{1-4x}}2$.
- Подстановка $-4x$ вместо $x$ даёт $\sqrt{1-4x}=\sum_m\binom{1/2}{m}(-4)^mx^m$.
- Сравнивая коэффициенты при $x^{n+1}$ (свободные члены сокращаются), получаем $C_n=-\frac12\binom{1/2}{n+1}(-4)^{n+1}$.
- Подставляем $\binom{1/2}{n+1}=(-1)^n\binom{2n}{n}/((n+1)2^{2n+1})$: знаки дают $(-1)^n(-1)^{n+1}\cdot(-1)=+1$, а $4^{n+1}/2^{2n+1}=2$ сокращается с $\frac12$.
- Итог: $C_n=\frac1{n+1}\binom{2n}{n}$ для всех $n\ge0$.

## oktch-q-1511
ticket: oktch-t-068 · level: L2
Выведите производящую функцию числа неупорядоченных разбиений на слагаемые из заданного набора и для разбиений специального вида (на попарно различные и на нечётные слагаемые); докажите, что количества разбиений на попарно различные слагаемые и на нечётные слагаемые совпадают.
### Эталон
- Допустимое слагаемое $n_i$ входит $m_i\ge0$ раз и даёт вклад $1+x^{n_i}+x^{2n_i}+\cdots=\frac1{1-x^{n_i}}$; в произведении $\prod_i\frac1{1-x^{n_i}}$ коэффициент при $x^n$ — число наборов $(m_i)$ с $\sum m_in_i=n$, то есть число неупорядоченных разбиений.
- Все натуральные слагаемые: $\prod_{k\ge1}\frac1{1-x^k}$; попарно различные (каждое $k$ не более одного раза): $\prod_{k\ge1}(1+x^k)$; нечётные: $\prod_{k\ge1}\frac1{1-x^{2k-1}}$. Бесконечные произведения понимаются формально: коэффициент при $x^m$ зависит лишь от первых $m$ скобок.
- Для каждого $k$ верно $1+x^k=\frac{1-x^{2k}}{1-x^k}$, поэтому $\prod_{k\ge1}(1+x^k)=\frac{\prod_{k\ge1}(1-x^{2k})}{\prod_{k\ge1}(1-x^k)}$.
- Множители $1-x^{2k}$ числителя сокращаются с множителями знаменателя с чётными номерами (ряды со свободным членом $1$ обратимы), остаётся $\prod_{k\ge1}(1-x^{2k-1})^{-1}$.
- Это производящая функция разбиений на нечётные слагаемые, поэтому она совпадает с производящей функцией разбиений на различные слагаемые.
- Равенство формальных рядов влечёт равенство коэффициентов при каждом $x^n$, то есть равенство количеств разбиений.
