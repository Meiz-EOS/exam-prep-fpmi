## matan-q-2210
ticket: matan-t-0212 · level: L2
Докажите критерий Коши: последовательность сходится тогда и только тогда, когда она фундаментальна.
### Эталон
- Если $a_n\to a$, то для заданного $\varepsilon>0$ найдётся $N$, после которого $|a_n-a|<\varepsilon/2$; значит для $n,m\geq N$ по неравенству треугольника $|a_n-a_m|<\varepsilon$, то есть последовательность фундаментальна.
- Пусть теперь последовательность фундаментальна; из условия с $\varepsilon=1$ следует, что все члены хвоста находятся в $1$ от $a_N$, а конечное начало также ограничено.
- По теореме Больцано–Вейерштрасса у ограниченной последовательности есть подпоследовательность $a_{n_k}\to a$.
- Для заданного $\varepsilon>0$ выберем $N$, чтобы $|a_n-a_m|<\varepsilon/2$ при $n,m\geq N$, и $K$, чтобы $|a_{n_k}-a|<\varepsilon/2$ при $k\geq K$.
- Положим $M=\max\{N,K\}$; тогда $n_M\geq N,K$, поэтому для $n\geq N$ имеем $|a_n-a|\leq|a_n-a_{n_M}|+|a_{n_M}-a|<\varepsilon$.
