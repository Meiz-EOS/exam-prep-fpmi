## matan-q-307
ticket: matan-t-0403 · level: L0
Сформулируйте теорему о пределах нестрого возрастающей функции на концах интервала.
### Эталон
- Пусть $a,b\in\overline{\mathbb R}$, $a<b$, и $f$ нестрого возрастает на $(a,b)$.
- Существуют односторонние пределы на концах интервала.
- $\lim_{x\to a+0}f(x)=\inf_{(a,b)}f(x)$ и $\lim_{x\to b-0}f(x)=\sup_{(a,b)}f(x)$.
## matan-q-308
ticket: matan-t-0403 · level: L1
Назовите идею и скелет доказательства формулы для предела возрастающей функции при $x\to b-0$.
### Эталон
- Положим $s=\sup_{(a,b)}f(x)$ и по определению супремума для каждого $r<s$ выберем $x_r$ с $f(x_r)>r$.
- Возрастание даёт $r<f(x)\le s$ при $x\in(x_r,b)$.
- Для конечного $s$ берут $r=s-\varepsilon$; при $s=+\infty$ берут $r=1/\varepsilon$.
- Выбор окрестности справа от $b$ из интервала $(x_r,b)$ даёт требуемый односторонний предел; случай у левого конца аналогичен для инфимума.
