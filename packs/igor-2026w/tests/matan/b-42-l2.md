## matan-q-2605
ticket: matan-t-0602 · level: L2
Докажите критерий Римана: ограниченная функция $f$ интегрируема на $[a,b]$ тогда и только тогда, когда для любого $\varepsilon>0$ существует разбиение $T$, для которого $\Omega_T(f)=S_T(f)-s_T(f)<\varepsilon$.
### Эталон
- При интегрируемости обозначить общий интеграл Дарбу через $I$.
- По определению выбрать $T_1,T_2$ с $s_{T_1}(f)>I-\varepsilon/2$ и $S_{T_2}(f)<I+\varepsilon/2$.
- Взять общее уточнение $T=T_1\cup T_2$; суммы Дарбу при уточнении монотонны.
- Тогда $\Omega_T=S_T-s_T\le S_{T_2}-s_{T_1}<\varepsilon$.
- Обратно, $0\le\overline{\int f}-\underline{\int f}\le S_T-s_T=\Omega_T<\varepsilon$.
- Произвольность $\varepsilon$ дает равенство верхнего и нижнего интегралов, то есть интегрируемость.
## matan-q-2606
ticket: matan-t-0603 · level: L2
Докажите, что всякая непрерывная на $[a,b]$ функция и всякая монотонная на $[a,b]$ функция интегрируемы по Риману.
### Эталон
- Для непрерывной $f$ использовать равномерную непрерывность: при достаточно мелком разбиении на каждом отрезке колебание $f$ меньше $\varepsilon/(b-a)$.
- Суммирование дает $\Omega_T(f)<\varepsilon$; по критерию Римана $f$ интегрируема.
- Для монотонной функции каждое слагаемое суммы колебаний равно $|f(x_i)-f(x_{i-1})|\Delta x_i$.
- При равномерном разбиении с шагом $h$ получить $\Omega_T(f)\le h|f(b)-f(a)|$.
- Выбрать $h$ достаточно малым и снова применить критерий Римана.
## matan-q-2607
ticket: matan-t-0605 · level: L2
Докажите критерий Дарбу: ограниченная $f$ интегрируема на $[a,b]$ тогда и только тогда, когда существует $I$, для любого $\varepsilon>0$ найдётся $\delta>0$, такое что для любого отмеченного разбиения $(T,\xi)$ с $|T|<\delta$ выполнено $|\sigma_T(f,\xi)-I|<\varepsilon$.
### Эталон
- Если $f$ интегрируема и $I=\int_a^b f$, лемма о мелких разбиениях даёт $0\le S_T-I<\varepsilon$ и $0\le I-s_T<\varepsilon$.
- Для любой отметки $s_T\le\sigma_T\le S_T$, откуда $|\sigma_T-I|<\varepsilon$.
- Обратно, предположить условие для всех отмеченных сумм и фиксировать разбиение $T$ с $|T|<\delta$.
- Переходом к инфимуму и супремуму по отметкам получить $I-\varepsilon\le s_T\le S_T\le I+\varepsilon$.
- Нижний и верхний интегралы лежат между $s_T$ и $S_T$, поэтому их разность не превосходит $2\varepsilon$.
- Произвольность $\varepsilon$ устанавливает их равенство и интегрируемость; общее значение равно $I$.
