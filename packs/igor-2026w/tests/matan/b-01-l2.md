## matan-q-2101
ticket: matan-t-0107 · level: L2
Докажите принцип математической индукции: если $P(1)$ истинно и для каждого $n \in \mathbb{N}$ из $P(n)$ следует $P(n+1)$, то $P(n)$ истинно для всех $n \in \mathbb{N}$.
### Эталон
- Рассмотрим множество $S=\{n\in\mathbb{N}:P(n)\text{ истинно}\}$.
- Из условия $P(1)$ следует $1\in S$.
- По условию перехода из $n\in S$ следует $n+1\in S$, значит, $S$ индуктивно.
- По определению натуральных чисел как минимального индуктивного множества $\mathbb{N}\subset S$.
- Так как $S\subset\mathbb{N}$, имеем $S=\mathbb{N}$, то есть утверждение верно для всех натуральных $n$.

## matan-q-2102
ticket: matan-t-0108 · level: L2
Докажите принцип наименьшего элемента: всякое непустое подмножество $A\subset\mathbb{N}$ имеет минимальный элемент.
### Эталон
- Предположим противное: у непустого $A$ нет минимального элемента; положим $M=\{x\in\mathbb{N}:\forall n\in A\;x<n\}$.
- $1\in M$, поскольку иначе $1\in A$ было бы минимальным элементом $A$.
- Если $x\in M$ и $x+1\notin M$, то найдётся $m\in A$ с $m\leq x+1$.
- Для всех $n\in A$ имеем $x<n$, а значит $x+1\leq n$; поэтому $m\leq n$ для всех $n\in A$, и $m$ — минимум, противоречие.
- Следовательно, из $x\in M$ следует $x+1\in M$; значит, $M$ индуктивно и $M=\mathbb{N}$.
- Тогда $A$ не может быть непустым, поскольку ни один его элемент не удовлетворяет определению $M$; противоречие.

## matan-q-2103
ticket: matan-t-0109 · level: L2
Докажите критерий супремума и инфимума: $c=\sup E$ тогда и только тогда, когда $c$ — верхняя грань $E$ и для каждого $\varepsilon>0$ найдётся $x'\in E$ с $x'>c-\varepsilon$; аналогично, $c=\inf E$ тогда и только тогда, когда $c$ — нижняя грань $E$ и для каждого $\varepsilon>0$ найдётся $x'\in E$ с $x'<c+\varepsilon$.
### Эталон
- Если $c=\sup E$, то $c$ является верхней гранью, а $c-\varepsilon<c$ не может быть верхней гранью.
- Поэтому для каждого $\varepsilon>0$ существует $x'\in E$ такое, что $x'>c-\varepsilon$.
- Обратно, первое условие делает $c$ верхней гранью.
- Для любой верхней грани $c'<c$ берём $\varepsilon=c-c'>0$; тогда условие даёт $x'\in E$ с $x'>c-\varepsilon=c'$, так что $c'$ не верхняя грань.
- Следовательно, $c$ — наименьшая верхняя грань, то есть $c=\sup E$.
- Для инфимума условие делает $c$ нижней гранью; для любой большей нижней грани $c'>c$ берём $\varepsilon=c'-c>0$ и получаем $x'\in E$ с $x'<c+\varepsilon=c'$, так что $c'$ не нижняя грань. Значит, $c$ — наибольшая нижняя грань, то есть $c=\inf E$.
