## matan-q-2110
ticket: matan-t-0209 · level: L2
Докажите теорему Кантора о вложенных отрезках: для вложенных отрезков $[a_n,b_n]$ пересечение непусто, а если $b_n-a_n\to0$, то в пересечении ровно одна точка.
### Эталон
- Вложенность даёт $a_1\leq a_n\leq a_{n+1}\leq b_{n+1}\leq b_n\leq b_1$ для всех $n$.
- Поэтому $(a_n)$ не убывает и ограничена сверху, а $(b_n)$ не возрастает и ограничена снизу; обе последовательности сходятся.
- Обозначим их пределы через $\alpha$ и $\beta$; из вложенности следует $\alpha\leq\beta$.
- Для каждого $n$ имеем $a_n\leq\alpha\leq\beta\leq b_n$, поэтому $[\alpha,\beta]\subset\bigcap_n[a_n,b_n]$ и пересечение непусто.
- Если $x,y$ принадлежат пересечению, то $|x-y|\leq b_n-a_n$ для каждого $n$.
- При $b_n-a_n\to0$ получаем $|x-y|=0$, то есть $x=y$; общая точка единственна.
