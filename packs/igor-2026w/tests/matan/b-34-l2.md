## matan-q-2506
ticket: matan-t-0510 · level: L2
Докажите правило Лопиталя для неопределённости $0/0$ при конечном правом конце $a$: если $f,g$ дифференцируемы на $(a,b)$, $g\prime\ne0$, $f(x),g(x)\to0$ при $x\to a+0$ и $\frac{f\prime(x)}{g\prime(x)}\to L$, то $\frac{f(x)}{g(x)}\to L$.
### Эталон
- Возьмём произвольную последовательность $x_n\in(a,b)$, $x_n\to a$.
- Непрерывным доопределением задают $f(a)=g(a)=0$.
- $g(x_n)\ne0$: иначе $g(a)=g(x_n)=0$, и по теореме Ролля найдётся точка между $a$ и $x_n$, где $g\prime=0$, вопреки условию.
- Теперь по теореме Коши на $[a,x_n]$ выбирают $c_n\in(a,x_n)$ так, что $\frac{f(x_n)}{g(x_n)}=\frac{f\prime(c_n)}{g\prime(c_n)}$.
- Из $a<c_n<x_n\to a$ следует $c_n\to a$.
- По условию отношение производных в $c_n$ стремится к $L$; по критерию Гейне то же верно для $f(x)/g(x)$.
