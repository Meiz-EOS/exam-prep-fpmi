## matan-q-2305
ticket: matan-t-0401 · level: L2
Докажите эквивалентность определений предела по Коши и Гейне: $f(x)\to b$ при $x\to a$ по Коши тогда и только тогда, когда для всякой последовательности $x_n\in E\setminus\{a\}$, $x_n\to a$, имеем $f(x_n)\to b$.
### Эталон
- Если предел существует по Коши, для заданного $\varepsilon>0$ выбирают соответствующее $\delta>0$.
- Из $x_n\to a$ следует, что начиная с некоторого $N$ точки $x_n$ лежат в проколотой $\delta$-окрестности $a$.
- По определению Коши $|f(x_n)-b|<\varepsilon$ при $n\ge N$, то есть $f(x_n)\to b$.
- Если условие Коши неверно, существуют $\varepsilon_0>0$ и для каждого $\delta>0$ точка $x\in E$ с $0<|x-a|<\delta$ и $|f(x)-b|\ge\varepsilon_0$.
- Берём $\delta=1/n$ и такие $x_n$: они стремятся к $a$, но образы не попадают в $B_{\varepsilon_0}(b)$.
- Это противоречит условию Гейне, поэтому предел по Коши существует.
