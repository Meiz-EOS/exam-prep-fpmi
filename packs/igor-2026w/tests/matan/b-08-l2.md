## matan-q-2205
ticket: matan-t-0113 · level: L2
Докажите бином Ньютона: для $a,b\in\mathbb{R}$ и $n\in\mathbb{N}$ выполнено $(a+b)^n=\sum_{k=0}^{n}\binom{n}{k}a^kb^{n-k}$, где $\binom{n}{k}=\frac{n!}{k!(n-k)!}$.
### Эталон
- База индукции $n=1$: $(a+b)=\binom{1}{0}b+\binom{1}{1}a$.
- Предположим формулу для $n$ и умножим её на $a+b$.
- Раскрыв скобки, получим суммы $\sum_{k=0}^{n}\binom{n}{k}a^{k+1}b^{n-k}$ и $\sum_{k=0}^{n}\binom{n}{k}a^kb^{n+1-k}$.
- Крайние слагаемые равны $b^{n+1}$ и $a^{n+1}$.
- Коэффициент при $a^kb^{n+1-k}$ для $1\leq k\leq n$ равен $\binom{n}{k-1}+\binom{n}{k}=\binom{n+1}{k}$ по формуле факториалов.
- Получаем сумму от $k=0$ до $n+1$ с коэффициентами $\binom{n+1}{k}$; индукция завершена.

## matan-q-2206
ticket: matan-t-0207 · level: L2
Докажите, что всякая нестрого возрастающая и ограниченная сверху последовательность сходится к своему супремуму.
### Эталон
- Пусть $c=\sup\{a_n:n\in\mathbb{N}\}$; тогда $a_n\leq c$ для всех $n$.
- Зафиксируем $\varepsilon>0$.
- По определению супремума найдётся $N$, для которого $a_N>c-\varepsilon$.
- Из нестрогого возрастания следует $a_n\geq a_N$ при всех $n\geq N$.
- Поэтому $c-\varepsilon<a_N\leq a_n\leq c<c+\varepsilon$ при $n\geq N$.
- Получили $|a_n-c|<\varepsilon$, значит $a_n\to c$.

## matan-q-2207
ticket: matan-t-0208 · level: L2
Докажите неравенство Бернулли: для $n\in\mathbb{N}$ и $x\geq-1$ выполнено $(1+x)^n\geq1+nx$.
### Эталон
- База индукции $n=1$: $(1+x)^1=1+x$.
- Пусть $(1+x)^n\geq1+nx$; поскольку $1+x\geq0$, умножение сохраняет знак неравенства.
- Тогда $(1+x)^{n+1}\geq(1+x)(1+nx)$.
- Раскрываем произведение: $(1+x)(1+nx)=1+(n+1)x+nx^2$.
- Так как $nx^2\geq0$, получаем $(1+x)^{n+1}\geq1+(n+1)x$.
- По математической индукции утверждение верно для всех $n\in\mathbb{N}$.
