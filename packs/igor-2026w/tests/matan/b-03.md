## matan-q-116
ticket: matan-t-0106 · level: L0
Сформулируйте оба свойства модуля из леммы: критерий $|x|\leq M$ и неравенство для суммы.
### Эталон
- Для $x\in F$ и $M$ выполнено $|x|\leq M\iff -M\leq x\leq M$.
- Для $x,y$ из упорядоченного поля выполнено $|x+y|\leq |x|+|y|$.
- В первом свойстве $M$ не предполагается положительным; само неравенство охватывает этот случай.

## matan-q-117
ticket: matan-t-0106 · level: L1
Назовите скелет доказательства неравенства треугольника для модуля.
### Эталон
- Из определения модуля получают $-|x|\leq x\leq |x|$ и $-|y|\leq y\leq |y|$.
- Складывают границы: $-(|x|+|y|)\leq x+y\leq |x|+|y|$.
- Применяют критерий $|z|\leq M\iff -M\leq z\leq M$ к $z=x+y$ и $M=|x|+|y|$.

## matan-q-118
ticket: matan-t-0111 · level: L1
Назовите скелет доказательства аксиомы Архимеда от противного.
### Эталон
- Предполагают, что $na\leq b$ для всех $n\in\mathbb{N}$; тогда $A=\{na:n\in\mathbb{N}\}$ ограничено сверху.
- По полноте у $A$ есть супремум $c$.
- Так как $a>0$, число $c-a$ не является верхней гранью; значит, для некоторого $n$ выполнено $na>c-a$.
- Тогда $(n+1)a>c$, хотя $(n+1)a\in A$, противоречие.

## matan-q-119
ticket: matan-t-0112 · level: L0
Сформулируйте плотность рациональных чисел в $\mathbb{R}$.
### Эталон
- Для любых $a,b\in\mathbb{R}$ с $a<b$ существует $r\in\mathbb{Q}$ такой, что $a<r<b$.
- Иными словами, каждый непустой открытый интервал содержит рациональное число.

## matan-q-120
ticket: matan-t-0112 · level: L1
Назовите скелет доказательства плотности $\mathbb{Q}$ в $\mathbb{R}$.
### Эталон
- По аксиоме Архимеда выбирают $n\in\mathbb{N}$ так, что $1/n<b-a$.
- Полагают $r=([na]+1)/n$, где $[na]$ — целая часть числа $na$.
- Из $[na]\leq na<[na]+1$ следует $a<r\leq a+1/n<b$, причём $r\in\mathbb{Q}$.

## matan-q-121
ticket: matan-t-0114 · level: L0
Сформулируйте классификацию промежутков на числовой прямой.
### Эталон
- Промежуток — множество $I\subset\mathbb{R}$, содержащее всякое $x$ между любыми двумя своими точками.
- Любой промежуток является одним из: $\emptyset$, $\mathbb{R}$, луч, прямая, отрезок, интервал или полуинтервал.
- В перечень входят вырожденные отрезки, состоящие из одной точки.

## matan-q-122
ticket: matan-t-0114 · level: L1
Назовите скелет доказательства классификации промежутков.
### Эталон
- Для непустого промежутка берут $a=\inf(I)$ и $b=\sup(I)$ в расширенной прямой.
- Если $a=b$, получают вырожденный отрезок.
- Если $a<b$, для каждого $a<x<b$ находят точки $x',x''\in I$ по разные стороны от $x$.
- По свойству промежутка $x\in I$, поэтому $(a,b)\subset I\subset[a,b]$; варианты включения конечных концов дают перечисленные типы.
