## matan-q-2307
ticket: matan-t-0402 · level: L2
Докажите критерий Коши для функции: для $f:E\to\mathbb R$ и предельной точки $a$ конечный предел существует тогда и только тогда, когда $\forall\varepsilon>0\ \exists\delta>0\ \forall x,x'\in B_\delta^\circ(a)\cap E:\ |f(x)-f(x')|<\varepsilon$.
### Эталон
- Если $f(x)\to b$, выбирают окрестность, где $|f(x)-b|<\varepsilon/2$.
- Для любых двух её точек неравенство треугольника даёт $|f(x)-f(x')|\le|f(x)-b|+|f(x')-b|<\varepsilon$.
- Обратно, возьмём последовательность $x_n\in E\setminus\{a\}$, стремящуюся к $a$; условие Коши делает $f(x_n)$ фундаментальной.
- По полноте $\mathbb R$ она сходится к некоторому $b$.
- Для любой другой последовательности $y_n\to a$ исходное условие даёт $|f(x_n)-f(y_n)|\to0$, поэтому $f(y_n)\to b$.
- По критерию Гейне предел функции существует и равен $b$.
