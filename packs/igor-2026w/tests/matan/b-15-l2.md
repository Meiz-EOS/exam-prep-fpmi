## matan-q-2304
ticket: matan-t-0304 · level: L2
Докажите лемму Гейне–Бореля: из любого открытого покрытия $[a,b]$ можно выделить конечное подпокрытие.
### Эталон
- Предположим, что конечного подпокрытия нет.
- Делим отрезок пополам и выбираем половину без конечного подпокрытия; повторение даёт вложенные отрезки $[a_n,b_n]$ с длинами $(b-a)/2^n$, каждый без конечного подпокрытия.
- По теореме Кантора существует $c\in\bigcap_n[a_n,b_n]$; выберем покрывающий его элемент $G_{\lambda_0}$.
- Открытость даёт $B_\varepsilon(c)\subset G_{\lambda_0}$ для некоторого $\varepsilon>0$.
- При достаточно большом $k$ длина $[a_k,b_k]$ меньше $\varepsilon$, поэтому весь этот отрезок лежит в $B_\varepsilon(c)$.
- Тогда $[a_k,b_k]$ покрыт одним элементом, противоречие его выбору.
