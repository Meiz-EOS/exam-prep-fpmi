## aisd-q-2104
ticket: aisd-t-005 · level: L2
Докажите эквивалентность двух постановок задачи сортировки: выдачи перестановки исходных индексов и выдачи отсортированной последовательности элементов.
### Эталон
- Рассматривают элементы как записи с ключом и исходным индексом; тогда даже при повторяющихся ключах записи различимы.
- Отсортированная последовательность записей задаёт перестановку исходных индексов в порядке неубывания ключей.
- Если алгоритм выдаёт такую перестановку, применение её к исходным записям даёт отсортированную последовательность.
- В обратную сторону, последовательность отсортированных записей восстанавливает их исходные индексы; для повторов используется сохранённая связь с исходной записью.
- Оба преобразования сохраняют записи и порядок ключей и взаимно обратны; следовательно, алгоритм для любой постановки преобразуется в алгоритм для другой с линейными дополнительными действиями.

## aisd-q-2105
ticket: aisd-t-006 · level: L2
Докажите, что $\log(n!)=\Theta(n\log n)$ при $n\to\infty$.
### Эталон
- Имеем $n!=\prod_{k=1}^n k\le n^n$, поэтому $\log(n!)\le n\log n$.
- Для $k=\lceil n/2\rceil,\ldots,n$ каждый множитель не меньше $n/2$; таких множителей не меньше $n/2$.
- Поэтому $n!\ge(n/2)^{n/2}$ и $\log(n!)\ge(n/2)\log(n/2)$.
- При достаточно больших $n$, $\log(n/2)=\log n-\log 2\ge(1/2)\log n$, так что снизу получаем $(n/4)\log n$.
- Итак, существуют положительные постоянные, ограничивающие $\log(n!)$ сверху и снизу кратными $n\log n$; смена основания меняет лишь константы.

## aisd-q-2106
ticket: aisd-t-007 · level: L2
Докажите нижнюю оценку $\Omega(n\log n)$ на число сравнений любой сортировки различных ключей.
### Эталон
- Представим работу алгоритма деревом решений: внутренний узел — сравнение, а исход сравнения выбирает ветвь.
- Для корректной сортировки каждая из $n!$ входных перестановок различных ключей должна завершаться в листе, совместимом с её порядком.
- Один лист не может соответствовать двум различным порядкам входных ключей: алгоритм получил бы одинаковые результаты сравнений и выдал бы один порядок для обоих.
- Значит, дерево имеет не менее $n!$ листьев; бинарное дерево высоты $h$ имеет не более $2^h$ листьев, поэтому $h\ge\log_2(n!)$.
- По доказанной оценке $\log(n!)=\Theta(n\log n)$ худшее число сравнений не меньше $\Omega(n\log n)$.
