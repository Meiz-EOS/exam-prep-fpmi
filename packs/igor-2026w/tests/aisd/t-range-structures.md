## aisd-q-313
ticket: aisd-t-037 · level: L0
Для какой модельной задачи подходит Sparse Table и каковы оценки построения и запроса?
### Эталон
- Для неизменяемого массива Sparse Table отвечает на запрос минимума на отрезке; эта схема не сохраняет прежние оценки после обновлений массива.
- Предвычисляются ответы для отрезков длины $2^k$; построение занимает $O(n\log n)$ времени и памяти.
- Запрос использует два перекрывающихся блока длины $2^{\lfloor\log_2 r\rfloor}$ и выполняется за $O(1)$ для идемпотентной операции минимума.

## aisd-q-314
ticket: aisd-t-037 · level: L1
Почему Sparse Table отвечает на RMQ за $O(1)$, хотя два блока могут перекрываться?
### Эталон
- Пусть длина запроса $d=r-l+1$, а $k=\lfloor\log_2 d\rfloor$.
- Берутся блоки длины $2^k$: с начала запроса и с конца запроса; вместе они покрывают весь отрезок.
- Перекрывающаяся часть не меняет минимум, поскольку минимум идемпотентен: $\min(x,x)=x$.
- Ответ — минимум двух сохранённых значений, то есть константное число операций.

## aisd-q-315
ticket: aisd-t-038 · level: L0
Опишите задачу, решаемую деревом отрезков, и оценки его операций.
### Эталон
- Дерево отрезков хранит агрегаты для отрезков массива и поддерживает точечное изменение и запрос агрегата на отрезке.
- Для суммы, минимума и других ассоциативных агрегатов построение занимает $O(n)$.
- Запрос и точечное изменение занимают $O(\log n)$.

## aisd-q-316
ticket: aisd-t-039 · level: L0
Как двоичный спуск в дереве отрезков находит для заданного левого конца $l$ первый правый конец $r$, для которого сумма подотрезка $[l,r]$ не меньше $x$?
### Эталон
- При неотрицательных элементах сумма наращиваемого подотрезка монотонна по правому концу.
- Спуск пропускает узлы, полностью лежащие левее $l$, и ищет первый правый конец, при котором сумма от $l$ достигает $x$; при переходе через целый узел его сумму вычитают из остатка.
- Спуск проходит один путь дерева и занимает $O(\log n)$.

## aisd-q-317
ticket: aisd-t-039 · level: L1
Объясните инвариант двоичного спуска для поиска первого $r$, при котором сумма подотрезка $[l,r]$ не меньше $x$.
### Эталон
- Поддерживаются остаток $x$ и уже учтённая сумма элементов от $l$ до текущего узла; узлы левее $l$ пропускаются.
- При рассмотрении целого узла, если его сумма меньше остатка, узел пропускается и его сумма вычитается; иначе поиск продолжается внутри него.
- Неотрицательность элементов обеспечивает монотонность суммы при движении правого конца, поэтому найденный лист задаёт первый $r$ с суммой $[l,r]\ge x$.
- Путь имеет длину $O(\log n)$; если суммарной суммы до конца массива недостаточно, такого $r$ нет.

## aisd-q-318
ticket: aisd-t-040 · level: L0
Что такое отложенное присваивание на отрезке и зачем дереву отрезков операция `push`?
### Эталон
- Узел хранит метку присваивания для всего своего отрезка, не распространяя её сразу по потомкам.
- При полном покрытии запроса узел обновляется напрямую; метка откладывает обработку детей.
- Перед спуском в детей `push` передаёт им метку и поддерживает согласованность агрегатов.
