## aisd-q-2201
ticket: aisd-t-015 · level: L2
Опишите стабильную сортировку подсчётом ключей из $\{0,\ldots,k-1\}$ и её применение к парам чисел; докажите стабильность и корректность и выведите оценку времени и памяти.
### Эталон
- Считают частоты $c[v]$ каждого ключа $v$ и префиксные суммы $p[v]=c[0]+\ldots+c[v-1]$: $p[v]$ равно числу элементов с ключом меньше $v$, то есть позиции первого элемента с ключом $v$ в ответе.
- Исходный массив просматривают справа налево; элемент с ключом $v$ записывают в позицию $p[v]+c'[v]-1$, где $c'[v]$ — число ещё не размещённых элементов с этим ключом, и уменьшают счётчик $c'[v]$ (начальное значение $c'[v]=c[v]$).
- Корректность: блок ключа $v$ занимает ровно позиции $p[v],\ldots,p[v]+c[v]-1$ и блоки идут по возрастанию ключей, значит ответ упорядочен; стабильность: при обходе справа налево среди равных ключей последний по входу элемент получает последнюю позицию блока, поэтому относительный порядок равных сохраняется.
- Время: подсчёт частот $O(n)$, префиксные суммы $O(k)$, размещение $O(n)$, итого $O(n+k)$; дополнительная память $O(n+k)$ (выходной массив и массив счётчиков).
- Пары $(a,b)$ сортируют лексикографически: сначала стабильно по второй компоненте $b$, затем стабильно по первой компоненте $a$.
- Корректность для пар: после второго прохода пары с разными $a$ упорядочены по $a$, а пары с равными $a$ сохраняют порядок первого прохода (по $b$) в силу стабильности; при диапазонах $k_a,k_b$ время $O(n+k_a+k_b)$.

## aisd-q-2202
ticket: aisd-t-016 · level: L2
Опишите LSD-сортировку чисел из $d$ разрядов по основанию $k$ и докажите её корректность индукцией по номеру прохода; выведите оценку времени.
### Эталон
- Ключи записаны $d$ разрядами по основанию $k$; разряды нумеруют от младшего (1) к старшему ($d$). Алгоритм выполняет $d$ проходов: на проходе $i$ стабильно сортирует массив подсчётом по $i$-му разряду.
- Инвариант: после $i$ проходов массив упорядочен по числу, образованному $i$ младшими разрядами (лексикографически по разрядам $i,i-1,\ldots,1$).
- База: после первого прохода массив упорядочен по младшему разряду, так как сортировка подсчётом корректна.
- Шаг: пусть верно для $i-1$. После прохода $i$ элементы с разными $i$-ми разрядами стоят в порядке этого разряда, а он важнее младших; элементы с равным $i$-м разрядом по стабильности сохраняют порядок, установленный ранее, то есть порядок по $i-1$ младшим разрядам.
- При $i=d$ получаем упорядоченность по всему числу; без стабильности каждого прохода шаг индукции неверен, поскольку порядок младших разрядов терялся бы.
- Время: каждый проход — сортировка подсчётом за $O(n+k)$, всего $O(d(n+k))$; память $O(n+k)$.
