## aisd-q-2401
ticket: aisd-t-047 · level: L2
Опишите дерево Фенвика для задачи «изменить элемент массива, найти сумму на префиксе» (операции `update` и `getSum`), докажите корректность обеих операций и оцените время.
### Эталон
- Индексы с единицы; ячейка `t[i]` хранит сумму $a_j$ по полуинтервалу $(i-\operatorname{lowbit}(i),\,i]$, где $\operatorname{lowbit}(i)$ — младший единичный бит $i$.
- `getSum(i)` складывает `t[i]`, затем переходит к $i-\operatorname{lowbit}(i)$ и так до нуля; `update(i,d)` прибавляет $d$ к `t[i]`, затем переходит к $i+\operatorname{lowbit}(i)$ до выхода за $n$.
- Корректность `getSum`: полуинтервалы на пути $i, i-\operatorname{lowbit}(i),\dots$ не пересекаются и примыкают друг к другу, а их объединение равно $(0,i]$, поэтому сумма ячеек равна префиксной сумме.
- Корректность `update`: ячейка $j$ содержит позицию $i$ тогда и только тогда, когда $j\ge i$ и $j-\operatorname{lowbit}(j)<i$; цепочка $i, i+\operatorname{lowbit}(i),\dots$ проходит ровно по таким $j$ (каждый шаг поднимает младший единичный бит и не пропускает покрывающих ячеек), значит изменяются все нужные ячейки и только они.
- Время: каждый шаг `getSum` обнуляет один единичный бит, поэтому шагов не больше числа единиц в $i$, то есть $O(\log n)$; каждый шаг `update` строго увеличивает $\operatorname{lowbit}$, а он не превосходит $2^{\lceil\log_2 n\rceil}$, так что шагов $O(\log n)$.
- Память $O(n)$; сумма на отрезке $[l,r]$ равна `getSum(r)` $-$ `getSum(l-1)`.

## aisd-q-2402
ticket: aisd-t-048 · level: L2
Опишите обобщение дерева Фенвика на $d$ измерений, докажите его корректность индукцией по $d$ и выведите асимптотику операций и памяти.
### Эталон
- Для массива $a[i_1]\dots[i_d]$ дерево хранит `t[i_1]...[i_d]` — сумму $a$ по прямоугольному блоку $\prod_{k}(i_k-\operatorname{lowbit}(i_k),\,i_k]$.
- Префиксный запрос по $d$ координатам — вложенные циклы: по $i_1$ идут вниз по $i_1\to i_1-\operatorname{lowbit}(i_1)$, внутри — по $i_2$, и так далее; обновление — те же вложенные циклы с шагом $+\operatorname{lowbit}$.
- Корректность запроса индукцией по $d$: при $d=1$ — случай одномерного дерева; для $d>1$ блоки по первой координате на цепочке не пересекаются и покрывают $(0,i_1]$, а для каждого из них внутренняя сумма по остальным $d-1$ координатам по предположению индукции есть префиксная сумма, поэтому сумма по всем вложенным блокам равна сумме по префиксному ящику $\prod_k(0,i_k]$.
- Корректность обновления: ячейка содержит точку $(i_1,\dots,i_d)$ тогда и только тогда, когда по каждой координате её индекс покрывает $i_k$; такие ячейки — это в точности произведение цепочек одномерного обновления, и вложенные циклы обходят их по одному разу.
- Время: цепочка по координате $k$ имеет длину $O(\log n_k)$, а вложенные циклы перемножают длины, поэтому `update` и префиксный запрос работают за $O(\prod_{k=1}^d\log n_k)=O(\log^d n)$ при $n_k=n$; запрос на прямоугольном ящике — включение–исключение по $2^d$ префиксным запросам, то есть $O(2^d\log^d n)$.
- Память $O(\prod_k n_k)=O(n^d)$; по сравнению с одномерным случаем время операции вырастает с $O(\log n)$ до $O(\log^d n)$.

## aisd-q-2403
ticket: aisd-t-049 · level: L2
Опишите обратное дерево Фенвика для максимума на отрезке $[l,r]$ при увеличениях значения в точке (операцию `update` достаточно описать идеей), докажите корректность запроса и оцените его время за $O(\log n)$.
### Эталон
- Две структуры: `t1[i]` — максимум $a$ по $(i-\operatorname{lowbit}(i),\,i]$ (обычное дерево), `t2[i]` — максимум по $[i,\,i+\operatorname{lowbit}(i))$ (обратное, блок обрезается справа числом $n$); память $O(n)$.
- `update` (идея; значения только увеличиваются, до $v$): `t1[j]=max(t1[j],v)` вдоль $j=i,\,i+\operatorname{lowbit}(i),\dots$ и `t2[j]=max(t2[j],v)` вдоль $j=i,\,i-\operatorname{lowbit}(i),\dots$ — это ровно те блоки, что содержат $i$; $O(\log n)$ шагов. Максимум блока при увеличении пересчитывается как $\max$ старого и нового значения; при уменьшении так нельзя, и в постановку оно не входит.
- Запрос $[l,r]$: идут вверх от $p=l$ по `t2`: пока $p\le r$ и $p+\operatorname{lowbit}(p)-1\le r$, берут `t2[p]` и $p\leftarrow p+\operatorname{lowbit}(p)$. Если $p>r$, ответ готов. Иначе идут вниз от $q=r$ по `t1`: пока $q>p$, берут `t1[q]` и $q\leftarrow q-\operatorname{lowbit}(q)$; в конце берут $a[p]$ (точка встречи).
- Корректность: блоки `t2` подряд покрывают $[l,p-1]$ без пересечений. На выходе $p=2^{s}\cdot\text{нечёт}$ и $p+2^{s}-1>r$, значит $r=p+u$, $0\le u<2^s-1$; тогда $\operatorname{lowbit}(r)=\operatorname{lowbit}(u)\le u$, и каждый шаг вниз стирает младший единичный бит $u$, оставаясь $\ge p$, пока $q=p$. Блоки `t1` покрывают $(p,r]$, а $a[p]$ закрывает остаток. Куски не пересекаются и в объединении дают $[l,r]$, а каждый содержит максимум своего блока, поэтому максимум всех равен максимуму на $[l,r]$.
- Время: шаги вверх строго увеличивают $\operatorname{lowbit}(p)\le n$, их не больше $\log_2 n+1$; шагов вниз не больше числа единиц в $u$, то есть $O(\log n)$. Итого запрос $O(\log n)$ (не $\log^2 n$), согласуется с оценкой $O(\log n)$ для запроса и увеличения.

## aisd-q-2404
ticket: aisd-t-050 · level: L2
Опишите дерево Фенвика деревьев Фенвика для суммы на прямоугольнике и точечного изменения в таблице $n\times m$, докажите корректность запроса и обновления и выведите время и память.
### Эталон
- Внешнее дерево Фенвика по строкам: его ячейка $i$ вместо числа хранит внутреннее дерево Фенвика по столбцам, которое поддерживает суммы по блоку строк $(i-\operatorname{lowbit}(i),\,i]$ как функцию столбца; всего $n$ внутренних деревьев размера $m$, память $O(nm)$.
- `update(x,y,d)`: по внешней цепочке $i=x, x+\operatorname{lowbit}(x),\dots$ для каждого $i$ выполняют внутренний `update(y,d)` по цепочке $j=y, y+\operatorname{lowbit}(y),\dots$.
- `getSum(x,y)` — сумма на $[1,x]\times[1,y]$: по цепочке $i=x, x-\operatorname{lowbit}(x),\dots$ складывают внутренние префиксные суммы `getSum(y)` в дереве $i$.
- Корректность `getSum`: блоки строк внешней цепочки не пересекаются и покрывают $(0,x]$, а внутри блока внутренняя сумма по $(0,y]$ — по корректности одномерного дерева — равна сумме по столбцам $[1,y]$ и по строкам блока; сложив по всем блокам, получим сумму по $[1,x]\times[1,y]$.
- Корректность `update`: внутреннее дерево $i$ представляет функцию $b_i(y)=\sum_{x'\in(i-\operatorname{lowbit}(i),i]}a[x'][y]$; клетка $(x,y)$ меняет $b_i$ ровно для $i$ из цепочки $x\to x+\operatorname{lowbit}(x)$ (по одномерной лемме), а для такого $i$ изменение $b_i(y)$ на $d$ есть одномерное `update(y,d)` внутреннего дерева, корректное по одномерному случаю; прочие ячейки не затрагиваются.
- Сумма на $[x_1,x_2]\times[y_1,y_2]$ равна $S(x_2,y_2)-S(x_1-1,y_2)-S(x_2,y_1-1)+S(x_1-1,y_1-1)$ по включению–исключению; каждая операция выполняет $O(\log n)$ внешних шагов по $O(\log m)$ внутренних, то есть $O(\log n\log m)$.
