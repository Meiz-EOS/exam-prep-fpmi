## aisd-q-206
ticket: aisd-t-019 · level: L0
Сформулируйте задачу проверки правильности скобочной последовательности с типами `()`, `[]`, `{}`.
### Эталон
- Требуется определить, образуют ли скобки корректно вложенные пары одного типа.
- Каждый закрывающий символ должен закрывать последнюю ещё не закрытую открывающую скобку того же типа.
- После чтения всей последовательности незакрытых открывающих скобок оставаться не должно.

## aisd-q-207
ticket: aisd-t-019 · level: L1
Опишите алгоритм проверки скобочной последовательности стеком и его инвариант.
### Эталон
- Открывающие скобки помещают в стек.
- При закрывающей скобке стек должен быть непуст, а его вершина должна соответствовать этой паре; иначе ответ «неверна».
- После обработки всех символов последовательность верна тогда и только тогда, когда стек пуст.
- Время $O(n)$, память $O(n)$; инвариант стека — открытые скобки, ожидающие закрытия, в порядке вложенности.

## aisd-q-208
ticket: aisd-t-020 · level: L0
Определите задачу поиска ближайшего меньшего элемента слева, справа, либо ближайшего большего элемента в статическом массиве.
### Эталон
- Для каждой позиции ищут ближайшую позицию в указанном направлении, значение которой строго меньше (либо строго больше) текущего.
- Если подходящей позиции нет, результатом является отсутствие элемента.
- Ближайший означает минимальное расстояние до текущей позиции среди подходящих.
- Для каждого направления и выбранного строгого сравнения требуется найти ответ для всех позиций массива.

## aisd-q-221
ticket: aisd-t-020 · level: L1
Опишите алгоритм монотонного стека для поиска ближайшего строго меньшего элемента слева для всех позиций массива и объясните его инвариант и сложность.
### Эталон
- Идём слева направо, храня в стеке индексы кандидатов с возрастающими значениями.
- Перед обработкой позиции $i$ удаляем с вершины индексы, значения которых не меньше $a_i$; оставшаяся вершина указывает на ближайший строго меньший элемент слева, а пустой стек означает, что его нет.
- После ответа добавляем индекс $i$. Стек содержит только кандидатов, которые могут стать ближайшим меньшим элементом для будущих позиций.
- Каждый индекс добавляется и удаляется не более одного раза, поэтому время $O(n)$, память $O(n)$.

## aisd-q-209
ticket: aisd-t-021 · level: L0
Определите обратную польскую запись и задачу вычисления заданного в ней выражения.
### Эталон
- В обратной польской записи бинарный оператор записан после своих операндов.
- Требуется вычислить значение выражения, соблюдая порядок операндов и заданные операции.
- Для корректного полного выражения остаётся одно итоговое значение.

## aisd-q-210
ticket: aisd-t-021 · level: L1
Опишите стековый алгоритм вычисления выражения в обратной польской записи.
### Эталон
- Число кладут в стек операндов.
- Для бинарного оператора сначала снимают правый операнд, затем левый, вычисляют `левый оператор правый` и кладут результат.
- Корректность следует из того, что перед обработкой очередного токена стек содержит результаты уже прочитанных незавершённых подвыражений.
- Корректная запись оставляет ровно одно значение; время $O(n)$, память в худшем случае $O(n)$.

## aisd-q-211
ticket: aisd-t-022 · level: L0
Определите структуру стека с поддержкой запроса минимума.
### Эталон
- Структура поддерживает `push`, `pop` и запрос текущего минимума.
- Требуемая сложность каждой операции — $O(1)$ в худшем случае.
- Запрос возвращает минимум среди элементов, находящихся в стеке в момент запроса.

## aisd-q-212
ticket: aisd-t-023 · level: L0
Определите очередь и назовите её основные операции при реализации односвязным списком.
### Эталон
- Очередь — структура данных с дисциплиной FIFO: первым извлекается самый давно добавленный элемент.
- `enqueue` добавляет в хвост, `dequeue` удаляет из головы.
- Указатели на голову и хвост позволяют выполнять обе операции за $O(1)$; пустая очередь не содержит элементов.

## aisd-q-213
ticket: aisd-t-023 · level: L1
Опишите реализацию очереди односвязным списком, поддерживающую добавление и удаление за $O(1)$.
### Эталон
- Хранят указатели на голову и хвост; при пустой очереди оба равны `null`.
- При добавлении новый узел связывают после хвоста и обновляют хвост; при пустой очереди он становится также головой.
- При удалении продвигают голову; если очередь стала пустой, обнуляют и хвост.
- FIFO сохраняется порядком связей; обе операции требуют $O(1)$ времени.

## aisd-q-214
ticket: aisd-t-024 · level: L0
Сформулируйте задачу реализации FIFO-очереди на двух стеках и назовите оценки добавления и извлечения.
### Эталон
- Очередь должна добавлять элементы в конец и извлекать из начала, соблюдая FIFO.
- Для реализации используют стек входа для добавлений и стек выхода для извлечений; когда стек выхода пуст, элементы перекладывают в него из стека входа.
- Добавление занимает $O(1)$, извлечение — $O(1)$ амортизированно (отдельный перенос может занять $O(n)$).
- Если нужен запрос минимума, минимумы хранят в обоих стеках, а минимум очереди получают за $O(1)$.
