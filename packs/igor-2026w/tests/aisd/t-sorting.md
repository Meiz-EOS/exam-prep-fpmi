## aisd-q-105
ticket: aisd-t-005 · level: L0
Сформулируйте задачу сортировки и назовите две эквивалентные формы её результата.
### Эталон
- Требуется упорядочить входные элементы по неубыванию их ключей.
- Один результат — перестановка самих элементов в отсортированном порядке.
- Другой результат — перестановка исходных индексов, задающая тот же порядок ключей.
- Применение перестановки индексов к исходным элементам даёт отсортированную последовательность.

## aisd-q-106
ticket: aisd-t-006 · level: L0
Сформулируйте асимптотическую оценку для $\log(n!)$ при $n\to\infty$.
### Эталон
- $\log(n!)=\Theta(n\log n)$ при $n\to\infty$.
- То есть $c_1 n\log n\le\log(n!)\le c_2 n\log n$ при всех достаточно больших $n$ для некоторых $c_1,c_2>0$.
- Основание логарифма (больше единицы) влияет только на константы.

## aisd-q-107
ticket: aisd-t-007 · level: L0
Сформулируйте нижнюю оценку на число сравнений, необходимое сортировке сравнением различных ключей.
### Эталон
- Любая сортировка, использующая только сравнения элементов, в худшем случае делает не менее $\lceil\log_2(n!)\rceil$ сравнений.
- Так как $\log(n!)=\Theta(n\log n)$, это $\Omega(n\log n)$.
- Поэтому Merge Sort асимптотически оптимальна среди сортировок сравнениями.

## aisd-q-108
ticket: aisd-t-007 · level: L1
Объясните аргумент дерева сравнений для нижней оценки сортировки сравнением.
### Эталон
- Каждый узел дерева соответствует сравнению, а исход сравнений задаёт путь алгоритма.
- Для корректной сортировки различных ключей разные входные перестановки должны приводить к различным листьям.
- Значит, у дерева не менее $n!$ листьев, а его высота не меньше $\log_2(n!)$.
- Так как $\log(n!)=\Theta(n\log n)$, худшее число сравнений равно как минимум $\Omega(n\log n)$.

## aisd-q-109
ticket: aisd-t-008 · level: L0
Определите Merge Sort и назовите его временную и дополнительную пространственную сложность.
### Эталон
- Алгоритм делит массив на две части, рекурсивно сортирует их и сливает результаты.
- Слияние двух отсортированных частей линейно по их суммарной длине.
- Рекуррентность $T(n)=2T(n/2)+O(n)$ даёт время $O(n\log n)$.
- Обычная реализация использует $O(n)$ дополнительной памяти.

## aisd-q-110
ticket: aisd-t-009 · level: L0
Какова асимптотическая оценка решения рекурренты $T(n)=2T(n/2)+O(n)$?
### Эталон
- $T(n)=O(n\log n)$.
- Если слагаемое вне рекурсии равно $\Theta(n)$ (как при слиянии), то $T(n)=\Theta(n\log n)$.
- Одного $O(n)$ для нижней оценки не хватает: при работе $O(1)$ вне рекурсии получится $\Theta(n)$.

## aisd-q-111
ticket: aisd-t-009 · level: L1
Выведите оценку $O(n\log n)$ для рекурренты $T(n)=2T(n/2)+O(n)$ методом дерева рекурсии.
### Эталон
- На глубине $j$ имеется $2^j$ подзадач размера $n/2^j$.
- Работа вне рекурсивных вызовов на подзадаче размера $m$ не больше $cm$, поэтому на уровне суммарно не больше $cn$.
- Высота дерева до задач постоянного размера равна $\log_2 n + O(1)$.
- Суммирование по уровням даёт $O(n\log n)$; если работа на подзадаче $\Theta(m)$, то и $\Theta(n\log n)$.

## aisd-q-112
ticket: aisd-t-010 · level: L0
Определите число инверсий массива и назовите время алгоритма подсчёта на основе сортировки слиянием.
### Эталон
- Инверсия — пара индексов $i<j$, для которой $a_i>a_j$.
- При разделении массива отдельно считают инверсии внутри каждой половины.
- При слиянии считают инверсии, пересекающие половины; один проход занимает $O(n)$.
- Общее время — $O(n\log n)$, дополнительная память стандартной реализации — $O(n)$.
