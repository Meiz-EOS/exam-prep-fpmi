## aisd-q-411
ticket: aisd-t-047 · level: L0
Сформулируйте задачу для дерева Фенвика: что делают `update` и `getSum`?
### Эталон
- Поддерживается массив чисел при точечных прибавлениях и запросах суммы префикса.
- `update(i, delta)` прибавляет `delta` к элементу с индексом $i$.
- `getSum(i)` возвращает сумму элементов с индексами от $1$ до $i$ включительно.
- В однобазовой индексации обе операции используют $O(\log n)$ ячеек и времени.

## aisd-q-412
ticket: aisd-t-048 · level: L0
Как обобщается дерево Фенвика на $d$ измерений и как меняется сложность операций?
### Эталон
- Индексы элементов и запросы становятся $d$-мерными; ячейки агрегируют прямоугольные блоки по каждой координате.
- В каждой координате переходы по индексам выполняются посредством `lowbit`.
- При размерах $n$ по всем измерениям запрос префиксного прямоугольника и точечное обновление требуют $O(\log^d n)$ времени.
- Для неодинаковых размеров $n_j$ оценка времени — $O(\prod_{j=1}^d\log n_j)$.

## aisd-q-413
ticket: aisd-t-048 · level: L1
Объясните, как вложенные циклы `lowbit` обобщают дерево Фенвика на $d$ измерений, и выведите асимптотику операций.
### Эталон
- В запросе префиксного прямоугольника для каждой координаты обходят цепочку индексов $i, i-\operatorname{lowbit}(i),\ldots$; обновление обходит соответствующую цепочку вверх через $i+\operatorname{lowbit}(i)$.
- В $d$ измерениях обходы вложены: для каждого выбранного индекса одной координаты выполняют обходы по оставшимся координатам.
- При размере $n_j$ по координате $j$ каждая операция занимает $O(\prod_{j=1}^d\log n_j)$; при одинаковом размере $n$ это $O(\log^d n)$.

## aisd-q-414
ticket: aisd-t-049 · level: L0
Сформулируйте задачу обратного дерева Фенвика из программы и условие на точечные изменения.
### Эталон
- Требуется поддерживать максимум на заданном отрезке и точечные увеличения значений.
- Изменяемое значение может только увеличиваться; операции, уменьшающие его, не входят в эту постановку.
- Запрос максимума и увеличение в точке занимают $O(\log n)$.

## aisd-q-415
ticket: aisd-t-050 · level: L0
Что означает структура «дерево Фенвика деревьев Фенвика»?
### Эталон
- Это многомерная структура, где во внешних узлах дерева Фенвика хранятся внутренние деревья Фенвика.
- Она поддерживает точечные обновления и префиксные агрегатные запросы по двум или более координатам.
- В двумерном случае стандартная операция занимает $O(\log^2 n)$ времени при одинаковых размерах координатных диапазонов.

## aisd-q-416
ticket: aisd-t-050 · level: L1
Как выполняются точечное обновление и префиксный запрос в двумерном дереве Фенвика деревьев Фенвика?
### Эталон
- Во внешних узлах дерева Фенвика по первой координате хранятся внутренние деревья Фенвика по второй.
- При точечном обновлении проходят вверх по внешним индексам и обновляют внутреннюю структуру в каждом посещённом узле; при префиксном запросе идут по внешним индексам вниз и суммируют соответствующие внутренние запросы.
- Для запроса прямоугольника из префиксных запросов используют включение-исключение.
- Для заранее заданного набора точек координаты второй оси, попадающие во внутренние структуры, предварительно собирают и сжимают.
- Операции занимают $O(\log n\log m)$ времени при размерах координатных диапазонов $n$ и $m$.
