# Промпт: файлы пакета из своих материалов любой LLM

Готовый текст для любой модели (ChatGPT, Gemini, DeepSeek, Claude, локальная — неважно): вы даёте ей формат и свои материалы по **одному предмету**, она выдаёт файлы `tickets/`, `cards/`, `tests/`, `items/`, `theory/`. Формат подробно — [pack-format.md](pack-format.md).

## Как пользоваться

1. Добавьте предмет в `pack.yaml` своего пакета: `- { id: <id>, name: <название> }` (id — латиница, например `combi`).
2. Соберите материалы предмета в один текст: программу экзамена (список вопросов), конспект или его часть, список заданий со сроками. Чем точнее программа, тем лучше билеты.
3. Скопируйте промпт ниже, впишите в начало id пакета и предмета, после него вставьте материалы. Большой конспект лучше давать частями: сначала программа → билеты, потом по нескольку билетов → карточки, тесты и теорию.
4. Ответ модели — файлы в виде `=== путь ===` и содержимое. Сохраните каждый в `packs/<пакет>/<путь>`.
5. `npm run check:pack` — и, если есть ошибки, отправьте их той же модели: «Исправь, выдай только изменённые файлы целиком».
6. Прочитайте результат сами: модель ошибается в фактах. Эталоны тестов и ответы карточек сверяйте с конспектом.

## Промпт

````text
Ты готовишь файлы курс-пакета для трекера подготовки к экзамену. Пакет: <ID ПАКЕТА>. Предмет: id <ID ПРЕДМЕТА>, название «<НАЗВАНИЕ>». Материалы — после строки «МАТЕРИАЛЫ».

Выдай файлы строго в таком виде, без пояснений между ними:
=== tickets/<предмет>.yaml ===
<содержимое>
=== cards/<предмет>/01.md ===
<содержимое>
…

ОБЩИЕ ПРАВИЛА
- Id: только строчная латиница, цифры, точка, дефис; начинается с буквы или цифры. Id уникален во всём пакете (билет, вопрос, карточка, задание — все разные). Начинай id с префикса предмета: <предмет>-t-01 (билет), <предмет>-q-001 (вопрос), <предмет>-c-0101 (карточка), <предмет>-hw1 (задание).
- Даты — только ГГГГ-ММ-ДД и только если они есть в материалах. Не выдумывай сроки и факты, которых нет в материалах; если чего-то не хватает — пропусти поле.
- Формулы — LaTeX в $…$ (строчные) и $$…$$ (выносные).
- Лишних полей не добавляй: проверка считает опечатку в имени поля ошибкой.

1) tickets/<предмет>.yaml — билеты: по одному на вопрос программы (определение, теорема, алгоритм).
tickets:
  - { id: <предмет>-t-01, title: "Определение группы", src: "программа, вопрос 1" }
  - { id: <предмет>-t-02, title: "Теорема Лагранжа", key: true }
  - { id: <предмет>-t-03, title: "Простое определение", maxLevel: L1 }
Обязательны id и title. key: true — ключевой билет (самые важные теоремы; у него нельзя maxLevel ниже L2). maxLevel: L1 — для чистых определений (доказывать нечего).

2) items/<предмет>.yaml — задания и сдачи (только если в материалах есть список заданий):
- group: Задание 1
  kind: дз
  items:
    - { id: <предмет>-hw1, title: "Сдать задание 1", soft: "2026-10-10", hard: "2026-10-17", note: "бумага до 17:00" }
- group: Задание 1 · задачи
  kind: дз-задача
  items:
    - { id: <предмет>-hw1-01, title: "№ 1.4" }
    - { id: <предмет>-hw1-02, title: "№ 1.9", star: true }
kind — одно из: дз, дз-задача, теордз, контест, задача-cpp, устная, кр, экзамен. soft не позже hard.

3) cards/<предмет>/NN.md — карточки для Anki: 2–4 на билет, вопрос короткий, ответ — суть в 1–4 строки.
---
deck: <тема>
tickets: [<предмет>-t-01, <предмет>-t-02]
---
## <предмет>-c-0101 · <предмет>-t-01
Что такое группа?
---
Множество с ассоциативной операцией, нейтральным элементом и обратными.

## <предмет>-c-0102 · <предмет>-t-02
Сформулируйте теорему Лагранжа.
---
Порядок подгруппы конечной группы делит порядок группы.
Карточка: «## id · билеты», вопрос, строка из трёх дефисов, ответ. Пустая строка между карточками. Билеты — только из tickets/<предмет>.yaml.

4) tests/<предмет>/<имя>.md — тест. Начни с входного теста по всем билетам (kind: entry), по 1–2 вопроса на билет:
---
id: <предмет>-entry
title: "<Название> — входной тест"
kind: entry
minutes: 60
---
## <предмет>-q-001
ticket: <предмет>-t-01 · level: L0
Дайте определение группы.
### Эталон
- множество с бинарной операцией
- ассоциативность
- нейтральный элемент
- обратный к каждому элементу
Уровни: L0 — определение или формулировка; L1 — формулировка с условиями, простой пример или следствие; L2 — доказательство (только в тестах kind: ticket или topic). Эталон — 2–6 пунктов «что должно быть в хорошем ответе», каждый проверяется «есть / нет». minutes — примерно 3 минуты на вопрос.

5) theory/<предмет>/NN.md — теория по билетам (для теорем и важных определений):
## <предмет>-t-02
### Формулировка
Если $H$ — подгруппа конечной группы $G$, то $|H|$ делит $|G|$.
### Скелет
1. Левые смежные классы по $H$ разбивают $G$.
2. Каждый класс равномощен $H$.
3. Значит, $|G| = [G:H]\cdot|H|$.
### Опирается на
<предмет>-t-01
Формулировка обязательна. Скелет — 3–5 нумерованных шагов доказательства (только если в материалах есть доказательство). «Опирается на» — id билетов этого же предмета через запятую. Один раздел на билет.

В конце ответа — строка: «Проверка: сохраните файлы и запустите npm run check:pack».

МАТЕРИАЛЫ
<вставьте программу, конспект, список заданий>
````

## Что проверить руками после модели

- Билеты покрывают всю программу, ничего не склеено и не пропущено.
- Даты и сроки — ровно как в объявлениях курса.
- Эталоны и ответы карточек верны по конспекту (модель уверенно ошибается в доказательствах).
- `npm run check:pack` — `ok`.
