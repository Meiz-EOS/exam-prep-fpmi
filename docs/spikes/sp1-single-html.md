# SP-1. Собранный Vite один HTML на claude.ai

Дата: 2026-11-07 · Карточка: W1-02

Сборка пробы: `ZACH_ENTRY=engine/sp1.html ZACH_OUT=../dist/sp1 npx vite build` (код пробы — `engine/spike/sp1.tsx`).

| Вопрос | Ответ | Как проверено |
|---|---|---|
| Принимает ли публикация полный документ Vite (`<!doctype><html><head>…`) | **принимает, но вкладывает** его целиком в `<body>` своего каркаса (видно в `Artifact read`). Браузеры это прощают, но это против правил платформы → нужна постобработка | публикация `dist/sp1/sp1.html`, `Artifact read` |
| Берётся ли `<title>` | **да** — «Зачётка SP-1» в списке артефактов | `Artifact list` |
| Запускается ли встроенный `<script type="module">` | **да** | `moduleRan: true` в пробной записи |
| Работает ли `await claude.use("db")` из собранного кода | **да**, на ПК и в приложении Claude на Android (WebView, ширина 411 px) | документ `probe/sp1` версии 2 (две записи), прочитан `ArtifactData`, затем удалён |

**Постобработка нужна** (исправлено 07.11 после `Artifact read`): `tools/build/postprocess.ts` снимает `<!doctype>/<html>/<head>/<body>`, убирает charset и viewport (их задаёт каркас), ставит `<title>` первым. Встроена в `npm run build:claude`.

**Итог:** сборка Vite в один HTML публикуется на claude.ai после постобработки; модульный скрипт и база работают на ПК и телефоне. Пробная страница остаётся для проверок перед выпуском (W1-11).
