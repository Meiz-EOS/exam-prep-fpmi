# Зачётка — функциональное описание

Версия: 0.4 · Дата: 2026-11-07 · Статус: **согласовано** пользователем 07.11 (с правками А-6, Н-1, Н-4, Н-5, Н-7; целевая платформа уточнена). Серые зоны, эпики и вехи — в [roadmap.md](roadmap.md).

## 1. Назначение

Инструмент студента для подготовки к сессии. В одном месте сведены:
- **сдачи и сроки:** письменные задания, контесты, задачи, контрольные, экзамены — со статусами;
- **знания:** карточки с интервальным повторением (в Anki, §5.1), входные тесты и ретесты, теория по билетам;
- **готовность:** карта «билет × уровень L0/L1/L2» и журнал ошибок — по [методике](#method).

У инструмента **два пользователя**:
- **студент** — смотрит и отмечает с телефона или компьютера;
- **агент** (Claude в Claude Code) — пишет контент (сроки, карточки, тесты), в начале каждой учебной сессии читает прогресс и по нему планирует.

Обоим должно быть удобно. Студенту — быстрое действие в одно-два нажатия. Агенту — сжатое чтение состояния и правка контента без лишних вызовов (§6).

Первый курс-пакет — зимняя сессия 2026/27 студента группы Б05-618 (МФТИ, ФПМИ). Сам инструмент не привязан к нему (§2, цель 5).

## 2. Цели и не-цели

### Цели
1. **Одно место для всех сдач.** Просрочка и «горит на неделе» видны с первого экрана.
2. **Повторение без трения:** ежедневные карточки занимают 10–20 минут с телефона.
3. **Измеримая готовность:** тесты дают уровни по билетам, карта готовности считается из них, а не ведётся руками.
4. **Агент работает дёшево:** состояние читается за 1–2 вызова, контент правится как файлы в git (§6).
5. **Переиспользуемость:** движок отделён от курс-пакета. Другой студент копирует репозиторий, подставляет свой пакет (предметы, сроки, карточки) и публикует свою копию.
6. **Расширяемость:** новый модуль (например, «теория» или «план дня») добавляется, не ломая данные остальных.

### Не-цели
- **Общая страница на группу.** Каждый ведёт свою копию; данные одного студента другим не видны (решение 2026-11-07); доступ одногруппникам — через форк публичного репо, решение 2026-11-12, roadmap E-10).
- **Решение домашних заданий за студента.** Для теорДЗ по АиСД курс прямо запрещает LLM, и инструмент этого не делает ни в каком модуле.
- Магазины приложений, аккаунты помимо claude.ai. (Публичный репозиторий движка — уже цель, E-10, 12.11; прогресс остаётся приватным.)
- Полноценный LMS: расписание пар, оценки преподавателей, чат с одногруппниками.
- Нативное приложение и офлайн-режим без сети (пока, см. ГЗ в roadmap).

## 3. Термины

| Термин | Значение |
|---|---|
| **Движок** | Код страницы и схемы данных. Общий для всех копий, личных данных не содержит |
| **Курс-пакет** | Контент одного студента и одного семестра: предметы, сроки, задания, карточки, тесты, ссылки на конспекты. Лежит файлами в git |
| **Прогресс** | То, что меняет студент: статусы, баллы, заметки, ответы, история повторений. Лежит в базе страницы |
| **Пункт** | Одна сдаваемая единица: задача задания, контест, задача C++, кр, экзамен |
| **Карточка** | Вопрос → ответ для интервального повторения; обычно факт уровня L0. Источник — файл пакета, повторение — в Anki |
| **Колода** | Набор карточек одного предмета или темы; в Anki — колода `zachetka::<предмет>::<тема>` |
| **Журнал попыток** | Запись каждого ответа в тесте: текст ответа, самооценка, время. Агент разбирает его в Claude Code |
| **Тест** | Набор вопросов по билетам с уровнем L0/L1/L2. Входной тест, ретест, пробный экзамен |
| **Билет** | Единица программы экзамена |
| **Уровень** {#method} | L0 — формулировки дословно; L1 — идея и скелет доказательства или алгоритма; L2 — полное доказательство или код по памяти. Пороги — в `экзамен/подготовка/методика.md` курс-пакета |
| **Сессия с агентом** | Разговор с Claude Code. В начале он читает прогресс, в конце пишет итоги |

| С-2 | студент | Утром открывает страницу | Видит: что горит, сколько карточек к повторению, план дня (если агент его записал) |

| С-3а | студент | Видит в карточке ошибку или лишнюю карточку | Ставит в Anki флаг (красный — ошибка, оранжевый — лишняя) или правит текст. Агент забирает правки в файлы пакета |

| С-6 | агент | Начинает учебную сессию | Одним-двумя чтениями узнаёт: что сдано, что горит, долги по карточкам, слабые билеты, новые ошибки |
| С-7 | агент | Узнал новый срок из чата или сделал карточки по главе | Правит файл курс-пакета и публикует. Прогресс студента не теряется |
| С-8 | студент | Пишет заметку к пункту или вопросу («не понял лемму 3») | Агент видит её в сводке |
| С-9 | другой студент | Хочет такой же инструмент | Копирует репозиторий, заменяет курс-пакет, публикует свою страницу по инструкции |

## 5. Модули

Модули — разделы одной страницы. Каждый можно выпускать отдельно (вехи — в roadmap).

| Модуль | Что делает | Состояние |
|---|---|---|
| **Сдачи** | Сроки, статусы, баллы, заметки, «Горит», прогресс по группам, экзамены с обратным отсчётом | Прототип работает (v0, 89 пунктов) |
| **Карточки** | Не в странице, а в Anki (§5.1). Страница показывает только сводку: сколько к повторению, слабые темы (если агент её записал) | Не начат |
| **Тесты** | Входной тест, ретест, пробный экзамен; самооценка по эталону, журнал попыток для агента; уровни L0–L2 по билетам; журнал ошибок | Не начат |
| **Теория** | Билеты: формулировка, скелет, ссылка на строки конспекта | Не начат |
| **Готовность** | Карта «билет × уровень» и пороги уд/хор по предметам; считается из тестов | Не начат |
| **Сегодня** | Первый экран: горит, карточки к повторению, план дня от агента | Не начат |

### 5.1 Карточки в Anki {#anki}

Свой планировщик повторений не пишется: берётся Anki (открытый, AGPL-3.0; для личного использования ограничений нет).
- **Студент** повторяет в AnkiDroid (Android, бесплатно) или Anki на компьютере. Синхронизация — через бесплатный аккаунт AnkiWeb.
- **Планирование** — встроенный в Anki FSRS, формулы — встроенный MathJax.
- **Источник истины для текста карточек** — файлы курс-пакета. Агент собирает из них колоду (у каждой карточки постоянный id) и импортирует в Anki. Повторный импорт обновляет текст, но не сбрасывает историю повторений.
- **Правки студента** в Anki (флаг, изменённый текст) агент переносит обратно в файлы.
- **Агент читает историю повторений** (что забывается, какие темы слабые) с компьютера — способ определяет спайк SP-5.

## 6. Требования к работе агента {#agent}

| ID | Требование |
|---|---|
| А-1 | **Сводка за один вызов.** Агент получает всё, что изменилось с прошлой сессии (статусы, заметки, итоги повторений и тестов), одним чтением. Без перебора сотен документов |
| А-2 | **Контент — файлы.** Сроки, карточки, тесты и теория лежат в git в текстовом формате, удобном для `grep` и diff. Правка контента — это правка файла и публикация, а не запись в базу по документу |
| А-3 | **Стабильные id.** У каждого пункта, карточки и вопроса постоянный id. Прогресс привязан к id и переживает правку текста |
| А-4 | **Документация по ссылкам.** Агент читает короткий индекс (≤ 50 строк) и дальше только нужный файл, как в `экзамен/подготовка/` |
| А-6 | **Журнал попыток тестов** читается одним запросом и содержит текст ответа и самооценку — этого хватает для разбора без переспрашивания |
| А-5 | **Проверяемость.** Логика (сроки, расписание повторений, подсчёт уровней) — чистые функции с тестами, запускаемыми одной командой |

## 7. Нефункциональные требования

| ID | Требование |
|---|---|
| Н-1 | Работает на телефоне (ширина 360–430 px) и на компьютере; тёмная тема |
| Н-2 | Страница приватная: открывают только владелец и те, кому он сам дал доступ |
| Н-3 | Действие студента (смена статуса, оценка карточки) сохраняется без перезагрузки и без отдельной кнопки «сохранить» |
| Н-4 | Язык интерфейса — русский/английский(системный) |
| Н-5 | Формулы в карточках и теории отрисовываются (LaTeX) |
| Н-6 | Курс-пакет не содержит чужих личных данных; ссылки на сообщения чатов — только в приватной части пакета |
| Н-7 | **Платформа в два этапа.** Минимальная рабочая версия — страница claude.ai с базой (artifact `db`): нет push и офлайна, это временно. **Целевая платформа (решено 07.11):** APK для Android (тот же веб-код в обёртке) и версия для ПК, где идёт основная работа. Обновление — один файл, присланный в Telegram «Избранное». Обмен данными телефон ↔ ПК — через «Поделиться» в Telegram (файл прогресса) |
| Н-8 | **Переносимость.** Движок не зависит от claude.ai: хранение прогресса, вход и публикация — за сменными адаптерами. Переезд на своё приложение не меняет форматы курс-пакета и прогресса и не теряет данные (экспорт → импорт) |
