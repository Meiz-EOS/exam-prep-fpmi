## Правила

1. **Ветки.** Интеграция — `dev`. Карточка — ветка `task/<ID>-<slug>` от `dev`, сливает координатор (`git merge --no-ff`) после прохождения «Проверки». `main` не трогает никто, кроме пользователя. Force-push запрещён.
2. **Одна карточка — один результат.** Карточка меняет только файлы из «Владеет».
3. **Решения, которых нет в документах, задаются пользователю.** Исполнитель не выбирает сам, а пишет вопрос в отчёт.
4. **Перед сдачей:** `npm run check` (типы + проверка пакета) и `npm test` зелёные.
5. **Коммиты** честно указывают участие ИИ трейлером `Co-Authored-By` (решение 12.11; глобальный запрет действует только для `mipt`).
6. **Рабочий трекер v0 не трогать.** Новая версия публикуется по его адресу только в карточке W1-11, после проверки на пробной странице.
