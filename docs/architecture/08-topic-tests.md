## Р-36. ОКТЧ: программа «Классика» {#oktch-program}

Источник — «Список вопросов ОКТЧ, Кл, 2025 (осень)», версия 14.12.2025, «ПМИ-Классика, ПМИ-РЭШ» (из чата курса; файл кладётся в `mipt/экзамен/tex/билеты/oktch-kl.tex`). 73 вопроса (удовл / хор / отл) и 45 пунктов «на двойку». Отличия от «Инф»: функция Мёбиуса на ч.у.м. (вопросы 25, 48, 49, 62–65), Эрдёш–Гинзбург–Зив (58, 73); часть вопросов «Инф» отсутствует.

`tickets/oktch.yaml` пересобирается: `oktch-t-001…073` — по номерам «Классики», `oktch-t-d01…d45` — «на двойку». Прохождений тестов ОКТЧ в данных нет, поэтому id меняются без переноса; ссылки на билеты во входном тесте и в карточках Anki ОКТЧ переписываются. Список временный: программа осени 2026 обычно выходит около 20.12 — тогда сверка.

## Р-37. Тест по теме: `kind: topic` {#topic-test}

Файл `tests/<предмет>/t-<тема>.md`:

```md
---
id: aisd-t-sort-test
title: "АиСД — сортировки (вопросы 5–11)"
kind: topic
covers: [aisd-t-005, aisd-t-006, aisd-t-007, aisd-t-008, aisd-t-009, aisd-t-010, aisd-t-011]
minutes: 52
reuse: [aisd-q-004]
---
## aisd-q-101
ticket: aisd-t-005 · level: L0
…
```

- `covers` — вопросы программы этой темы (обязательно для `topic`, запрещено для других видов). Тема — 4–8 соседних вопросов программы, 20–40 минут.
- Каждый вопрос теста (свой и из `reuse`) относится к билету из `covers`.
- `minutes` = 2 на вопрос L0 + 4 на вопрос L1 (как Р-23).

## Р-38. Полнота и «только L0» {#coverage}

- **Полнота** (как Р-24): у каждого билета из `covers` есть вопрос L0 и вопрос L1 (свои или `reuse`).
- **Билеты «на двойку»** помечаются в `tickets/` полем `maxLevel: L0`: для них в тесте нужен только L0, и на карте готовности у них нет клеток L1/L2 — они не занижают долю L1. Пороги не меняются: «уд» требует L0 ≥ 95 % по всем билетам, включая «на двойку».
- Один билет входит в `covers` **не больше одного** теста темы (тест пакета). Что весь предмет покрыт — проверяется при выпуске (W6-27), не тестом пакета: контент доливается по частям.

## Р-39. Страница `#tests` {#tests-screen}

У предмета с тестами `topic` после входного/ретестов/пробных — раскрывающаяся группа **«По темам (N)»** в порядке первого билета `covers`; строка — название, минуты, число вопросов, последний результат (как у «По билетам»). Прохождение теста не меняется.

## Р-40. Уровни вопросов {#levels}

- **L0** — определение, формулировка, «что это и зачем» (для C++ — что делает конструкция, правило языка; для АиСД — постановка задачи, асимптотика).
- **L1** — идея и скелет доказательства (ОКТЧ); идея алгоритма, инвариант, почему верна асимптотика (АиСД); механизм и типичная ловушка, короткий пример кода с вопросом «что выведет / где ошибка» (C++). Задачи, которые программа ОКТЧ называет прямо («Задача 2.1»), — L1.
- Эталон — 2–6 пунктов (Р-15, Р-17). Источник эталона: конспект ОКТЧ `tex/oktch.tex`; АиСД и C++ — программа экзамена и стандартные учебники/cppreference (как Р-21), в отчёте карточки — откуда взято.

## Р-41. Контентные карточки {#content-cards}

Одна карточка — диапазон ~12–14 соседних вопросов программы (~25 новых вопросов), свой диапазон номеров вопросов `<предмет>-q-<k>01…<k>99`. Внутри диапазона исполнитель сам делит вопросы на 2–3 темы (границы тем — внутри своего диапазона). Входные вопросы по этим билетам — через `reuse`. Конвейер, проверенный в W4: бриф (reuse, недостающие слоты, минуты) → codex пишет → проверка сборкой (полнота, минуты, KaTeX, слэши) → второй codex-рецензент → правки → моя выборочная сверка (≥ трети вопросов).
