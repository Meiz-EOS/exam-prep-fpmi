Волна **W4**: вопросы L0 и L1 по всем теоремам АиГ и матана, по тесту на каждый экзаменационный билет; «Теория» сгруппирована по экзаменационным билетам; колода Anki пересобрана; выпуск v4. ОКТЧ, АиСД и C++ — следующей волной (порядок — по датам экзаменов).

Зачем: вопросы были у 15–20 % теорем, поэтому пороги «уд» на карте готовности были недостижимы. После W4 у АиГ и матана достижим порог **«уд»** (L0 95 %, L1 50 %). **«Хор» остаётся недостижимым намеренно**: L2-вопросов в W4 нет (решение 09.11), карта покажет «до хор» по L2 — это не ошибка.

## Тест по экзаменационному билету {#ticket-test}

**Р-23.** Новый вид теста `ticket`. Файл `tests/<предмет>/<код>.md`, например `tests/aig/b-g01.md`:

```markdown
---
id: aig-b-g01-test
title: "АиГ g01 — коллинеарность, компланарность, линейная зависимость"
kind: ticket
exam: aig-b-g01
minutes: 16
reuse: [aig-q-001, aig-q-002]
---
## aig-q-101
ticket: aig-t-0201 · level: L1
…
```
- `exam` — обязателен у `kind: ticket` и запрещён у остальных; экзаменационный билет того же предмета; на один экзаменационный билет — не больше одного теста.
- Вопросы (свои и из `reuse`) — только по теоремам из `includes` этого билета. Вопросы входного теста по этим теоремам не переписываются, а берутся через `reuse`.
- `minutes` = 2 × (вопросов L0) + 4 × (вопросов L1).
- id вопросов уникальны в пакете; у каждой контентной карточки W4 свой диапазон номеров (указан в карточке), чтобы параллельные ветки не пересекались.

**Р-24. Полнота.** Если у экзаменационного билета есть тест, то у **каждой** его теоремы в этом тесте есть хотя бы один вопрос L0 и хотя бы один вопрос L1. Проверяется тестом пакета (`engine/tests/pack-math.test.ts`); билеты без теста не проверяются, поэтому контент можно доливать по частям.

**Р-25. Уровни вопросов.**
- L0 — формулировка дословно (для определения — определение и, где принято, отрицание).
- L1 — для теоремы: идея и скелет доказательства (3–5 шагов, сверка со «Скелетом» в `theory/`); **для определения** (билета без «Скелета»): пример и контрпример или связь с соседним понятием (решение 09.11). Движок и карта готовности не меняются.
- Эталон — по строкам конспекта из `src` билета. Теоремы, у которых `src` указывает на программу (`билеты/…`, темы нет в конспекте: сейчас aig-t-1506 в g12 и aig-t-2107 в a12), — эталон по программе экзамена и стандартному учебнику, как Р-21; в отчёте карточки они перечислены отдельно.

## Страница `#tests` {#tests-screen}

**Р-26.** Список тестов — по предметам (порядок предметов как в `pack.yaml`). Внутри предмета сначала входной, ретесты и пробные, затем раскрывающаяся группа **«По билетам (N)»**: строки в порядке `exam/<предмет>.yaml` — код билета, название, отметка уверенности (✔ ≈ ★ ?), минуты, число вопросов и последний результат, как у остальных тестов. Прохождение теста не меняется.

## Страница `#theory` {#theory-by-exam}

**Р-27.** У предмета с `exam/<предмет>.yaml` список теории сгруппирован по экзаменационным билетам: заголовок группы — код, название, отметка уверенности; внутри — теоремы в порядке `includes`, ключевые помечены (не переставляются). Теоремы вне экзаменационных билетов — группа «Вне билетов» в конце (у АиГ и матана сейчас пусто). Предмет без `exam/` — как раньше (Р-20: ключевые сверху). Шторка билета не меняется.
