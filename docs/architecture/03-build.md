# 03. Сборка и публикация

## Команды {#commands}

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальная страница с адаптером `memory` и пакетом `igor-2026w` |
| `npm test` | Vitest: `core`, `content`, слияние, сборка пакета |
| `npm run check` | `tsc --noEmit` + проверка пакета |
| `npm run build:claude` | Один HTML для claude.ai → `dist/claude/index.html` (пакет — `ZACH_PACK`, по умолчанию `packs/igor-2026w`) |
| `npm run build:claude:frozen` | То же, страница только для просмотра с плашкой «переехали» ([07#migration](07-standalone.md#migration)) |
| `npm run build:local` | Версия для ПК → `dist/local/index.html` с полным каркасом, адаптер `http` (режим Vite `pc`, [07#build-local](07-standalone.md#build-local)) |

## Сборка в один HTML {#build}

1. `tools/pack/build-pack.ts` читает `packs/<имя>/` (кроме `private/`), проверяет и отдаёт JSON.
2. Vite встраивает JSON как модуль (`import pack from "virtual:pack"`), `vite-plugin-singlefile` встраивает весь JS и CSS в HTML.
3. Постобработка под платформу (`tools/build/postprocess.ts`, по итогам [SP-1](../spikes/sp1-single-html.md)): платформа сама оборачивает файл в каркас, поэтому снимаются `<!doctype>/<html>/<head>/<body>`, charset и viewport; первым идёт `<title>`, затем meta, скрипт, стили и `<div id="app">`.

## Публикация {#publish}

**С v5 (09.11) основная версия — на ПК** ([07](07-standalone.md)): выпуск = `npm run build:local` и перезагрузка вкладки. Ниже — процедура для claude.ai (замороженная страница, откат).

Публикует **агент** инструментом Artifact (у студента это не делается).
- **Пробная страница** (SP-1, проверки карточек): отдельный путь файла → отдельный адрес. Рабочий адрес не трогается.
- **Рабочий адрес** (страница claude.ai автора, адрес не публикуется): файл `dist/claude/index.html` — **другой путь**, чем у v0, поэтому публикация **обязательно с `url`**, а перед ней `Artifact read` этого адреса. `capabilities` не передавать — сохранятся `{db, user}`.
- После публикации — одна проверка: `ArtifactData list items` и одна смена статуса на странице.

## Сборка APK {#apk}

Подробности — [11-apk.md](11-apk.md#build). Окружение: `. tools/apk/env.sh` (JDK 21 и Android SDK в `../android/`, вне репо; ключ подписи — `~/.config/zachetka/release.jks` + `keystore.env`).

- Инструменты поставлены 12.11 без sudo: Temurin 21.0.13 (сверен по sha256), cmdline-tools 15859902, `platform-tools`, `platforms;android-36`, `build-tools;36.0.0`; ~1,2 ГБ без кэша Gradle.
- Ключ: PKCS12, RSA 4096, псевдоним `zachetka`, отпечаток SHA-256 — у автора. Копии хранятся вне репо (12.11). Потеря ключа = новую версию не поставить поверх, только удалить приложение и перенести прогресс файлом.
- `yes | sdkmanager --licenses` под `set -o pipefail` завершается кодом 141 (SIGPIPE) — это не ошибка, лицензии приняты.

## Ловушки платформы {#traps}

1. **CSP:** скрипты только встроенные или с разрешённых CDN; стили — только встроенные (кроме Google Fonts). Ничего не грузить с других адресов.
2. **`<title>`** должен быть в первых 8 КБ файла.
3. **Нет `alert/confirm/prompt`:** подтверждения — внутри страницы (как «Точно удалить?» в v0).
4. **`localStorage`** — только удобства (фильтр, раскрытые группы), в `try/catch`.
5. **Подписка на базу** — один раз; повторная подписка в рендере зацикливает страницу.
6. **Хэш** — только `#имя`.

## KaTeX {#katex}

CSS KaTeX встроить в HTML, шрифты woff2 — как data URI (`build.assetsInlineLimit` достаточно большой). Иначе шрифты молча не загрузятся. Размер и вид в тёмной теме проверяет SP-2 (нужен с E-3/E-5, в W1 не подключается).

**Реализация (W2-04):** компонент `engine/src/ui/math.tsx` (`<Math text="…$x^2$…$$…$$" />`) импортирует `katex/dist/katex.min.css`; `$…$` — строчная, `$$…$$` — выносная формула; ошибка разбора (`throwOnError`) показывает исходник формулы в `.math-error`, страница не падает. Плагин `tools/build/katex-woff2.ts` оставляет в CSS только woff2 (woff/ttf отрезаются, иначе встроились бы все три формата); шрифты уходят в HTML как `data:font/woff2` (20 штук). Цвет формул наследуется (`currentColor`), в тёмной теме читаются без правок.

**Размер HTML (`build:claude`):**

| | байт | gzip |
|---|---|---|
| до (без KaTeX) | 84 691 | 22 777 |
| компонент не импортирован (tree-shaking убирает KaTeX) | 84 785 | ~23 400 |
| компонент импортирован (временная проба) | 713 491 | 365 228 |

Прибавка при подключении: +629 KB (+342 KB gzip), почти всё — шрифты в base64 (woff2 уже сжат). До W2-05 компонент нигде не подключён, поэтому текущая сборка не растёт.

## Перенос с v0 {#migration}

- Данные переносить не нужно (Р-3): v1 читает те же документы `items`.
- Каталог v0 (89 пунктов) переводится в `packs/igor-2026w/items/*.yaml` один раз (карточка W1-05) из `packs/igor-2026w/private/v0-seed.json` — исходные документы, которыми заполнялась база (89 шт., id → поля).
- **v0 остаётся рабочим**, пока v1 не прошёл проверку на пробной странице и на рабочем адресе. Откат — переиздать `mipt/экзамен/подготовка/app/tracker.html` с `url` рабочего адреса.
