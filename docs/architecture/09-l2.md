Решения пользователя 09.11: W7 — **L2 по всем пунктам АиГ и матана** (L0+L1 там уже полные после W4, тесты «по темам» были бы дублем); L2 — **отдельный тест** рядом с тестом билета; у пунктов-определений **`maxLevel: L1`** (список ниже утверждён); L2-тест — **не больше 5 вопросов** (≤ 40 мин), иначе делится на части.

Зачем: порог «хор» (`hor: { L0: 1.0, L1: 0.85, L2: 0.5, keyL2: true }`) сейчас недостижим — L2-вопросов нет (6 штук во входных тестах). После W7 у каждого пункта с доказательством есть L2-вопрос, у ключевых — обязательно.

## Р-43. Пункты без L2 {#max-l1}

В `tickets/<предмет>.yaml` поле `maxLevel: L1` (то же поле, что `L0` в Р-38): у пункта нет клетки L2, он не входит в долю L2 и не требует L2-вопроса.

- **АиГ (4):** `aig-t-0101` Матрицы: определение; `0401` Декартова система координат; `2201` Линейные пространства; `3102` Подстановки степени n.
- **Матан (12):** `matan-t-0101` Определение функции; `0102` Инъекция, сюръекция, биекция; `0104` Аксиомы поля ℝ; `0105` Аксиома непрерывности; `0201` Определение предела последовательности; `0210` Бесконечные пределы; `0301` Внутренние, внешние, граничные точки; `0404` Непрерывность в точке; `0415` Сравнение функций; `0417` Классификация точек разрыва; `0501` Определение производной; `0601` Определение интеграла Римана.

Инвариант (проверяет тест пакета): у пункта с `key: true` нет `maxLevel` ниже L2 — иначе «хор» недостижим (`keyL2`). Нашёл исполнитель ещё пункт без доказательства — пишет вопрос в отчёт, список сам не меняет.

Экзаменационные билеты целиком без L2: АиГ g02, матан 09 — L2-теста у них нет.

## Р-44. L2-тест билета {#l2-test}

Файл `tests/<предмет>/b-<код>-l2.md` (части — `-l2a`, `-l2b`, `-l2c`):

```markdown
---
id: matan-b-05-l2-test
title: "Матан 05 — L2: доказательства"
kind: ticket
exam: matan-b-05
level: L2
minutes: 16
reuse: []
---
## matan-q-2101
ticket: matan-t-0202 · level: L2
Докажите единственность предела последовательности.
### Эталон
- …
```

- `level: L2` — новое необязательное поле теста, допустимо только при `kind: ticket`. Без него тест билета — как раньше (L0+L1, Р-24).
- Все вопросы L2-теста (свои и `reuse`) — уровня L2 и по пунктам из `includes` билета.
- **Полнота:** по всем L2-тестам одного билета вместе каждый пункт из `includes` без `maxLevel` ниже L2 имеет L2-вопрос. Части одного билета пункты не повторяют.
- **Части:** больше 5 L2-пунктов → `ceil(n/5)` частей, пункты делятся поровну в порядке `includes`. По прогнозу: АиГ g10 (8 → 2), a02 (13 → 3), a09 (7 → 2).
- `minutes` = 8 на вопрос L2 (Р-23 дополняется: 2 / 4 / 8).
- Уже готовые L2-вопросы (`aig-q-011, 023, 025, 027`, `matan-q-006, 011` во входных тестах) подключаются через `reuse`, а не пишутся заново.

## Р-45. Что такое L2 {#l2-level}

**L2 — полное доказательство** (вывод формулы, обоснование алгоритма — для «Метода Гаусса», «Правила Крамера» и т. п.) так, как его спрашивают на экзамене. Вопрос — «Докажите …» / «Выведите …», с точной формулировкой утверждения, если название пункта её не даёт.

Эталон — **4–8 пунктов**: ключевые шаги доказательства по порядку, каждый проверяемый «есть / нет» (опорная конструкция, применённая лемма, ключевая оценка или равенство, вывод). Без воды и без «доказательство очевидно». Источник — конспект `mipt/экзамен/tex/algem.tex`, `tex/matan.tex` по `src` пункта (у части пунктов `src` указывает только на формулировку — тогда доказательство ищется дальше в конспекте или в лекциях потока); в отчёте карточки — откуда взято доказательство каждого вопроса.

## Р-46. Движок {#engine}

- `content/coverage.ts`: `ticketTestGaps` проверяет L0+L1 только у тестов без `level`; для L2-тестов — Р-44 (полнота по всем частям билета, только L2, только пункты билета). `topicTestGaps` — уровни по индексу `maxLevel` (как `ready.ts`), а не только `L0`. `ticketTestMinutes` — 8 за L2.
- `core/ready.ts`, путь экзаменационных билетов: клетка уровня билета считается по пунктам, у которых эта клетка есть; пропадает, только если таких пунктов нет. Сейчас она пропадает, если **хоть один** пункт без клетки — с `maxLevel: L1` у b-05 исчезла бы L2-клетка всего билета.
- `#tests`, группа «По билетам»: L2-тест (и его части) идёт сразу после теста L0/L1 того же билета, в строке — метка «L2» (и «часть 1/2»).
- `#ready`: подсказка «до хор» (`ready/index.tsx` `gaps()`) учитывает `maxLevel: L1`.
