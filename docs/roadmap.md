# Зачётка — карта разработки

Версия: 0.3 · Дата: 2026-11-07 · Основа: [functional-spec.md](functional-spec.md) v0.3

**Обозначения:**
- **ГЗ-n** — серая зона: решение за пользователем или за спайком;
- **SP-n** — спайк: короткая проверка с ответом «да/нет/цифры»;
- **E-n** — эпик;
- **M-n** — веха.

**Размеры:** S ≤ полдня, M ≤ 2 дней, L > 2 дней.

**Порядок работы:**
1. функциональное описание (этот шаг);
2. ответы на ГЗ;
3. архитектура (`docs/architecture/`) и ADR;
4. карточки задач (`docs/architecture/tasks/`, одна карточка = один результат + проверка);
5. реализация по волнам.

Решения, которых нет в документах, задаются пользователю, агент их не выбирает.

**Срок:** сессия начинается 26.12.2026, поэтому всё, что нужно до неё, должно работать к **~20.11**. Позже — только то, что не мешает учёбе.
