# Изменения

Версии — `vMAJOR.MINOR.PATCH` ([13-classmates.md#releases](docs/architecture/13-classmates.md#releases)): MAJOR — несовместимое изменение формата пакета или прогресса (тогда ниже — раздел «Миграция пакета» с точными шагами), MINOR — новые возможности, PATCH — исправления. Сверху — новые.

## Не выпущено

- «Сегодня»: смена предмета больше не теряет отметки начатой темы — тема откладывается (`meta/day.parked`) и возвращается с отметками, если в тот же день вернуться к предмету.
- Пакет `igor-2026w`: независимая вычитка АиСД и ОКТЧ (все карточки и тесты) — исправлены оценки в дереве Фенвика и Sparse Table, корни знаменателя ряда Фибоначчи, авторство решения гипотезы Кемница, привязки к билетам; у тем «Поверхности второго порядка», «Точки разрыва» и «Обращение Мёбиуса на ч.у.м.» появились карточки (всего +9), два новых вопроса L1.

## v1.2.0 — граф тем, план дня, короткий входной тест (15.11.2026)

Формат пакета и прогресса совместим назад: пакет без `graph/` работает как раньше. Подробно — [docs/architecture/14-graph-plan.md](docs/architecture/14-graph-plan.md).

- **Граф тем**: `graph/<предмет>.yaml` — темы из билетов и рёбра «требует»; сборка проверяет граф и раскладывает темы в порядке изучения.
- **«Сегодня» — план дня от приложения**: повторения в Anki → новая тема (следующая открытая по графу, с билетами, теорией и именем колоды Anki) → мини-проверка из 3 вопросов. Оценка времени у каждого шага, одна кнопка «Начать», выбор предмета, состояние дня — в `meta/day`. Сроки — узкой полосой сверху, план агента — свёрнутой заметкой. Когда всё сделано — «На сегодня всё» и «Ещё одна тема».
- **Входной тест по графу**: не больше 8 вопросов по одному, вопрос делит оставшиеся темы пополам; «Прервать и сохранить» на каждом вопросе, тест можно продолжить; в итоге — какие темы уже известны и с какой начать, отметку темы можно поправить руками (`meta/topics`). В `#tests` у предмета с графом входной тест открывает его вместо линейного прогона.
- **Карта тем** — новый раздел `#map`: темы предмета по порядку с состоянием (знал / изучена / открыта / закрыта), зависимостями, билетами и действиями (теория, мини-проверка, «уже знаю» / «не знаю»).
- Колоды Anki по графу: `zachetka::<предмет>::<NN> <тема>`, новые карточки идут в порядке графа. Перед первым импортом старую колоду `zachetka` нужно удалить (история повторений не сохраняется).
- Шаг «Новая тема» у темы без теории в пакете (например, весь C++) прямо говорит, что делать: разобрать перечисленные билеты по своему конспекту и открыть колоду темы в Anki.
- Пакет `igor-2026w`: 124 темы (АиГ 27, матан 24, АиСД 23, C++ 26, ОКТЧ 24); входные пулы — 253 вопроса вместо прежних линейных тестов (АиГ 57, матан 48, АиСД 47, C++ 53, ОКТЧ 48), по два и больше на тему.
- `docs/pack-prompt.md`: промпт для LLM теперь выдаёт `graph/` и входной пул по новым правилам.
- Сводка агента (`tools/agent/diff.ts`) относит ответы входного теста и мини-проверок (`placement-<предмет>`, `check-<тема>`) к их предмету.

## v1.1.0 — ПК одним файлом (12.11.2026)

- `zachetka-linux-x64` в релизе: сервер, страница и пакет в одном исполняемом файле, без git и Node; прогресс — `~/.local/share/zachetka/<пакет>/`, ярлык в меню при первом запуске. Сборка — `npm run build:bin`, в CI — `.github/workflows/bin.yml` по тегу.

## v1.0.0 — первый публичный выпуск (12.11.2026)

- Публичный репо для форков: свой пакет и свой прогресс у каждого, общего сервера нет.
- Локальные настройки — нетрекаемый `zachetka.local.json` (пакет, папка данных, Android SDK); `npm run serve` для Windows/macOS.
- Личное (заметки агента, конфиг синхронизации) — в папке данных, не в репо.
- `npm run check:pack` — проверка пакета, все ошибки сразу в виде `файл:строка: текст`; формат — `docs/pack-format.md`.
- Промпт для любой LLM, генерирующий файлы пакета — `docs/pack-prompt.md`.
- APK собирает GitHub Actions форка по тегу `v*`, ключ — в Secrets форка.
- Лицензия MIT.
