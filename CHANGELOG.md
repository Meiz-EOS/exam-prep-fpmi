# Изменения

Версии — `vMAJOR.MINOR.PATCH` ([13-classmates.md#releases](docs/architecture/13-classmates.md#releases)): MAJOR — несовместимое изменение формата пакета или прогресса (тогда ниже — раздел «Миграция пакета» с точными шагами), MINOR — новые возможности, PATCH — исправления. Сверху — новые.

## v1.0.0 — первый публичный выпуск (12.11.2026)

- Публичный репо для форков: свой пакет и свой прогресс у каждого, общего сервера нет.
- Локальные настройки — нетрекаемый `zachetka.local.json` (пакет, папка данных, Android SDK); `npm run serve` для Windows/macOS.
- Личное (заметки агента, конфиг синхронизации) — в папке данных, не в репо.
- `npm run check:pack` — проверка пакета, все ошибки сразу в виде `файл:строка: текст`; формат — `docs/pack-format.md`.
- Промпт для любой LLM, генерирующий файлы пакета — `docs/pack-prompt.md`.
- APK собирает GitHub Actions форка по тегу `v*`, ключ — в Secrets форка.
- Лицензия MIT.

## До v1.0.0 (личные выпуски v1…v10, 08–12.11.2026)

Сдачи и сроки на новом движке; тесты (входные, по экзаменационным билетам, по темам; уровни L0–L2); теория по билетам и карта готовности; экран «Сегодня» с планом дня; карточки Anki из пакета; версия для ПК (локальный сервер, прогресс в файлах); обмен прогрессом файлом; APK для Android; синхронизация статусов из таблиц курса. Подробно — [docs/architecture/03-build.md#releases](docs/architecture/03-build.md#releases).
